# 21-07 — Measure the final three-prompt Turbo4 context curve

Recommended model: **Luna High**. Phase 21; cluster `21c-final-measurements`.
Depends on: `21-06`.

## Objective

After 21-06 proves the mechanism works, measure the original three benchmark
questions at 20K, 40K, 60K, 100K, 175K, and 262,144 logical context. These are
findings, not pass/fail gates.

## Work

Use one immutable release and T=0/seed42/thinking-off. At each point use one
discarded 40-token warmup and three measured trials per question, with actual
occupied tokens near the requested capacity and explicit generation reserve.
Run selective target KV with CPU-canonical Turbo4 backing, budget-derived hot
Turbo4 pages, and GPU Turbo4 native MTP. Record pp/tg, TTFT, output counts,
route fractions, selected/host/physical rows, MTP acceptance, H2D/D2H/faults,
queue/copy/wait time, graph launches, and memory peaks.

Run one job at a time, checkpoint after every trial, and use progress-aware
deadlines. A point that cannot start or complete is null with a reason; never
replace it with a shorter context. Keep prepared-warm, cold-load, and
fixed-262K growing-history diagnostics in separate tables.

## Acceptance and deliverables

Create `handoffs/21-07.md` and `evidence/PHASE21_CURVE.json/.md`. Include
per-question medians and dispersion, actual occupancy and movement, and a
clear statement of which points are valid. Do not pool unlike contexts or
claim CPU-RAM paging from a zero-transfer run.
