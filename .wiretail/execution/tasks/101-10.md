## Correct test boundary

The saved server_query_replay_transition helper tests callback control flow,
not checkpoint math. The proof must call production query checkpoint capture,
commit, restore, actual target/draft decode and MTP carry, comparing against a
one-pass final-map query from the **same pre-query recurrent state**. Comparing
all history recomputed under a different sparse map is the wrong oracle.

## Specific implementation

1. Add an opt-in model-backed test mode/target beside tests/test-server-prompt-cache
   and its CMake target. Keep its ordinary no-model unit mode fast/CPU capable.
   Link real server-context and existing common init; accept model/B/U/L/H
   through argv. The test loads weights **once**, creates actual target/draft
   contexts sharing those weights, then runs trial and control sequentially
   using reset/restore. Free temporary contexts before creating others if
   scratch/graph ledgers exceed headroom. Never run two Qwen servers/models.
2. Expose the smallest generic test seam that invokes the same production
   server_query_checkpoint::capture/restore (server-context.cpp ~1952–2150)
   and slot query replay owner (~21676), with
   real ctx/spec/sequence IDs. Do not duplicate server logic in a test lambda
   or add a public unauthenticated debug endpoint. Model-backed assertions
   must fail if actual production restore/llama_decode is bypassed.
3. Ingest a tiny deterministic prefix, save the true pre-query GDN/conv/target/
   draft/carry frontier. Create a distinct final-map history view using the
   fixture's explicit deterministic selection (allowed for parity, not natural
   selection proof). Trial executes query provisionally, commits changed map,
   uses real checkpoint restore keeping final map, and replays query once.
4. Control restores the SAME pre-query state, installs SAME final map before
   query, decodes query once, then same suffix. Compare finite target logits,
   final hidden, GDN/conv state, committed token positions/encoded current KV,
   draft frontier/carry and next short native-MTP accept/reject cycle. Use
   existing quantized CUDA tolerances; no hardcoded exact bit identity of
   floating reductions. Historical map equality/version correctness is exact.
5. Add unchanged map (zero replay), cancel after provisional decode and after
   map publication, plus next-request recovery. Existing unit cancellation
   fixtures cover branches; here assert actual states restored/cleared and
   successful finite subsequent target/draft decode. Keep token sequences
   small (hundreds, not4K); synthetic old-page selection suffices for parity.
6. Stop managed Qwen via sudo -n through its lifecycle, record identity; run
   this one model-backed executable with GPU Turbo4 L8192/H4096 and enough
   admitted scratch; resume/reload the same final candidate afterward.
   Required services8080/8091 must be healthy;8092 is untouched. If the fixture
   conflicts with the loaded model, the service is stopped, not treated as
   an authorization blocker. Use current compiled library DSOs.
