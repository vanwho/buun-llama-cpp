# 11-02 — Execute all-page query retrieval and structural union

## Objective

Score the live query against every valid page summary and form a bounded retrieval set that can recall
cold pages while always including mandatory, recent, and structural pages.

## Read

- Task README, cluster `11a-live-routing`, plan 8.6, 21.3, 23.
- Handoffs 01-04, 04-01, 08-04, 11-01.
- Query tensor availability, routing summary/policy APIs, GPU top-k, server token/turn metadata, calibration
  corpus, exact attention ranks.

## Implementation

1. Define the query representation and the layer/head aggregation point before target attention. Tag it
   with query/token/table/model generations.
2. Score all valid page summaries on CPU or GPU based on measured latency/transfer cost. Keep complexity
   bounded by `L * summary_width`, not K/V rows; use existing top-k primitives when beneficial.
3. Form the union in deterministic priority order: current/write/inflight/application pins, required
   structural/system/tool anchors, recent pages, summary top-K, and bounded exploration. Deduplicate before
   comparing with `H`.
4. If mandatory union exceeds `H`, fail with a typed diagnostic. Missing/invalid summary is unavailable,
   not a zero score; use safe fallback/repair rules.
5. Export decision reasons, candidate scores, top-K time, bytes, recall labels, and page-distance metrics.

## Tests and live checkpoint

Ties, all pages cold, missing summaries, structural/recent overlap, mandatory overflow, small `H`, `H>=L`,
focus changes, stale query/table, exploration rotation, and deterministic replay. On calibration prompts,
measure page recall and exact/dense attention-mass capture across top-K/candidate choices; demonstrate at
least one early cold needle enters the requested set.

## Acceptance

Retrieval considers every valid page summary, returns no more than capacity after union, never drops
mandatory pages, recalls cold calibration needles at the frozen floor, and stays within the checkpoint
latency/byte budget.

## Deliverable

Create `handoffs/11-02.md` and a machine-readable retrieval checkpoint with configurations, recall/mass,
latency, failure examples, and selected baseline for telemetry/policy.
