# 101-04a — Fused CUDA parallel GDN prefix with exact rollback tail

Revision: `hotpath-v10-20260914`. Amendment: `gpu-execution-101-20260930`.
Cluster: `gpu101-recurrent-graphs`. Implementation/assessments: gpt-6-luna High.
Dependency: 101-04. Read SPEED101, TESTING and handoff101-04 only.

## Measured reason

The existing graph chunk decomposition is numerically equivalent to serial GDN
and preserves all K snapshots, but loses at the Q256/K3 model geometry on the
RTX 4080: 6.994 ms total versus 6.444 ms serial, including setup, scratch,
copies and execution (0.728 ms versus 0.428 ms graph execution). Production
dispatch therefore remains serial until this successor establishes a
consistently faster CUDA implementation.

## Scope

Implement the existing chunk recurrence as a CUDA backend path for the long
prefix, then feed its final state to the existing serial GDN tail of K tokens.
Keep MTP verification/decode unchanged. Do not whitelist unsupported FLA cubins,
disable rollback, change the GDN norm/epsilon/gate math, or move intermediates to
CPU. Retain the graph decomposition as the numerical oracle.

## Implementation and proof

1. Profile the existing GDN CUDA kernels and graph chunk operations at
   Q256/K3, D128, Hk16/Hv48. Implement the smallest fused CUDA operation that
   computes the same scalar-gate chunk recurrence and final state on device.
   Add generic shape/stride dispatch; preserve the exact K-token tail.
2. Add a deterministic CUDA fixture against the existing serial op for
   N=1/3/64/128/256/257, K=1/3, model head ratio3 and ratio1. Compare every
   output and newest-first snapshot at tolerance <=4e-3; restore every tail
   snapshot and compare the next decode against serial one-pass state.
3. Time serial, graph split and fused CUDA split at Q256/K3/Hk16/Hv48 across
   three alternating repeats. Include graph/setup, copies, allocation/scratch,
   and execution. Enable production dispatch only after split wins consistently
   in full cost and graph execution. Otherwise keep serial and report the next
   measured repair boundary without a live retake.
4. Verify dispatch keys include graph phase, sequence shape and K; MTP verify
   and query replay/checkpoint graph slots cannot reuse stale split topology.
   Confirm all new operations execute on CUDA in the numerical fixture.

Named proof: `cuda_parallel_gdn_prefix_matches_and_wins`.

No managed live request is required unless the measured fused operation is
enabled in production; then retake one representative 4K row.
