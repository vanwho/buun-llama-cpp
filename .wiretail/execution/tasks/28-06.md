## Exact edits
1. Replace per-token CPU Q collection/full inventory scoring with a bounded
   double-buffered GPU->pinned candidate mailbox. Records contain layer/logical
   identity/generation/score and requested bytes, not full Q or attention
   matrices. Poll completed events without synchronizing the compute stream.
2. Maintain pending/inflight/ready slots in the existing pager. Issue H2D on
   copy stream into reserved spare layer slots; do not call upload_ring.wait()
   unconditionally at each attention boundary. Mark ready only after event,
   then update next selection device map with proper producer dependency.
   Reject stale/rejected-speculation versions before publication.
3. Enforce bytes-per-refresh, outstanding capacity, minimum-residency/hysteresis
   and duplicate suppression. Initial experiment cadence8, max1 cold layer
   page per refresh,2 spare slots if memory permits. Scale based on measured
   copy latency/slack, not C. Do not cyclically explore every cold page merely
   to make fault counters increase.
4. Normal decode uses ready resident pages while transfers progress. A cold
   page is not “used” because it was selected before upload. Add a bounded
   demand-miss option at an input/topic boundary for recall that cannot wait
   for later queries. Record that latency as cold TTFT; never silently stall
   every layer/token awaiting its entire ranked cold set.
5. CPU canonical bytes are authoritative for eviction; completed clean victim
   drops mapping, no D2H bounce. Spare-slot exhaustion applies backpressure
   to promotion only where possible, not all no-fault attention.
6. Tests: delayed copy while another decode proceeds, stale candidate and
   speculative reject, in-flight duplicate, full queue, multiple layers same
   logical page, missing host slice. Verify generation/event lifetime and
   prompt cancellation without leaking pinned slots.
7. Live primary: place known fact in early page, fill past H, establish its
   host-only state, issue natural relevant query. Save compact before/copy/
   publication/subsequent layer-use proof and output. No test_force_page in
   this proof. Compare warm no-fault128-output segment to same configuration
   before recall; sampled diagnostics off for production speed timing.
