## Ordered implementation / experiment

1. At identical prefix and native-MTP settings, capture CPU time, CUDA kernel/transfer time, graph capture/update/replay counts, table rebuild cost, allocator churn and verify acceptance.

2. Separate content generation from shape/layout identity. Keep bounded descriptor addresses stable and safely update tables/data without recapturing graphs every token solely for an epoch increment.

3. Avoid O(full-context) CPU scans, vector allocations and metadata copies on no-change decode. Keep fast path for all-fit/all-selected and reuse admitted tables when policy unchanged.

4. Preserve a forced-paged diagnostic mode so the all-fit bypass cannot conceal incorrect paged kernels. Off mode performs no pager work; observe overhead is separately reported.

5. Optimize only measured dominant costs; include multiquery MTP verification and prefill, not a single-token microbenchmark alone. Check that MTP acceptance/output parity is unchanged.

6. Re-run the original short three-prompt protocol and one true warm-pressure workload; compare selective/observe/off with MTP matched. The historical 33% gap is a regression to explain, not an unavoidable sparse-attention tax.

## Concrete execution recipe

Read `EXECUTION_COOKBOOK.md` sections C1/C3/C4/C5 and `IMPLEMENTATION_CONTRACTS.md` sections I3/I5/I6. These are shared context; reuse them within the cluster.

Collect a profile with counters for host prepare, summary scoring, selection,
metadata allocation/copy, graph capture/replay, direct/reference kernel and
native-MTP verification. Isolate one dominant cost with one switch; preserve
identical prefix/H/acceptance for before/after comparison.

Change graph keys to shape/capacity/device/representation layout and pass active
counts/valid bits as data where supported. Data generations still guard readers.
Use fixed-capacity input buffers and bounded descriptor storage instead of
sizing every graph tensor to the changing selected count. Test content-only
updates, a true shape change and rollback, not only steady replay.

Remove an unconditional eval callback from stable warm execution; current-query
or predicted selection mode is recorded and must pass cold first-answer tests.
Run forced-paged parity as well as all-fit fast dispatch so a dense bypass
cannot hide corruption. Export profile breakdown, graph keys and selected
dispatch rules; diagnose remaining costs without inventing a numeric speed gate.
