## Ordered implementation / experiment

1. Make graph write destinations use the pager physical slot and intra-page row mapping, while causal positions remain logical. All layer K/V segments of a token share a generation-safe commit.

2. Batch D2H of newly committed Turbo4 pages into canonical host storage using existing capture/events. Keep writable/unsealed tails pinned and include their bounded bytes in the ledger.

3. Handle partial tails and speculative writes: retain rollback state, never publish rejected tokens, flush accepted tail before checkpoint/free, and reject stale completions before visible publication.

4. Check actual host bytes against source compressed rows including codec/rotation/meansub identity. No quantize-dequantize-requantize conversion on transfer.

5. On clean eviction only release the GPU slot/mapping; host copy survives. Drop neither host bytes nor logical index because the page becomes cold.

6. Keep host canonical metadata separate from GPU presence; retain clear/copy/remove semantics and failure cleanup on capture/allocation errors.
