# 01-01 — Freeze selective-attention product semantics

## Objective

Write the internal behavior contract that every later implementation and test consumes.

## Read

- Task README; plan sections 2, 8, 10, and 15.
- Baseline provenance/results and salvage matrix.
- Existing CLI/VBR configuration resolution in `common/arg.cpp`, `common/common.h`,
  `src/llama-context.cpp`, and `src/llama-vbr-config.h`.

## Deliverable

Add `.wiretail/execution/design/SEMANTICS.md` specifying:

- `off`, `observe`, `selective`, and late `exact` behavior;
- selective mode’s approximation and the bounded GPU page-wave exact reference scope;
- retrieval versus retention and why cold pages require an all-page router;
- structural anchors, recent window, exploration, pins, and fallback choices;
- single-sequence/single-slot initial scope and all fail-closed cases;
- current write-page behavior and partially filled tail pages;
- separation of representation/VBR from residency/pager under one composite transaction authority;
- state/checkpoint/recurrent/MTP ownership;
- telemetry fields and feature-disabled zero-overhead requirement;
- which knobs remain internal/experimental.

Define stable names only for internal concepts. Do not add CLI or public API in this task.

## Acceptance

- At least one concrete example covers a relevant old page becoming cold and later being recalled.
- At least one example covers a resident-only attention trap and exploration recovery.
- Unsupported multi-slot/multi-sequence behavior is explicit rather than silently incorrect.
