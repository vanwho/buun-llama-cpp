## Ordered implementation / experiment

1. Capture actual native-MTP verification query shapes from telemetry; support bounded multiple query tokens with correct per-query logical causal masks and GQA grouping.

2. Load K/V Turbo4 tiles directly from physical page descriptors and dequantize in registers/shared memory. Reuse proven Turbo4 transforms; don't gather selected K/V to giant F16/F32 buffers.

3. Correctly handle page gaps/permutations, partial last page, tokens from current verify block, all-masked rows and partial online-softmax states.

4. Update capability routing only for tested shapes and keep a forced reference diagnostic. Unsupported shapes remain explicit rather than silently reporting direct execution.

5. Run same-prefix per-layer/logit parity with the old reference and dense all-selected; then a cold-promotion verify block.

6. Measure direct/reference fraction, kernel latency, target verify wall time, MTP acceptance and scratch at the same context/config.
