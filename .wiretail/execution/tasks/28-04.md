# 28-04 — Implement tiled paged Turbo4 prefill using the mature MMA pipeline

Cluster: 28c-optimized-paged-kernels-v8. Model: Luna High.

## Read
V8 section4;27-03 bridge measurements;28-03 loader;28-02 buffers.

## Exact edits
1. Refactor the existing fattn-mma-turbo.cuh K/V tile-address loader just enough
   to support contiguous and paged source policies; keep the mature MMA,
   online-softmax, GQA and output logic. Bind the page-aware policy from
   ggml_cuda_flash_attn_ext_paged_turbo4 in fattn.cu. No second attention math
   implementation copied from the old scalar row kernel.
2. Align KV tiles to page256 boundaries or split loads across two pages while
   retaining exact native positions and valid lengths. Skip unselected pages
   via descriptor iteration, not an L-wide mask. Q tiles16/32/64 as supported
   by existing template instances; U64/128/256 may comprise multiple tiles.
3. Reuse decoded K/V tiles across grouped query columns, with coalesced Turbo4
   loads and double-buffered shared tiles where existing pipeline permits.
   Use MMA intrinsics already supported on this GPU family; no SM90-only API.
   Price dynamic shared/register/partial storage. Preserve one inverse V
   transform and causal masking, including mandatory new query-block pages.
4. Share write-frontier and historical descriptor format with decode. Sparse
   prefill attends only bounded A plus its budgeted mandatory rows. No host
   selection round trip or full-C scan per query token.
5. Compare fused paged MMA with27-03 packed+normal FA at Q16/64/128,
   A2048/4096 and one larger A. Include packing/unpack and scratch cost.
   Faster measured bridge may remain for a shape; it may not force repeated
   full-history packing or be presented as zero-copy. Kernel support itself
   must be implemented/tested, not marked done by only running the bridge.
6. Existing CUDA fixture extended for multi-query native gaps/tails and
   selected-all versus normal Turbo4 FA outputs. Check QKV rotations and
   quantized coefficient conventions before changing tolerances.
7. Live append512 and2048 uncached tokens at the primary occupied coordinate,
   two U choices max. Compare throughput and scratch+H headroom at equal A/C.
   Single long-prefill setup is not needed to evaluate this kernel.
