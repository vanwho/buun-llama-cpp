# 10-05 — Connect exact page waves to the live model graph

## Objective

Turn the bounded exact executor into a real all-page Qwen attention route using canonical host pages,
CUDA staging, Turbo4 partial states, and stable online-softmax merging.

## Read

- Task README, cluster `10b-live-prefill-exact`, plan 8.10, 22 step 8, 23.
- Handoffs 06-05, 09-04–09-05, 10-01–10-04.
- Exact plan/executor, direct Turbo4 partial-state kernel, host catalog, transfer scheduler, Qwen graph,
  masks/positions and frozen numerical tolerances.

## Implementation

1. Bind exact upload/wait/compute callbacks to the real catalog, bounded staging slots, CUDA streams/events,
   per-layer/head partial buffers, and merge operation.
2. Cover resident pages plus every cold valid page exactly once. Tail validity, native positions, masks,
   GQA, logical order independence, and identity generations remain authoritative.
3. Size waves from staging/device budget; support serial and double-buffered execution; reject missing
   host backing or duplicate/missing coverage.
4. Merge `(m,l,o)` stably and normalize once. Keep intermediate storage bounded by wave/query/layer/head,
   never by full K/V context and never via CPU Turbo4 dequantization.
5. Integrate exact prefill/decode mode, lifecycle cancellation, graph fences, telemetry/ledger fields, and
   deterministic error propagation.

## Tests and model evidence

CPU merge extremes and coverage tests; CUDA partial-state parity and memcheck; live small-context dense vs
selected-all vs exact per-layer/final-logit comparison; odd tails, permuted hot/cold sets, wave size one/
many, double buffering, missing/corrupt host page, stale event, cancellation. Run a maximum-context exact
smoke with full coverage ledger and bounded memory even if slow.

## Acceptance

No fake callback remains; exact visits every valid position once, matches frozen bounded tolerance, runs
at maximum context, reports wave/staging/transfer/timing data, and does not allocate full target K/V on GPU.
