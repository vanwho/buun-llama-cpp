# 11-05 — Connect predictive prefetch, overlap, and full server lifecycle

## Objective

Overlap real page movement with decode and prove pager, recurrent state, MTP, speculative state, slots,
prompt artifacts and checkpoints remain one atomic lifecycle.

## Read

- Task README, cluster `11b-live-policy`, plan 8.8–8.9 and 22 steps 5–7.
- Handoffs 04-04, 05-01–05-04, 09-05, 11-04.
- Prefetch scheduler, CUDA transfer adapter, graph scheduler, server slot/cache/checkpoint paths, speculative
  accept/reject/carry, hybrid/recurrent memory and MTP generation handling.

## Implementation

1. Feed ranked future intents from retrieval/controller into bounded prefetch depth; coalesce compatible
   pages and submit on dedicated streams before they are required.
2. At decode boundary, resolve readiness by wait budget, prior valid hot set, or safe union. Record faults,
   hits, late waits, overlap, backpressure and cancellation.
3. Join table publication and target/recurrent/MTP frontier changes under one sequence/session generation.
   Speculative rejection rewinds all companions; accepted tokens publish only valid page writes.
4. Fence slot reuse, request cancellation, prompt cache adoption, checkpoint save/restore, clear and
   teardown against old transfer/attention completions.
5. Support one slot explicitly; enable multiple slots only if resources and identities are isolated and
   a live concurrency test passes. Otherwise reject pager startup with `-np > 1`.

## Tests and live benchmark

Prefetch hit/miss, depth/backpressure, event reordering, required miss, focus shift, dirty victim, cancel
during upload, speculative accept/reject, malformed carry, slot reuse, prompt reuse, checkpoint restore,
clear/shutdown and repeated init/free. Live traces must demonstrate actual compute/copy overlap and correct
answers for a cold recall/focus shift.

## Acceptance

No stale completion publishes; MTP remains context-sized Turbo4/GPU; lifecycle state agrees after every
operation; overlap counters/timeline prove asynchronous work; resources return on teardown.
