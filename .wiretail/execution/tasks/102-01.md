to 262144 tokens. This is a small input-validation change, not a model run or

## Exact change

validation around `--context-tokens` (currently default 32768) and the guard
that rejects `context_tokens > 32768`. Keep the default unchanged, introduce a
single named maximum of 262144, and use it only to validate the requested
logical context. Do not change `--target-tokens`, `--hot-tokens`, page size,
fresh-chunk, batch, ubatch, timeout, request, or server behavior here.

Keep existing invariants: `0 < H < L <= 262144`; page-aligned L and H;
`target_tokens <= L - max_tokens`; and all current resume-identity and
effective-runtime-geometry checks. Invalid values must fail before driver
loading, endpoint discovery, credentials, slot clear, or any network call.
The default remains L=32768. The allowed ceiling is a software input range,
not a claim that the GPU can admit that L.
