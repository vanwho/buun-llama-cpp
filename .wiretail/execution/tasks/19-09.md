## Ordered implementation / experiment

1. Profile the current one-CTA-per-query-head serial row loop at increasing selected rows, including the actual native-MTP verification shape; record occupancy, memory throughput, synchronization and end-to-end share.

2. Implement bounded split-KV: multiple page partitions per head/query tile produce unnormalized (m,l,o), followed by a GPU merge/normalization. Reuse the exact-wave partial contract, not a second incompatible definition.

3. Keep partition scratch derived from shape and admitted rows with an explicit cap; choose partitions from runtime device/shape, never a server-specific SM count. Preserve partial tails, gaps, masks, page permutations and all-masked finiteness.

4. Compare split-KV decode with a page-addressing adaptation of existing Turbo4 tiled/MMA for multiquery verify/prefill. Select qualified kernels by measured shape; preserve serial implementation as debug oracle only where useful.

5. Correct global page-mass statistics after merging; benchmark telemetry off/on and maintain Turbo V output-domain/inverse-transform contract.

6. Re-run same-prefix live parity and original short benchmark plus one populated pressure case. Record both kernel-only and end-to-end speed so a fast microkernel cannot hide MTP/host overhead.

## Concrete execution recipe

Read `EXECUTION_COOKBOOK.md` sections C1/C3/C4/C5 and `IMPLEMENTATION_CONTRACTS.md` sections I3/I4. These are shared context; reuse them within the cluster.

Reuse device partial layout and empty-state rules from 19-06. First implement
two page partitions with a merge kernel and validate against partition-count
one; then 4/many partitions with a scratch cap. Keep query/head strides explicit,
and make launch geometry depend on selected row count/device properties.

Profile serial versus split at the same selected rows and query shapes,
including the native-MTP verify block. The merge receives maxima and unnormalized
sum/value, not normalized per-partition outputs. Page mass must be rescaled by
global denominator before retention consumes it.

Benchmark the qualified tiled/MMA alternative for multiquery shapes rather than
assuming split-KV always wins. Preserve debug serial dispatch and report chosen
dispatch boundaries, scratch bytes and end-to-end impact. Use representative
short/long selected-row microcases and one live pressure case, not the final
six-point context campaign.
