# 49-02 — Restore valid cold-page metadata from canonical host storage

Revision: `hotpath-v10-20260914`. Cluster: `49b-selector-correctness-v10`.
Model: Luna Medium; first retry High. Prerequisite:49-01.

## Source and invariant

Inspect `src/llama-kv-pager.cpp::{exact_page_records,routing_inventory}`,
`src/llama-kv-residency.h::llama_kv_page_record`, canonical host page/unit
descriptors in `src/llama-vbr-artifact-catalog.h` and
`src/llama-vbr-artifact-capture.h`,
`src/llama-kv-cache.cpp::set_kv_page_select_inputs`, and
`ggml/src/ggml-cuda/kv-page-select.cu::page_select_eligible`.
Both host-only conversion loops currently leave `valid_length=0`. CUDA then
rejects those pages. Fix the producer, never weaken the kernel's validity rule.

## Exact implementation

1. Factor a single checked canonical-host-to-logical-record conversion used
   by both inventories. Derive valid token extent from identity.position_begin/
   position_end (confirm existing exclusive-end contract) and actual canonical
   unit valid_rows. Require nonnegative/nonempty extent <=page_tokens, proper
   logical page alignment, matching sequence/session generations and required
   K/V layer units of compatible version/extent. Do not assume full page when
   only a tail is valid; sealed-only selection remains a separate condition.
2. Populate valid_length, authoritative content version, host_valid=true,
   dirty=false, host_clean state, physical_slot=UINT32_MAX and full stable page
   identity. Do not synthesize a GPU slot or treat summary-ready as host-valid.
   Bad canonical descriptors return a specific validation failure, not a
   zero-filled eligible page. Preserve the resident version of an identity
   when it has newer uncommitted content and keep it pinned/dirty.
3. Deduplicate by complete stable identity (session, seq, seq generation,
   logical page, layer/bundle semantics), not logical page alone. Maintain
   deterministic ordering; inventory copying is still allowed here and is
   removed from hot path later. Do not change persistence format for this fix.
4. Preserve valid summary ownership separately. A host-ready cold page with
   absent/stale summary is counted with that reason; it must not disappear
   silently from diagnostics. Keep position/causal and rollback checks.

## Regression tests, not hand-written valid-record substitutes

Extend `tests/test-kv-pager.cpp`, `tests/test-kv-routing-retrieval.cpp` and
`tests/test-kv-page-select.cpp`. Create pages through the actual canonical
host store and pager write/seal/evict API, then inspect **both production
inventories**. Assert positive cold valid_length and eligibility; zero-length,
truncated unit, partial page, stale generation, reused logical ID across
sequences and inconsistent K/V version are rejected/explained correctly.
Feed the converted records into the real selector-input builder. Add a CUDA
selector test with a cold candidate and no device slot; positive winner must
come from this conversion, not manual metadata assignment.

Run focused built CPU tests and CUDA selector test. A TurboQuant CPU numerical
kernel refusal in unrelated test-llama-archs is not a failure of opaque host
storage; do not switch canonical bytes to F16/Q8. The GPU test is required on
the available CUDA device. Capture its command and return code.
