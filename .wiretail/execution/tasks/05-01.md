# 05-01 — Make hybrid recurrent and page operations atomic

## Objective

Integrate target paging with Qwen3.8 hybrid memory without paging or corrupting recurrent state.

## Read

- Task README; plan sections 8.1 and 8.9.
- `src/llama-memory-hybrid.*`, `src/llama-memory-recurrent.*`, Qwen3.8 model construction, VBR composite
  operation/companion code, and current sequence-op tests.

## Implementation

- Attention child alone owns page residency and host backing.
- Recurrent state remains exact, fixed-layout, GPU-resident, and separately accounted.
- Wrap prepare/clear/seq_cp/seq_rm/shift/rewind/import in one composite operation/generation decision.
- Define ordering and rollback so attention publication cannot outlive failed recurrent mutation.
- Ensure attention logical positions and recurrent frontier agree after every accepted mutation.
- Feature-disabled hybrid behavior remains unchanged.

## Tests and acceptance

Cover prepare failure in each child, seq copy/remove, rollback, clear/reset, stale async page completion,
and frontier mismatch. Inject failures before/after each child mutation and prove either a consistent old
or consistent new state, never a mixed tree.
