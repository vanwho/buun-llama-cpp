## Exact edits
1. Extend the existing residency identity/mapping to full-attention-layer
   ordinal. GPU per-layer slabs have independently assigned slots and H_l.
   Canonical host bundle remains one owner with existing layer slices. Do not
   create16 duplicate full logical stores or16 copies of global pager state.
   Only full-attention layers participate; GDN and native MTP excluded.
2. In llama-kv-pager.{h,cpp}, llama-kv-residency.{h,cpp}, host-provider adapters
   in llama-kv-cache.cpp and transfer implementation, propagate
   (sequence,logical_page,layer,representation,content_version,valid_length).
   Existing external APIs lacking layer may adapt to a bundle operation in
   reference mode, but the fast runtime must not promote unrelated layers.
3. Bind cpy_k/cpy_v row destinations and K/V attention loads to the SAME
   per-layer slot map. A graph dependency ensures produced rows are written
   before their layer's attention; do not copy from a stale duplicate root.
   Maintain deterministic attention-layer ordinal to model-layer mapping.
   In llama-kv-cache.cpp/.h separate logical position/sequence bookkeeping
   from physical row indices. One global k_idxs/v_idxs cannot address
   independent layer slots: llm_graph_input_attn_kv must bind each layer's
   write-index input, and cpy_k/cpy_v select it by model-layer ordinal.
   get_k/get_v views and reserve_kv_attention_scratch must likewise use that
   layer's physical tensor width, not the maximum logical cell index.
   Do not allocate a second dense-L GPU cache to retain an indexing shortcut.
   Logical metadata may have L host entries. Off/observe/draft caches retain
   their original implementation when the layer-paged path is disabled.
4. Seal only new/rewritten committed Turbo4 ranges on a dedicated copy stream
   after producer event. Use existing bounded pinned ring and completion queue.
   Batch contiguous source spans. Retain immutable full page once clean;
   no whole-page SHA/dequant/readback on each token. Tail rollback invalidates
   affected summary and host versions; never mark host clean before D2H ends.
5. H2D can request K+V slices for one layer. In this test one layer page is
   270336bytes, all16 bundle4325376bytes; derive from geometry at runtime.
   Validate physical/actual transfer bytes against requested layer payload,
   including separate K/V copies and alignment. Evict only a host-clean layer
   mapping whose consumer events have completed.
6. Reuse existing budget solver: charge sum_l H_l*layer_page_bytes plus
   physical rounding, summaries and rings. Allocate full-L MTP once separately.
   Initial equal H_l is okay; interface must allow per-layer budgets without
   a union-based layer coupling.
7. Focused residency/pager tests with two layers needing different pages:
   promotion of layer0 cannot overwrite or implicitly promote layer1.
   Delayed seal/upload, cancellation, partial-tail rewrite and slot reuse
   fixtures required. GPU raw bytes match canonical represented slice.
