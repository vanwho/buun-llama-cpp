## Implementation contract

1. Freeze a submission descriptor at graph submission: exact ordered logical
   page identities, content/summary versions, sequence+rollback generation,
   query position/generation, actual resident-rank and cold-rank offsets/counts,
   layer/head layout and output tensor owner. Decode returned indices against
   that descriptor, **never a newly reconstructed inventory**. Enqueue/upload
   does not mean output is ready. Preserve slot until completion/consumption.
2. Capture rank offsets from the built op even when page_count < A/page size.
   Never infer them later from configured A. Separate resident selection per
   layer from the shared two-cold-bundle admission budget. Deduplicate across
   layers by stable bundle identity. Use rank priority `1/(1+rank)` per layer;
   order bundles by maximum rank priority, then number of distinct nominating
   layers, then ascending logical page ID. Do not compare unnormalized raw
   scores across layers or count one layer twice. Resident candidates cannot
   exhaust slots reserved for cold candidates. Keep this deterministic policy
   explicit so later quality tuning can change it independently of transport.
3. Validate session/seq/rollback/query generation and each candidate's source
   content identity. An unrelated current residency-table epoch increment
   after sealing must not invalidate a still-correct logical query result.
   Publication still rechecks the **current** mapping and leases. Rejected
   speculative results, changed source content or sequence reuse must fail.
   Avoid exact equality to a global epoch as a substitute for these checks.
4. Disable/remove `kv_packed_page_mass_producer` from normal selective packed
   graph construction, its unused buffers and its telemetry-dependent graph
   reuse key. Keep explicitly requested old diagnostic modes isolated. Default
   selective must use mature target FA once, not another custom paged FA to
   produce attention_samples. Normal selection needs no attention-mass callback.
5. Use one optional bounded trace ring of routing edge events, not a second
   observer framework: submitted, eligible resident/cold, ranked, rejected
   reason, queued copy, completed, published, used-in-completed-target-graph.
   Each record carries stable page IDs and generation. Production-disabled
   traces must not add tensor readbacks or affect graph shape. Read aggregate
   counters only at existing reporting boundaries.
