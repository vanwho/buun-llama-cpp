# 101-05 — Stable bounded attention owners and correct hybrid graph reuse

Revision: `hotpath-v10-20260914`. Amendment: `gpu-execution-101-20260930`.
Cluster: `gpu101-recurrent-graphs`. Implementation/assessments: gpt-6-luna High.
Dependency: 101-04. Read SPEED101, TESTING and handoff101-04 only.

## Selected change

Use existing dual target/MTP graph arenas. A selected page's current content,
valid row extent or map update is data, not automatically a new graph. Keep
physical buffer identity, capacity bucket, route, query shape, recurrent state
layout and leases as real structural constraints.

## Implementation

1. Compare llama-graph.cpp::llm_graph_input_attn_kv::can_reuse (~1300) with
   llm_graph_input_mem_hybrid::can_reuse (~2202). Extract/share the attention
   validation/refresh helper and call it from both; retain hybrid s_copy,
   recurrent head/shape and binding-generation checks. Do not simply return
   true on a metadata epoch. Record each false reason only if explicit
   profiling is enabled; no repeated page scans to collect stats.
2. In llama-kv-attention-execution.cpp::llama_kv_attention_packed_row_capacity
   and packed_cache::find_or_create, use a stable admitted capacity bucket
   for the current view/phase. Default bucket is bounded by admitted H plus
   required in-flight current rows already charged to A, rounded to P;
   allocation may use smaller growth buckets when ledger cannot admit fullH.
   Valid extent and native mask remain mutable. Do not reserve L rows in GPU
   packed/F16 storage. Account simultaneous old/new owners and FA scratch
   before growing; if no budget, keep the current legal bucket/route.
3. set_input_kq_mask/can_reuse_kq_mask must use packed capacity for tensor
   shape, and valid native positions for actual attention. Initialize all
   padding to -infinity each appropriate refresh, never attend stale rows.
   On equal capacity and new page IDs/content versions, refresh descriptors
   and delta copies in-place while retaining the old graph's version leases
   until its stream completion event. New route/shape/owner requires rebuild.
4. Verify direct descriptor tables are also bounded reusable buffers; maps
   can change without new tensor addresses when capacities fit. Split mutable
   content epoch from ownership/binding epoch. Preserve generation-ring and
   rollback mutations as data only when graph topology truly stays constant.
5. Regression in test-kv-attention-execution and hybrid graph/CUDA fixture:
   advance valid rows across page/tail boundaries in one bucket; change page
   contents/selection; alternate Q1 and Q3 arena; rollback; grow bucket.
   Expect reuse for stable shape/capacity, rebuild for a real structural change,
   finite causal attention and no stale lease/UAF. Assert nonzero correct
   rebuild reasons in a profiling-only negative test.
6. Use the same short timeline row only if graph churn was material. Report
   prefill vs decode rebuild counts separately, number of allocations and
   time, A peak and end-to-end speed. 324 request-wide rebuilds cannot be
   called 324 prefill rebuilds. Do not weaken lifecycle invariants to meet a
   count target; counts themselves are not acceptance speed gates.
