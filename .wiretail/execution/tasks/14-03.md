# 14-03 — Run held-out dense/exact/selective quality acceptance

## Objective

Evaluate the locked release configuration on held-out `pager-corpus-v2` without retuning and determine
whether selective attention preserves the frozen quality contract.

## Read

- Task README, cluster `14a-correctness-quality`, plan 23.
- Handoffs 08-04, 10-05, 13-05, 14-01–14-02; frozen corpus/gate and release config hashes.

## Runs

1. Verify corpus, expected-answer, checker, model, binary and config hashes before any request.
2. At contexts where dense all-pages fits, compare dense, selected-all and exact per-layer/final logits,
   outputs and greedy tokens using frozen tolerances.
3. At maximum context run exact and selective held-out warm focus, early/middle/end/competing needles,
   system/tool anchors, repository facts, conversation referents, focus shifts, churn and recent controls.
4. Record exact-answer/task scores, all failure examples, router recall/top-page recall, captured exact
   attention mass, output/logit divergence where exposed, perplexity/KL sample, MTP acceptance, selected
   pages and component ablations using the predeclared method.
5. Confirm exact page coverage and canonical host retrieval for every full-context case. Do not modify
   policy, thresholds, prompts, answers or checkers after observing results.

## Acceptance

Every frozen quality/numerical gate passes and no category hides failures behind an overall average.
Selective quality flaws return to their routing/policy/attention owner for a new release candidate and
full rerun; this task cannot be deferred.

## Deliverable

Create `handoffs/14-03.md` and `evidence/QUALITY_ACCEPTANCE_V2.md/json` with hashes, raw paths, per-case
scores/failures, exact coverage and a pass/block decision.
