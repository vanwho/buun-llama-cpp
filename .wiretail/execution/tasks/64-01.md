Model: Luna High; first retry High. Prerequisite:63-04.

Use the installed model, immutable candidate identity, and existing canonical
runner to advance the two concrete phase-63 physical gaps. Run one bounded T1
controlled model-query fixture and, only if its production selector/transfer
chain is mechanically valid, one T3 organic two-document cold-to-hot round
trip. Run a separate concise answer-quality prompt in the same cached
conversation where the fixture permits it.

controlled setup is labeled `controlled_model_query`; a physical promotion is
counted only after completed H2D, published mapping, and completed target-graph
use; and answer correctness is recorded independently. The numeric before
state is phase-63 `controlled_physical=not_run`, `organic_physical=not_run`,
and `answer_quality=not_run`. The after record must give each attempted edge
and quality row a measured, failed, or not_run status with its actual IDs,
generations, bytes, and reason.

Stop at the first invalid response, missing MTP denominator, or broken T0/T1
chain. Preserve the raw boundary and do not call a correct answer or table
epoch a physical-promotion proof.
