   cannot change the production graph topology or route. Replace no-change
   host inventory construction/scans with existing dirty/version queues.
   Use existing actual_capture_count/replay in ggml-cuda.cu for verification;
   fix names if necessary, do not add a new global metrics service.

   speculative tail and alternate Q1/Q3/Q64; contents refresh and numerical
   output change without stale capture. Repeat128 no-fault decode steps and
   verify no steady allocator growth and reused CUDA graphs where enabled.
   Measure eager versus graph mode once; preserve faster valid dispatch.
