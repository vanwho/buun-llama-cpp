# 85-04 — Remove host-bound work from the selected prefill critical path

Revision: `hotpath-v10-20260914`. Cluster: `85d-maintenance-v10`.
Prerequisite:85-03.

Use the existing pager host worker, transfer mailbox, and event ownership to
remove the measured phase-84 maintenance churn. A page seal is eligible for
canonical publication only after a complete 256-token page (the mutable tail
remains deferred); a sealed page gets one asynchronous D2H operation. Policy
and routing catalogue publication are coalesced and obey the configured
accepted-token refresh cadence. A skipped refresh must skip scoring/catalogue
work and no U-token scheduler fence may call host sealing, per-layer/head
Turbo4 summary dequantization, or graph rebuild merely because it is a fence.

Exact implementation scope:

- `llama_kv_pager_host::enqueue()`, `drain()`, and `worker_main()` plus
  `llama_kv_pager::seal_ready_pages()`, `drain_host_completions()`,
  `queue_maintenance()`, and `rebuild_maintenance_queue()` in
  `src/llama-kv-pager.cpp/.h`.
- `llama_kv_cache::capture_kv_routing_query()`,
  `seal_kv_pager_pages()`, `apply_pager_live_policy()`, and
  `note_kv_pager_accepted_tokens()` in `src/llama-kv-cache.cpp/.h`.
- `llama_kv_pager_refresh_due()` in `src/llama-kv-pager-config.cpp/.h` and
  the existing `llama_context::finish()`/pager fence call path only where
  needed to preserve ownership and event ordering.

Required tests:

- Extend `tests/test-kv-pager.cpp` with partial-tail, complete-page, repeated
  fence, async completion, coalesced publication, and refresh-skip counter
  assertions. Keep `tests/test-arg-parser.cpp` cadence coverage green.
- Run `tests/test-cuda-kv-promotion.cpp` to verify canonical host bytes become
  usable only after the bounded D2H completion and that old graph-pinned pages
  remain valid until publication.
- Run a 256-token fail-fast smoke at L8192/C6143/H4096/A4096/B128/U128. Record
  automatic direct-route counters, at least ten GPU utilization samples, and
  deltas for seal calls, complete-page D2H calls/bytes, summary builds,
  catalogue/table publications, graph rebuilds, and waits. The append must
  demonstrate no per-U-token seal/summary/graph maintenance.

Do not add another scheduler or reduce the evidence by disabling the pager.
