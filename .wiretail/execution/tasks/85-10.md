## Bounded dense-target localization

1. Capture valid-vocabulary finite/NaN/Inf counts and explicit argmax from
   available logits for first output and one teacher-forced next row.
   `server_mtp_logit_identity` (~1609 server-context.cpp) currently uses optional
   `llama_get_logits_argmax`: -1 means unavailable, not necessarily bad logits.
   Distinguish absent side-output from computed argmax. Enable expensive
   diagnostic scans for these rows only, never timed production by default.
2. If logits and text are finite/coherent, retain that passing baseline and
   run one native version, retaining proposal/verification trace for85-12.
   Do not bisect a failure no longer reproducible. Native placement/startup
   alone does not certify acceptance, and acceptance is not this task's exit.
3. If MTP-off dense is corrupt, use the same fixed input IDs to compare
   prefill and one-token continuation. Source anchors: ordinary
   `ggml_cuda_flash_attn_ext` (~4030 fattn.cu: Q<=4 fused dispatch, Q rotation,
   prefill materialization), `build_attn_mha`/`build_attn_v_unrotate`, and the
   model's actual GGUF-selected graph builder (`src/models/qwen35*.cpp` where
   applicable). Inspect KV writes, normalization/RoPE, attention output and
   recurrent blocks for the first divergent/nonfinite tensor using a bounded
   diagnostic callback, not a full-layer full-vocabulary trace every token.
4. Disable `GGML_TURBO_MMA_FUSED` once in a fresh process as discriminator
   (env is cached), not permanent fix. Test capture disabled once only if
   replay-specific. Preserve failing token IDs, positions, tensor shapes and
   encoded bytes in a tiny operator regression. Check padded/invalid rows,
   `0*NaN` contamination, inverse channel scale and WHT/V inverse convention.
   Repair the offending operator/data contract, not its output by zeroing NaNs.
5. If a good control is needed, build relevant target from recorded pristine
   upstream/fork master in a separate worktree; never reset/switch active
   worktree. Run identical small tokens/model/flags, narrow the first bad op's
   changes. Don't run a huge full-server bisect. Keep site builds under /srv/ai.

No slash-token constrained probe, arbitrary vocabulary trimming, zero-filled
logits, CPU KV substitution or disabling required target math can count as the
control repair. Finite but incoherent output still needs matched reference.
