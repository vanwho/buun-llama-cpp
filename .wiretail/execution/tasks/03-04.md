# 03-04 — Integrate prefill, decode, and graph epochs

## Objective

Make the selected attention path usable across prompt ingestion and generation without stale graph reuse.

## Read

- Task README; Phase 03 code; graph build/reserve/capture paths in `src/llama-context.cpp`,
  `src/llama-graph.*`, and Qwen3.8 model builders.
- Existing VBR representation-epoch graph invalidation and scratch reservation logic.

## Implementation

- Use the compact reference for unsupported prompt shapes and direct paged kernel where qualified.
- Define prefill page admission/write behavior and transition to decode.
- Keep table pages pinned through every submitted graph.
- Rebuild/recapture only when table/representation/shape epochs require it.
- Reserve scratch against resident rows plus transfer/router work, not logical context.
- Add clear logs for selected reference, selected direct, observe, dense, and refusal paths.

## Tests and acceptance

Test multi-chunk prefill, tail completion, first decode token, unchanged-table graph reuse, changed-table
rebuild, representation change, and feature-off behavior. The small selected-all-pages path must match
dense Turbo4 within the established tolerance.
