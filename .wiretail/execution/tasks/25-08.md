## Implementation recipe

1. Extend the existing optional model-backed test/driver for explicit logical
   context, token-file, GPU/FA placement, selected route and small test H.
   Private test injection of a selected logical page is permitted to prove
   transfer mechanics; keep it opt-in and never a production fixed policy.
   Existing --tokens CLI/default512 context cannot generate a valid pressure
   test by magic. Document every implemented option.
2. Start the real Qwen model with <=16K resolved L and matching native GPU
   Turbo4 MTP, 4–8K occupied, a test H near2K rows with append/transfer slack.
   Disable optional checkpoint/idle caches, not host backing. All target
   weights/attention compute remain GPU.
3. Populate enough pages to exceed H. Identify a specific host-committed,
   nonresident logical page/content version and capture its checksum from
   the canonical bytes outside the timed window. Deterministically request
   that page through the real selection -> promotion transaction path.
4. Correlate logical page/layer, H2D payload, completion event, new physical
   slot/generation, selected descriptor and actual attention invocation.
   Read back a bounded promoted slice after the event for byte identity.
   Counters cannot count just page-table uploads as KV transfer.
5. Run a short ordinary request through the server at the same pressure
   configuration, 128 accepted output tokens budget; record pp/tg and actual
   movement. Deterministic test proves mechanics; natural attention-directed
   recall is separately qualified in 25-11. Label the distinction.
6. On failure, fix the exact layer-index/host-version/slot reuse/queue/fence/
   native-position path here. A CPU attention fallback or gathered F32
   reference is a diagnostic, not target success. Do not increase L to262K
   to reproduce a small-page bug.

and host rows above resident rows; full GPU draft capacity + actual processing;
one complete timed real-pressure server request. Reuse focused
test-kv-residency, test-kv-pager and paged-CUDA regressions.
