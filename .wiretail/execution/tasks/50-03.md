# 50-03 — Overlap selector output and page movement with target computation

Revision: `hotpath-v10-20260914`. Cluster: `50b-hotpath-ownership-v10`.

## Implementation

1. Give each of two submission slots a bounded pinned host result buffer and
   completion event. On GPU selector completion enqueue only bounded IDs/
   scores/descriptor result to that buffer on an ordered async path. Hold
   graph/output ownership until copy finishes. At next ordinary scheduler
   boundary poll event nonblocking; if pending, keep prior valid selection.
   Never wait per layer/token for a just-launched query. No full Q or catalogue
   readback. Overflow backpressure skips/replaces only non-owned future work.
2. Freeze submission source metadata exactly as49-04. Consume a previous
   completed result even when unrelated residency epoch changed; revalidate
   candidate identity/content/rollback against current state before admission.
   Stale source, generation or reuse is rejected with a bounded reason event.
3. Coalesce admitted cold bundle units into contiguous transfer runs using
   existing residency transaction. Use dedicated upload stream, bounded pinned
   staging ring or already pinned canonical spans, and transfer-completion
   event. Publish mapping only after event; retain old valid selected set
   meanwhile. Prevent slot reuse while any target graph still references it.
4. Canonical GPU-tail D2H uses its existing bounded queue: copy only new
   committed rows, avoid full-page repeated sealing or duplicate GPU→CPU→GPU
   traffic for a page still resident. Clean eviction must copy zero D2H.
   Promotion H2D may span all attention layer units in the current bundle
   architecture; record useful/actual bytes, no fake per-layer savings.
5. Stable scheduling point consumes/reaps per request/token batch without
   busy-spin. One explicit capacity wait on an event that can release a slot
   remains permissible from49-05; no unconditional `cudaDeviceSynchronize`,
   backend synchronize, stream wait on CPU or full pager snapshot per token.
6. Cancel/rollback/clear/shutdown synchronize only owned operations before
   freeing resources. A cancelled upload cannot publish later. Preserve full-L
   native-MTP cache and main/draft graph independence.

## Verification

remains valid pending new publication; source IDs and payload checksums agree;
two-slot exhaustion has bounded allocation/no overwrite; rollback invalidates
only affected data. Test clear/restart and repeated graphs under compute-sanitizer
on the small fixture where practical, not a multi-hour model soak.

Capture a short actual-model C6144 append+focus-switch trace with CUDA events
or Nsight if available. Show compute and copies overlap when there is work
to overlap, plus queue/copy/wait time separately. If device/platform serializes
a particular path, identify the actual stream/dependency; do not fabricate an
overlap ratio from enqueue counters. Compare uninstrumented throughput with
traced throughput to quantify measurement overhead.
