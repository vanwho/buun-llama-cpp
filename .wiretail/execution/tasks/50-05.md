## Required changes and controlled decisions

1. Derive live host bundle unit descriptors from model attention layers and
   actual KV tensor geometry (K/V types, row bytes, heads, attention vs
   recurrent layers). Replace fixed16-layer/32-unit live transport loops by
   those descriptors. Separate live dynamic schema from legacy on-disk VBR
   snapshot format; preserve/explicitly reject old format incompatibility,
   do not silently reinterpret persisted bytes or rewrite the VBR ladder.
   Check small and larger layer counts and layer-index mapping, not only this
   model. Unsupported shapes fail at setup with a precise generic message.
2. Ledger includes model weights, all full-L draft KV, recurrent/checkpoint
   state, target H/slack, A workspace, summary catalogue, selector scratch,
   pinned ring, graph compute peak and allocator overhead. Observe peak after
   target+draft warmup/verification, not just model load. Calculate safe H
   using free bytes after non-H reservations and a documented configurable
   headroom margin. Align to actual page/allocation granularity; report totals.
3. Diagnose phase36 control `draft_n_accepted=0` before comparing speeds:
   assert same model/MTP type, draft GPU Turbo4/full-L, prompt synchronization,
   accepted frontier, sampling and rollback state in selective and controls.
   Run tiny same-prefix MTPoff/on isolation. Do not force acceptance or bypass
   verification. Fix incorrect cache/state transfer or timing attribution if
   found; real model rejections are reported honestly with exact inputs.
4. After parity, tune B/U/A/native draft n_max on small same-input work. Start
   B128/U128, compare B64/U64 and B256/U256 only when ledger safe; isolate B
   from U in one extra run only if host batching dominates. Start draft nmax1,
   compare2, optionally4 only if both2 improves and reserve permits. Try A4096,
  2048,1024 subject to mandatory rows/recent/pinned and observed quality.
   No full Cartesian product: change one knob, retain only measured winners.
5. Optimize committed decode and cached append with useful H, not maximum
   synthetic prefill alone. Smaller U can free H but hurt GEMM throughput;
   record peak scratch deltas and rates, fit a conservative measured envelope
   over U,A,L rather than linearly guessing from one OOM. Full-L draft cannot
   be resized to H or CPU. Keep optional distinct ingest vs interactive
   configurations if their measured tradeoff is meaningful and generic.
