## Lifecycle work to implement, not defer

1. Add dedicated persistent ranking backend to llama_context, same CUDA
   device as target. Never share the host capture worker's transfer backend.
   Pass non-owning ranking_backend and pinned_host_buft in pager resources;
   pager exposes accessors. Only probe-rerank creates it. Derive actual buft
   with ggml_backend_dev_host_buffer_type, not pageable std::vector bytes.
2. Add cache unique_ptr<llama_kv_router_job>; new internal
   src/llama-kv-router-job.{h,cpp}, CMake source list. The class is production
   owner, not a test-only duplicate. It owns ring, two pinned host slots, two
   encoded-K GPU slots, job descriptors/identities/state/result contexts and
   terminal events. Existing persistent probes stay cache-owned. Slot size
   <=4MiB; score scratch<=2MiB per processed layer; no L-sized extra cache.
3. Allocate once after admitted pager attach, reuse across turns/graph reserve.
   Real buffer-size/alignment ledger separates GPU/pinned/pageable bytes.
   Failure cleanly unwinds and refuses opt-in; never silently resize H/B/U.
4. Extend ring submit with immutable by-value chunk task identifying candidate,
   layer,row_offset,rows,query/version. Backend enqueue receives that task.
   Store source holder BEFORE enqueue. Add typed completed tickets: successful,
   failed or cancelled. Current poll only reports retirement count; production
   must not normalize after a failed reader. Preserve old wrapper for unit
   compatibility, but new job uses error-aware API and latches failures.
5. Resolve host bundle using host_catalog()->find_page and existing UINT32_MAX
   bundle fallback. Find key unit compact_layer*2, side key, Turbo4 row_bytes,
   current content version. Read contiguous complete rows from unit.bytes
   into pinned slot; shared holder retains view/unit chain through reader event.
   No per-token reads, cold V reads or resident K device->host copies.
6. Production enqueue callback: ggml_backend_tensor_set_async + RERANK graph
   compute_async + terminal event_record on same ranking backend. Slot reusable
   only after key-reader terminal; H2D completion alone is insufficient.
   Preallocated graphs/tensors survive reserve; no per-chunk allocation.
   Backpressure waits only oldest owned event, never whole-device synchronize.
7. Cancel/reset/end/detach release events BEFORE device/pinned/probe buffers;
   context detaches cache while ranking backend lives, then resets backend.
   Repeated cleanup is safe. Published residency is not erased by job cancel.
