## Source-directed optimization decisions (no arbitrary implementation choices)

Use the first material measured owner, not every item simultaneously:

- Full-H packed copies/graph rebuild dominate: packed_cache::update_slots and
  dirty intervals in llama-kv-attention-execution.cpp, set_input/can_reuse in
  llama-graph.cpp. Retain immutable history and copy only append/rewrite rows;
  keep fixed bounded owner capacity and refresh descriptors without rebuilding
  legal stable shapes. Preserve mask/native positions and rollback identity.
- D2H seal waits dominate: pager maintenance/event publication and
  llama_kv_cache host capture. Submit one encoded immutable page/version across
  layers into bounded pinned staging; overlap compute and drain event-ready
  completions. Wait only on exhausted capacity, not every row/layer. A clean
  eviction never copies the historical page back again.
- CPU scans/metadata dominate: retained slot/page indices at the existing
  pager/routing owner and bounded per-query arrays. No scans of L at every
  output token; reuse allocations. Do not turn diagnostics into production
  synchronous readbacks. Prove no-change fast path with one fixture.
- Checkpoint/replay dominates: server_query_checkpoint and final-user span.
  Eliminate full-L serialization/provisional-prefix replay, retain bounded
  GDN/convolution/tail/native carry. Do not skip necessary replay. Optional
  first-attention-Q one-pass experiment is justified only after this correct
  baseline and explicit measured savings, with same-view logit parity.
- Model/GDN/FA dominates: confirm real CUDA backend/layer placement, U256
  parallelism and no unsupported fallback. Profile representative256-query and
  Q1/Q3 shapes. Preserve99-01 evidence favoring packed; benchmark a kernel change
  against IDENTICAL page IDs/masks/bytes. No blind switch to direct or global
  batch decrease. Any speed/B/U tuning uses explicit controls and retains the
  standard1024/256 reporting campaign.
- MTP acceptance remains low AFTER state parity: distinguish sparse-target vs
  dense-draft distribution difference from carry/position defect. If state
  mismatch, repair native-MTP update/carry/rollback owner. If distribution mismatch,
  test one minimal retrieval-view/summary refinement with the same short p0
  shape and page budgets. Keep full-L GPU draft and frozen target view; follower
  draft redesign is optional later, not an unmeasured emergency workaround.

Every inserted repair includes measured baseline/candidate identity, exact
