## Per-row protocol

Start each geometry with a fresh matching server and empty slot. Preserve raw
artifacts externally under
`/srv/ai/paged-kv/results/forward/106-promotion-cost/106-00/`; never commit
requests, SSE streams, slot dumps, builds, binaries or DSOs.

1. **Initial all-hot measurement.** Ingest the frozen target source and only
   the minimum ordinary prefix needed to ask the question. Verify every page
   overlapping the answer-bearing token span is resident. Snapshot cumulative
   counters immediately before and after the exact question. Run one unscored
   warmup, restore the same short logical prefix, then run three measured hot
   requests from independent restores. Record TTFT, request wall time,
   server prompt/decode time and tok/s, output count, response-local MTP, and
   semantic result. This is the requested natural hot-first result.
2. **Fill and prefill curve.** Reset the slot and rebuild the exact same target
   prefix without a scored query. Append the frozen repository schedule in
   chunks of at most 4,096 fresh tokens until exact C. Record each chunk's
   cumulative C, genuinely fresh and processed tokens, cached tokens,
   prompt milliseconds/tok/s, wall time and memory. Do not call cached-history
   throughput fresh prefill.
3. **Cold precondition.** Save/fingerprint the exact filled logical base. The
   complete answer-bearing page set must be host-backed and nonresident before
   a cold measurement. If ordinary pressure has not evicted it, continue only
   within the row's C budget using the next frozen source range. If C is already
   reached, report `cold_precondition_not_met` for that row; do not force a page
   transition or alter production policy.
4. **Matched hot/cold pairs at C.** Preserve a restorable cold-base artifact.
   For each of three repetitions:
   - restore the exact cold base and verify its token/frontier/source hash and
     answer page are cold;
   - run an unscored copy of the exact question to promote the answer page;
   - recapture the exact pre-question logical base (remove the question and
     response through the existing checkpoint/prefix restore, without changing
     bytes or C), verify the answer page remains resident, and run the measured
     **hot-at-C** request;
   - reset and restore the frozen cold base, verify the answer page is again
     host-backed/nonresident, and run the measured **cold-at-C** request.

   The measured hot-at-C and cold-at-C HTTP request JSON must be byte-identical
   except transport/request identifiers. Their pre-request logical C, rendered
   token hash, question span and model/server identity must match. If prefix
   recapture cannot retain a hot page or cold restore cannot recreate a cold
   page, retain the initial-hot and valid cold result and label the same-C
   paired estimate unavailable; do not invent a comparison or loop retries.
5. Verify a cold request counted as promotion has the target page cold before,
   natural selector nomination/admission, completed H2D, published mapping,
   target-graph use, and target page resident afterward. Semantic correctness
   and physical promotion are separate fields. Complete a poor/incorrect row
   as measured data; do not repair ranking or retry a completed semantic miss.

all three pairs, median delta, min/max, and percentage overhead. Also report
prompt/decode deltas, but do not call server `transfer_time_us` the total cost.

counter snapshots. It must not add diagnostic work to production kernels or
