## Ordered implementation / experiment

1. Reduce page attention mass using final softmax normalization across kernel tiles/partitions; verify mass sums against reference. Keep per-layer/group identity and valid-tail normalization.

2. Retain EMA/peak/reuse/recency separately and normalize before combining. Unobserved cold pages are unknown, not measured zero. Query retrieval must remain able to recall them.

3. Define mandatory anchor/sink/write pins first, then capacity-relative recent/history/transient shares, hysteresis and bounded exploration. Explicitly handle pin overflow and promotion workspace.

4. Start with cross-layer storage groups and per-layer selection masks. Measure wasted union traffic/attention; only add finer layer-group residency if its bytes/latency savings justify added atomicity complexity.

5. Expose policy knobs generically with existing configuration seams; document automatic scaling and tune only on calibration cases.

6. Add an uncertainty/low-recall fallback that expands selection or invokes a labeled exact check when budget permits. Never allow omitted pages to become permanently unreachable.

## Concrete execution recipe

Read `EXECUTION_COOKBOOK.md` sections C1/C3/C4/C5 and `IMPLEMENTATION_CONTRACTS.md` sections I3/I5. These are shared context; reuse them within the cluster.

Verify page-mass output against the CPU softmax reference using multi-partition
F3 before using it as a policy signal. Sum over valid rows using the global
denominator; aggregation across queries/heads/layers is explicitly max/sum/mean,
not an accidental index collision.

Implement per-page observation count/last observation, EMA and recent peak.
Keep missing observation distinct from measured zero. Define deterministic tie
breaking and the priority order: writable/speculative/inflight pins, caller/
sink anchors, then capacity-relative policy choices with staging space reserved.
Test H=small, all pins filling H, missing summaries and alternating focus.

Compare recency-only, retrieval-only and retrieval+retention on calibration
traces at the same H. Export policy configuration, normalized score families,
tie/hysteresis rules and a cold recall trace. A per-layer mask can reuse
cross-layer storage; finer layer-group transfers require measured union waste
and new lifecycle tests, not an unplanned per-head allocator rewrite.
