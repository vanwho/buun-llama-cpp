## Exact changes

1. In `src/llama-kv-cache.{h,cpp}` add per-sequence/per-attention-layer probe
   storage beside the existing accumulator. F32 [D,Qheads,4], four absolute
   positions and validity/generation metadata. Allocate once from the same
   GPU buft as layer K. It survives graph reserve exactly like the pager owner.
   Legacy accumulator/output remains unchanged when mode=legacy.
2. Derive unique positions query_end-{1,2,4,8} within [query_start,query_end).
   Use the current server-rendered user span, never ubatch-local row indexes
   as positions. For a short span discard unavailable probes; never clip
   several probes to the same row and count duplicates. Ensure the final real
   user row is always present. Inspect `final_user_token_end` trimming and
   `begin_kv_pager_turn` rather than shifting boundaries by guessed tokens.
3. Add GGML_OP_KV_QUERY_PROBES and `ggml_kv_query_probes` with explicit
   inputs transformed Q, absolute positions, persistent probe tensor,
   persistent validity/generation tensor, control (turn/query/span identity).
   Extend op names/symbols in ggml.c, enum/API in ggml.h, CUDA dispatch and
   supports_op in ggml-cuda.cu, CPU dispatch/task-count in ggml-cpu.c, and
   scalar oracle in ggml-cpu/ops.{h,cpp}. Implement CUDA beside existing
   query_accumulate_* in kv-page-select.cu; one fused gather/reset operation
   instead of three kernels or Q device-to-host. Output aliases/depends on
   persistent probes using established accumulation ownership semantics.
4. `build_kv_page_select` transforms original target Q with existing
   ggml_turbo_wht(direction2), then attaches probes on each user ubatch.
   `llama-graph.cpp::cb(Qcur_routing)` and graph input reuse recognize both
   mean accumulation and probe capture, attach required controls, and expand
   persistent writes even before the final row. Selector creation still runs
   once when has_final_user_row is true. Reuse keys include mode, tensor
   shape, probe count and coordinate identity; value/position inputs refresh.
5. Reset validity on a new turn/query identity, slot clear, cancellation and
   owner teardown. Replay of the committed query does not recapture or rank;
   it uses frozen selection. Repeated same-generation provisional rows
   overwrite their matching probe slot instead of adding/duplicating data.
   Poison/absent probes do not silently become zero vectors.
