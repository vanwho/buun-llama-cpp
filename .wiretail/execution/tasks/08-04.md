# 08-04 — Freeze pager-corpus-v2 and performance gates

## Objective

Create immutable calibration/held-out workloads and result schemas before live selective parameters are
tuned. This task defines evaluation; it does not tune or run selective acceptance.

## Read

- Task README, cluster `08b-benchmark-contract`, plan sections 23–24.
- Handoffs 00-03, 06-03, 06-04, 07-02, 08-03.
- `/srv/ai/benchmarks` instructions, current runner/results schema, repo pager adapter.

## Work

1. Inspect `/srv/ai` dirty state. Put server-specific corpus/config/orchestration there; keep reusable
   parser/schema support in `tools/server/bench` only when portable.
2. Build `pager-corpus-v2` with calibration and held-out partitions. Include warm focus, early/middle/end
   needles at recorded page distances, competing facts, tool/system anchors, repository/code facts,
   conversation referents, abrupt focus shifts, adversarial churn, and recent-only controls.
3. For every scored case record exact input construction, tokenizer/model identity, expected answer or
   deterministic checker, scoring rule, minimum score, context/page distance, and stable hash. Do not use
   subjective unrecorded grading.
4. Freeze numerical tolerances for dense/selected-all/exact output/logit comparisons, routing recall,
   captured attention mass, held-out task score, perplexity/KL sample, and MTP acceptance disclosure.
5. Freeze performance gates exactly as plan 24, trial counts, warmup boundaries, fault-segment labeling,
   context ladder selection rules, and all telemetry fields.
6. Extend manifest validation so missing hashes, expected answers, MTP placement, pager ledger, or timing
   fields fail the applicable run rather than becoming zero.

## Tests and acceptance

- Corpus generator/checker is deterministic across two runs and rejects altered prompts/answers.
- Calibration and held-out inputs have no duplicate hashes or accidental answer leakage.
- Dry-run manifests validate; malformed/missing telemetry and wrong model/tokenizer hashes fail.
- Existing historical result parsing remains supported and clearly labeled legacy/non-acceptance.
- No selective result or observed output is used to set thresholds.

## Deliverable

Create `handoffs/08-04.md` with corpus paths/hashes/counts, frozen gates, schema version, commands, and
operator restoration procedure. Do not copy large/raw corpus payloads into upstream-bound code commits.
