context, while preserving legacy behavior under `auto`. Keep this generic seam separable for
`vanwho/llama.cpp`; document and verify Turbo4 draft K/V in Buun.

## Contract to freeze first

- Preferred experimental spelling: `--spec-draft-kv-device auto|gpu|cpu`.
- `auto` exactly preserves legacy derived placement.
- `gpu` independently enables draft KQV/KV offload and fails clearly if no requested GPU backend can
  satisfy it; it does not silently move model weights or target K/V.
- `cpu` independently disables draft KQV/KV offload; it does not change target placement.
- Explicit draft placement wins over copied target `no_kv_offload` state.
- The normalized tri-state is carried once through common parameters and is applied to both external
  draft and native MTP context parameters before context construction and fit/accounting.

If current naming conventions materially favor an `auto|on|off` option, record the evidence in the
handoff before choosing it. Do not add both public switches.

## Implementation steps

1. In the prepared `llama.cpp-kv-pager` worktree, add the tri-state parameter, parser validation, help
   text, and configuration serialization where existing speculative options live.
2. Centralize the conversion from tri-state plus legacy target setting to the draft
   `llama_context_params::offload_kqv` value; do not duplicate policy in server and CLI paths.
3. Apply it to external speculative model construction and native MTP construction.
4. Update fit/cache-placement diagnostics so logs distinguish target and draft K/V devices.
5. Port/adapt the same semantic contract into Buun without overwriting Buun-specific speculative/VBR
   changes. Verify `-ctkd t4 -ctvd t4` and all existing Turbo4 aliases remain accepted for MTP; update stale
   generated option/type documentation through the repository workflow.
6. Keep the generic llama.cpp logical change isolated from Buun-only Turbo4 documentation/test deltas
   and record base/tip SHAs plus a range-diff or file/hunk correspondence between the two forks.
