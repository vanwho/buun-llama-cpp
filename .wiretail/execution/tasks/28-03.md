## Exact edits
1. Adapt the mature Turbo4 vector loader/scheduling to the device page descriptor.
   Resolve source slot + row-in-page + layer/head strides ONCE per KV tile.
   Preserve existing codebook/channel scaling, Q WHT and V unrotation domain.
   Do not retain the old loop with two block barriers for each KV row.
2. CUDA decode specialization Q1 and smallQ2/3: parallelize KV rows and output
   dimensions; share loads across query heads with the same KV head. For the
   scalar dot-product piece sum the lane's products before warp reduction,
   not five shuffles separately for every one of eight dimensions.
   Use the established online-softmax/tile accumulator and split merge.
3. Choose cooperative vector versus existing small-query/GQA fused MMA based
   on actual geometry/timings. Fold query and GQA dimensions into effective
   work when legal. Keep splits bounded by active work/SM occupancy; do not
   allocate one huge split result per logical page just because L grew.
4. Decode Turbo4 tiles in registers/shared memory, never materialize all H/L
   F16. Workspace depends on A and query-shape capacity, not occupied C.
   Direct output for unsplit small workloads avoids needless merge launch.
5. Replace automatic scalar direct dispatch for supported target geometry.
   Keep repaired scalar kernel reachable explicitly by tests as reference.
   No unsupported production shape silently returns to CPU or slow row loop.
6. CUDA fixture Q1/2/3, all selected gaps/tails/permutations/GQA/masks and
   all-masked row. Compare same selected-set output with reference. Separate
   kernel timing from selection and movement. Profile register spill/occupancy
   once with ncu if time fails to improve; do not guess from instruction count.
7. Live primary native MTP q0 at fixed C/A/H,128 committed outputs when possible.
   Verify target verification actually invokes the intended small-query path;
   distinguish draft generation cost. Use matched old/new timings.

## Completion
Production no longer uses the serial paged reference kernel for supported
decode/verification. Same-selected-set correctness, small live result and
quantified kernel+end-to-end timing are required. If a mature vector path wins
over new MMA, retain vector; the goal is latency, not a tensor-core counter.
