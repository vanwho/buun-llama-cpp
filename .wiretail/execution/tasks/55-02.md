# 55-02 — Revalidate full-L progress and the matched hot-path matrix

Revision: `hotpath-v10-20260914`. Cluster: `55b-bounded-revalidation-v10`.
Model: Luna Medium; first retry High. Prerequisite:55-01.

## Objective

Measure the repaired candidate after the resource boundary is green. This is
a bounded revalidation, not a broad scale loop.

## Exact harness contract and hypothesis

Use the existing V10 server/profile benchmark and production-chain fixture;
do not create a new runner. Hypothesis: once the pre-submit resource owners
are correct, the candidate will complete the smallest full-L request and the
previously deferred speed rows can be compared without mixing startup with
occupied context or treating controls as native-MTP proof.

## Minimal fixtures, invariants, and numerical discriminator

First run the exact `L262144/H30208/B128/U128` 1200-token request and record
actual C, H, A, bytes, target/draft placement, and request-scoped MTP deltas.
Then run the original q0/q1/q2 prompts at
`L8192/C6144/H4096/A2048/B128/U128`, one warmup plus three measured trials for
selective, CPU-main-KV/GPU-draft, and all-GPU/GPU-draft modes. Run cached
append probes for 64 and 256 new tokens and committed decode, with the exact
same prefix/tokenization/template/sampling state.

The phase-53 baseline is full-L `C=0`, no matched revalidation rows, and
append/decode revalidation `not_run`. The after discriminator is one successful
full-L request with `C>0`; 27 matched q/mode/trial rows, both append probes,
and committed decode rows present; every native-MTP row has
`draft_delta>0`, `0 <= accepted_delta <= draft_delta`, and the computed
acceptance percentage. Keep failed/not-run rows explicit if a stop condition
fires. Physical promotion requires completed H2D, publication, and target
graph use of the cold logical page; answer correctness is recorded separately.

## Stop condition and proof

Stop before scale if candidate identity/placement is invalid, the full-L
request regresses, the production cold chain regresses, or any native-MTP
counter is missing. Do not infer C from launcher context, infer acceptance
from startup, or fill missing controls with null-to-zero conversions. Raw data
belongs under `/srv/ai/paged-kv/results/v10/55-02/<UTC-run-id>/`. Required
proofs are `full_l_request_progress` and `matched_three_prompt_matrix`.
