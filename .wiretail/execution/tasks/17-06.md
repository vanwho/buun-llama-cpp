# 17-06 — Build a fact-bearing multi-page benchmark corpus

## Objective

Create a new immutable corpus whose prompts contain the facts they ask the
model to retrieve and whose tokenized lengths actually exercise multiple KV
pages and declared distances.

## Read

- Cluster `17c-corpus-exact`, handoff 17-05, the corpus generator/validator,
  current V2/V3 corpus evidence, and the pinned Qwen3.8 tokenizer/model facts.

## Work

1. Generate a new corpus version; never mutate the recorded V2 corpus in place.
2. Embed deterministic category fixtures, expected answers, and real padding in
   each prompt. Place early/middle/end needles at measured page distances,
   include tails, focus shifts, churn, and partition separation.
3. Validate token lengths with the target tokenizer, fact presence, answer
   reachability, unique stable hashes, and model/tokenizer provenance.
4. Keep calibration and held-out construction identical except for partition
   identity; do not append misleading held-out suffixes.

## Acceptance

Run semantic validation and a dense-control probe for every case. Stop before
pager tuning if dense control cannot answer the embedded facts. Preserve raw
prompts/responses and hashes outside Git, with only summaries and pointers in
the handoff.

## Deliverable

Create `handoffs/17-06.md`, the versioned corpus/validator changes, and raw
dense-control evidence.
