# 11-01 — Produce production routing summaries for every sealed page

## Objective

Generate and maintain compact all-page routing metadata from live target K/V so cold pages remain
discoverable without scanning or transferring full K/V.

## Read

- Task README, cluster `11a-live-routing`, plan 8.6 and 23.
- Handoffs 04-01, 08-04, 09-03–09-04, 10-05.
- Routing-summary API/tests, Turbo4 decode helpers, RoPE/position treatment, seal/catalog lifecycle,
  frozen calibration corpus and exact/dense attention evidence.

## Implementation

1. At page seal or safe update, produce a runtime-geometry summary keyed by full page identity and valid
   rows. Avoid re-reading the full page per decode token.
2. Implement the existing representative/rotated-key design as baseline, then add only bounded candidate
   forms needed for calibration (for example centroid plus norm/upper bound or a small multi-vector set).
3. Preserve layer/head information needed for query scoring while minimizing bytes. Document whether
   summaries are computed on GPU or CPU and why; transfers must be bounded and measured.
4. Store summaries for all sealed logical pages in host/controller or bounded device memory. Invalidate on
   mutation, representation/topology/model/session change; tails update only when their valid range changes.
5. Add summary bytes/build time/version/hash counters and prompt artifact compatibility checks.

## Tests and calibration capture

Known synthetic keys/queries, rotated positions, full/tail pages, repeated positions, stale/corrupt
summary, mutation/reseal, artifact restore, and varying runtime `L`. On calibration prompts, compare each
summary candidate's top-page recall and upper-bound behavior against dense/exact attention rankings.

## Acceptance

Every sealed live page has a valid bounded summary; cold pages remain queryable; summary creation is not
on every decode token; identity invalidation is correct; raw accuracy/bytes/time results select candidates
for 11-02 without touching held-out data.

## Deliverable

Create `handoffs/11-01.md` with summary formats, ownership, candidates, calibration table, counters, tests,
and raw paths.
