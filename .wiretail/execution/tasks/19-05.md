## Ordered implementation / experiment

1. Implement bounded query-tile prefill using compressed page descriptors; bound scratch by query tile and resident/wave width, not full 262K history.

2. Handle prompt chunks crossing physical slots, query-local causal masks, existing history, partial tails and native MTP prompt processing. Preserve exact logical positions across ubatches.

3. Use the direct kernel for supported tiles; any fallback expansion must fit the same budget and be visible in telemetry. Diagnostic reference may remain slow but cannot allocate full-context F16 scratch.

4. Initially prove all-fit dense parity and fixed-page selective prefill only. Label selective-prefill approximation explicitly; full-history exact prefill is completed in 19-06.

5. Benchmark multiple ubatch/query tile sizes with reserved compute memory and MTP enabled; choose safe defaults from evidence, never hardcode a server GPU or former hotset.

6. Persist prefill progress counters so long clients distinguish healthy processing from hangs.

## Concrete execution recipe

Read `EXECUTION_COOKBOOK.md` sections C1/C3/C4/C5 and `IMPLEMENTATION_CONTRACTS.md` sections I2/I3. These are shared context; reuse them within the cluster.

Start with one small prefill tile spanning a page boundary and an existing
history prefix. Reuse the multiquery contract from 19-04, translating each
K/V tile row through its page descriptor and physical slot. Keep causal native
positions separate from compact row index.

Apply page-aware addressing to the existing Turbo4 tile/MMA loader where it
is compatible. Test an all-selected small tile before varying tile/ubatch size;
compare outputs to both dense and the diagnostic serial kernel. A query tile
must not include future rows just because they occupy the same physical page.
Pending write pages and scratch must fit admission before graph submission.

Export a prefill capability table and shape-dependent scratch formula, actual
direct/reference dispatch counts, and a two-length progress/time example.
Selective prefill is labeled approximate. Exact prefill is 19-06, so this task
must not claim full-history equivalence for deliberately omitted rows.
