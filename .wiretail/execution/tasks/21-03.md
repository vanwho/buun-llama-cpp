# 21-03 — Make cold-page promotion and selective routing correct

Recommended model: **Luna High**. Phase 21; cluster `21a-quality-curve`.
Depends on: `21-02`.

## Objective

Ensure selective attention can answer a fact stored in a nonresident logical
page while keeping the complete Turbo4 target KV canonical in host RAM and the
hot subset in VRAM. The four-page run showed no useful H2D/fault evidence and
returned anchor text instead of cold facts.

## Implementation

1. Trace `llama_kv_pager` admission, `apply_live_policy`, host sealing,
   promotion, eviction, and `selected_attention_*` calls for one sequence.
   Verify that every committed row is host-valid before it can be evicted and
   that a promoted page has a matching physical slot, generation, and CUDA
   fence.
2. Make automatic hot capacity derive from the actual VRAM ledger after model,
   workspace, and GPU Turbo4 MTP reservations. Expose requested, admitted,
   resident, and host-backed bytes. A user page cap remains an explicit test
   cap and is never silently substituted for `auto`.
3. Ensure the selector can request a cold logical page from attention telemetry
   (including early, middle, late, and multi-hop needles), schedules H2D from
   canonical host storage, waits on the event only where needed, and includes
   the page in the same causal attention operation. Preserve pinned/recent
   pages and avoid evicting pages still referenced by an in-flight graph.
4. Keep exact mode as a correctness oracle and selected-all as an all-fit
   control. Selective mode may be approximate only when the receipt explicitly
   lists omitted pages; it must not silently fall back to the system anchor.
5. Add telemetry fields and tests for host-valid rows, selected page IDs,
   H2D useful/actual bytes, D2H seal bytes, faults, evictions, stale-transfer
   cancellation, route, and wait/queue/copy time. Missing telemetry is a
   failed capability, not a zero counter.
6. Add deterministic tests for cold promotion, clean eviction, dirty seal,
   cancellation, page-generation reuse, logical gaps, tail pages, and exact
   parity. Run one live cold-needle probe at a budget-derived hot capacity.

## Acceptance

The probe retrieves a known cold fact with canonical host bytes and records a
real promotion or an explicit, explained no-promotion path. No use-after-free,
stale generation, or answer corruption is allowed. Produce
`handoffs/21-03.md` and `evidence/PHASE21_RESIDENCY.json/.md`.

## Validation

Run focused pager/residency/CUDA tests, the one minimized live probe, state
validation, and `git diff --check`. Keep target and draft K/V Turbo4 and MTP
GPU-resident. Do not launch the full corpus or speed curve here.
