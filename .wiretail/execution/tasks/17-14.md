# 17-14 — Repair exact/native and concurrent response oracles

## Objective

Remove the exact/native HTTP 500 and make concurrent correctness evidence
deterministic before rerunning quality or performance acceptance.

## Read

- Cluster `17g-quality-oracles`, handoff 17-13, exact attention callbacks,
  native-MTP rollback paths, concurrent soak raw responses, and focused tests.

## Work

1. Before any long corpus loop, run a bounded resolved-context startup probe
   with target Turbo4 and native Turbo4/GPU draft KV. If the server exits after
   `model loaded`/`listening`, classify it as a runtime crash and stop the
   probe; do not reinterpret it as missing pager telemetry or spend the full
   benchmark budget retrying an unstable service.
2. Capture the kernel/systemd crash record and, where available, a debugger,
   sanitizer, or core backtrace. Isolate the smallest trigger by toggling only
   one lifecycle feature at a time (pager mode, MTP, unified KV, cache/checkpoint
   options, and request handling), while retaining Turbo4 requirements for any
   candidate acceptance configuration. Record whether the failure is before or
   after the request-to-transfer boundary.
3. Reproduce the exact/native HTTP 500 at the resolved corpus context and
   isolate whether it is geometry, page inventory, transfer fencing, online
   softmax, or response serialization. If startup remains unstable, preserve a
   deterministic refusal and defer live exact/native execution rather than
   claiming a correctness result.
4. Repair the smallest generic boundary and add a regression for the failing
   geometry/tail/host-page or startup configuration combination.
5. Make concurrent requests use independent slots/markers and distinguish
   transport success, server semantic errors, and exact-marker correctness.
6. Preserve full request/response/error evidence; do not treat HTTP 200 with an
   error payload as a pass. Restoration must be bounded, identity-aware, and
   must quiesce a `Restart=always` crash loop before waiting for the prior
   profile.

## Acceptance

Exact/native returns a usable reference or an explicit supported refusal with
focused coverage; concurrent requests have deterministic isolated outputs, or
the remaining blocker is machine-readable and reproducible.

## Deliverable

Create `handoffs/17-14.md`, portable fixes/tests, and raw oracle evidence.
