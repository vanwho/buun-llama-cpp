# 17-14 — Repair exact/native and concurrent response oracles

## Objective

Remove the exact/native HTTP 500 and make concurrent correctness evidence
deterministic before rerunning quality or performance acceptance.

## Read

- Cluster `17g-quality-oracles`, handoff 17-13, exact attention callbacks,
  native-MTP rollback paths, concurrent soak raw responses, and focused tests.

## Work

1. Reproduce the exact/native failure at the resolved corpus context and
   isolate whether it is geometry, page inventory, transfer fencing, online
   softmax, or response serialization.
2. Repair the smallest generic boundary and add a regression for the failing
   geometry/tail/host-page combination.
3. Make concurrent requests use independent slots/markers and distinguish
   transport success, server semantic errors, and exact-marker correctness.
4. Preserve full request/response/error evidence; do not treat HTTP 200 with an
   error payload as a pass.

## Acceptance

Exact/native returns a usable reference or an explicit supported refusal with
focused coverage; concurrent requests have deterministic isolated outputs, or
the remaining blocker is machine-readable and reproducible.

## Deliverable

Create `handoffs/17-14.md`, portable fixes/tests, and raw oracle evidence.
