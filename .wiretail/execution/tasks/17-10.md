# 17-10 — Produce phase-17 soak and lifecycle evidence

## Objective

Demonstrate that the measured pager+MTP configuration remains correct and
bounded under long conversations and lifecycle stress.

## Read

- Cluster `17e-benchmark-soak`, handoff 17-09, lifecycle/rollback tests, and
  the soak contract.

## Work

Run repeated long-context requests, page churn, focus shifts, speculative
  rejection, cancellation, slot reuse, checkpoint save/restore, clear,
  restart, concurrent request isolation, and resource sampling. Verify no
  monotonic host/pinned/device/event/page-table growth, stale completion,
  corruption, deadlock, or health loss. Keep the successful tested profile
  loaded after success; restore only for an explicit control or failed-start
  recovery.

## Acceptance

Retain raw timelines and request records, before/after identities, health, and
all counters. A control soak cannot substitute for a pager soak. Mark each
sub-gate pass or block without hiding faults.

## Deliverable

Create `handoffs/17-10.md`, `PHASE17_SOAK.json/.md`, and raw endurance results.
