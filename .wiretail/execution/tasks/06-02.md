# 06-02 — Complete CUDA correctness and fault matrix

## Objective

Prove Turbo4 selected/paged attention, transfers, and graph lifecycle on the reference CUDA system.

## Read

- Task README; plan section 12.2–12.3; CPU matrix; Phase 03–05 handoffs.
- Build instructions and existing CUDA/backend test conventions.

## Work

- Build from a cleanly recorded SHA/config for RTX 4080 sm_89.
- Run dense Turbo4, compact gather, and direct paged comparisons for one/tail/304/permuted/gapped pages.
- Cover GQA=4, width 256, decode and supported prefill shapes, score reduction on/off, and graph epoch
  reuse/rebuild.
- Exercise D2H/H2D, cancellation, reordering, stale completion, host corruption, VRAM denial, ring
  exhaustion, all-pinned, clear/teardown, recurrent operations, MTP acceptance/rejection/checkpoint.
- Run compute-sanitizer on bounded fixtures and capture compiler/kernel resource information.

## Acceptance

- Add `.wiretail/execution/evidence/CUDA_TEST_MATRIX.md` with raw log paths, tolerances, outputs, GPU/driver,
  build SHA/options, and every failure disposition.
- No sanitizer error, corruption, stale publication, hidden F16 full-cache buffer, or unexplained output
  difference.
- If the required GPU is unavailable, block this task. Do not defer release correctness.
