## Ordered implementation / experiment

1. Freeze calibration/held-out case IDs and provenance. Adjudicate dense-control failures from rendered fact-bearing prompts and answers; corrections create a new corpus version and new controls.

2. Compare exact-prefill+selective-decode with selective-prefill+selective-decode on identical histories. Explain that later page retrieval cannot repair KV already computed under a different approximate prefix.

3. Measure recent-only, query retrieval, query+retention, exploration, optional layer-group budgets and confidence fallback. Change one variable at a time with the same hot-byte cap and MTP settings.

4. Use distant/multiple facts, focus shifts, repository dependencies and multi-hop queries at increasing occupied lengths, with raw gold fact locations. Don't tune to held-out answers.

5. Select a conservative default on a documented quality/latency/memory Pareto curve; retain faster lower-quality settings as explicitly labeled options only.

6. Persist policy config, selected mass/recall, answer score, logit or perplexity deltas where valid, and costs including prefill. Record unresolved fundamental-quality failures as implementation work, not a cosmetic threshold adjustment.
