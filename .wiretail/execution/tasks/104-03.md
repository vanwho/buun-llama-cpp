## Implementation recipe

1. Add separate GGML_OP_KV_PAGE_RANK / ggml_kv_page_rank; legacy selector
   opcode/API/type remains identical. Inputs use existing summary,
   metadata/membership/query plus independent probes [D,Qheads,n_valid].
   Output I64 [2,resident_width+cold_shortlist_width] holds the16-byte record
   from104-01. Params carry checked widths/page-size/probe mask/attention scale;
   do not overload legacy scorer_mode1 without a distinct op/shape gate.
2. CUDA score work tiles page/head/probe; calculate Mean-K and sign-aware
   min/max estimates on the same coefficient representation. Normalize each
   source per head/probe over eligible pages using stable max-subtracted
   softmax; do not multiply different layer raw logits together. Causal/stale/
   absent/summary-not-ready pages remain ineligible. Positive-infinite range
   bounds receive deterministic finite ranking treatment (equal probability
   among +inf values), invalid NaN never wins. Zero query coordinate must
   not cause 0*inf. Reuse existing outward bound conventions.
3. Derive K=min(cold_count,max(8,min(32,ceil(H_pages/4)))) with checked counts.
   For each score source page strength is max probability across probes/heads,
   then mean probability as tie-break. Take ceil(K/2) from each source,
   deduplicate logical IDs, continue rankings alternately to fill K. Stable
   logical-ID ties. Keep actual normalized scores in output; rank remains
   diagnostic only. This shortlist is not a permission to promote K pages.
4. Reuse existing CUB sorting workspace, allocating bounded workspace once
   per owner. Score one attention layer at a time, tile if matrix+sort scratch
   exceeds2MiB. No malloc/free per page/head and no host sorting of full-L
   score matrices. No extra catalogue or subblock representation in this task.
5. Add packed-record expansion next to shared ID expansion, with a snapshot
   before aliasing writes. Extend segment descriptor with explicit format and
   byte count/stride; checked bytes=records*16, not records*4. Keep logical-ID
   indexing and immutable identity/content/generation authentication. Mailbox
   size must derive resident_width+K per layer and maximum expansion byte size;
   preserve late-layer IDs beyond128/200. Never copy probabilities through an
   int pointer or infer their value from rank. Legacy5-ID sizing stays legacy.
6. Add peak/mean score provenance to `llama_kv_prefetch_candidate` after its
   existing aggregate prefix, including score kind so rank/softmax/exact-mass
   values cannot be combined accidentally. Both async and sync paths decode
   the new record through the shared helper. No cross-layer policy switch yet;
  104-05 consumes finalized rerank results. Source flags isolate this partial
   path until rerank is implemented; reject unsupported opt-in before inference.
