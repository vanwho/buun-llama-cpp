## Required math and implementation

The catalogue currently bounds stored quantized coefficients (including the
row norm), not inverse-rotated original K. At the callback Q is post-RoPE but
not yet in the Turbo4 coefficient domain. A dot product across these domains
is not the intended query-aware score.

1. Write the actual mature-FA K reconstruction as a linear transform of
   stored dequantized coefficients. Derive its transpose acting on Q. For the
   orthogonal FWHT/sign transform without nonunit calibration this is the
   corresponding forward WHT/sign Q; when inverse channel scales are active,
   apply those in the mathematically matching order. Reuse repository
   `ggml_turbo_wht`/codebook/scale sources; no independently guessed constants.
   Preserve any nonunit normalization explicitly. Store transform/codec
   identity with summary metadata so a mismatched calibration invalidates it.
2. Add a router-only graph node to transform the authorized Q slice to the
   coefficient basis. Never mutate/double-transform Q used by mature target
   FA. Select first causal query of a prefill/verification microbatch initially;
   a later future query must not decide history for earlier rows. Ordinary
   decode and MTP n_q>1 need explicit tests. Keep D and GQA grouping derived
   from actual dimensions; no assumptions about head0 or exactly16 layers.
3. Bound score is sum_d q[d]*(q[d]>=0?max[d]:min[d]) for each query head,
   using its GQA-mapped KV head's bounds; page score is the maximum over
   query heads (preserve the current kernel's rule, no averaging change).
   Use fp32 accumulation; finite validity
   checks; deterministic score-desc/logical-id-asc ties. Half bounds must
   round minima downward and maxima upward, not nearest into the interval.
4. Make CPU selector reference use the same defined basis and grouping. It
   is a test/reference implementation, not a per-token CPU fallback. Keep
   missing/nonfinite Q separate from empty eligible inventory errors.

documented floating tolerance; bound remains conservative for every stored
row. Reference must use actual Turbo4 pack/unpack, not original unquantized K.

ties, invalid floats, n_q1/2/3/64/128 and causal gaps. The production graph's
target-FA Q must be numerically unchanged by enabling router capture.
