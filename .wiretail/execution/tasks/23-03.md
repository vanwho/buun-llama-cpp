# 23-03 — Remove the live Qwen selected-reference prefill bottleneck

Recommended model: **Luna High**. Phase 23; cluster `23a-runtime-repair`.
Depends on: `23-02`.

## Measured gap and hypothesis

Phase 21 already replaced the three-token tile workaround with 16-token CUDA
fixtures, but the live Qwen run still used `selected_reference`; 8K timed out and
20K/262K advanced too slowly to measure. Do not repeat tile-size work.
Hypothesis: an observed Qwen geometry/verification condition still disqualifies
the direct Turbo4 route, while the fallback rebuilds and synchronizes graphs per
page wave. Owner: `llama_context::prepare_kv_attention_graph`, direct-route
eligibility/reason reporting, graph keys, and the paged Turbo4 dispatcher.

## Minimal reproducer and implementation

1. On one immutable binary, profile identical 4K and 8K prompts in off, observe,
   forced selected-reference, and eligible selected-direct modes. Record the
   exact fallback reason, query tile/shape, route, graph rebuild/replay counts,
   launches, synchronizations, kernel/copy/wait time and prompt throughput.
2. Change one measured cause: extend direct support for the actual Qwen
   multiquery/prefill geometry when dense/selected-all numerical fixtures pass;
   if geometry is already supported, make content-only page-table changes reuse
   stable descriptors/graphs and remove redundant fallback synchronization.
3. Test 1/3/16/32-query tiles, GQA heads, causal masks, gaps, tails, page
   permutation, M-RoPE coordinates, canaries and MTP verification. Unsupported
   cases retain an explicit bounded fallback and reason.
4. Repeat the 4K/8K comparison, then a single progress-aware 20K warmup. Do not
   launch the final curve here.

## Measurement change and deliverables

The live route must be direct or the remaining bounded fallback must have a
measured causal profile; graph/sync counts must be wave-bounded and parity must
hold. Report before/after prompt rate as a finding, not a pass threshold. Produce
`handoffs/23-03.md` and `evidence/PHASE23_PREFILL.json/.md`, focused CUDA/tests,
state validation and `git diff --check`.
