# 11-03 — Publish live GPU-reduced per-page attention telemetry

## Objective

Collect bounded post-attention evidence from real Qwen layers/heads and feed retention without transferring
attention matrices or changing outputs.

## Read

- Task README, cluster `11a-live-routing`, plan 8.7 and 23.
- Handoffs 04-02, 10-02–10-03, 11-01–11-02.
- Direct/reference attention outputs, page-mass CUDA reduction, telemetry controller, graph events,
  server metrics and calibration traces.

## Implementation

1. Emit page mass or selected retention statistics during/adjacent to attention on GPU. Prove enabling
   reduction does not alter normalized output.
2. Aggregate configured layers/heads/tokens using bounded device buffers. Copy only page-level vectors to
   CPU/controller after the producing event; dynamically size to `L` or participating pages.
3. Validate table/page/session/sequence/representation generations before publishing. Drop stale samples
   and count them.
4. Update EMA, recent peak, frequency and normalization only for observed participating pages. Preserve
   unknown state for unobserved cold pages.
5. Make cadence and layer/head sampling configurable/auto; record GPU reduction, D2H bytes/time, publish
   time, samples, skipped/stale counts, and total observe overhead.

## Tests and benchmark

Reduction on/off equality, known mass bins, layer/head aggregation, changing selected sets, dynamic `L`,
sample cadence, stale events, cancellation, table rebuild, exact/reference/direct routes, and feature-off.
Run at least five dense/observe and selected telemetry trials on calibration inputs; report overhead and
captured-mass consistency.

## Acceptance

Live telemetry reaches controller with real generations; no attention matrix crosses to CPU; outputs are
unchanged; stale data cannot update state; observe overhead meets the frozen checkpoint budget or has a
profiled repair plan for phase 13.

## Deliverable

Create `handoffs/11-03.md` and telemetry checkpoint JSON/markdown with raw paths and overhead breakdown.
