# 10-01 — Wire selected-all-pages reference attention into the live Qwen graph

## Objective

Make the real target graph consume compact page views through the correctness-first selected reference
route while selecting every logical page that fits. Establish a live parity oracle before sparse routing.

## Read

- Task README, cluster `10a-live-decode`, plan 8.5, 9.4, 22 step 6.
- Handoffs 03-01, 03-02, 03-04, 09-02–09-05.
- Qwen model graph builders and attention nodes, memory interface, selected view/operator/execution,
  masks/positions, graph allocator/capture and current dense Turbo4 path.

## Implementation

1. At each supported full-attention layer, build selected metadata from the immutable live residency table
   and compact K/V buffers. Preserve native query/KV positions and causal mask.
2. Add the selected reference operation to actual graph construction/evaluation. It may use a bounded
   gather or reference operator only within selected physical rows; it must never allocate for full `C`.
3. Select all logical pages for contexts where `L <= H`; page order must remain arbitrary and tails valid.
4. Fence table/page lifetime through scheduler completion. Include route/table/representation/shape in
   graph reuse keys and invalidate safely.
5. Produce layer/route diagnostics and memory accounting. `off` remains the untouched dense graph.

## Tests and model evidence

CPU/reference metadata tests plus live CUDA Qwen runs at small all-pages-fit contexts. Compare dense and
selected reference per-layer outputs or final logits, greedy tokens, and MTP acceptance with frozen
tolerances. Test permuted slots, gaps after mutation, odd tails, page-table change, graph reuse/rebuild,
cancel/teardown, and unsupported refusal.

## Acceptance

The production graph demonstrably calls the selected reference route at all supported target attention
layers; selected-all-pages matches dense; target graph/scratch allocation scales with selected rows; no
full-context F16 gather is present.

## Recovery

If graph operators require contiguous tensors, first implement a bounded selected-row tensor view owned
by the pager and prove its allocation size. Do not restore logical-frontier dimensions or skip parity.
