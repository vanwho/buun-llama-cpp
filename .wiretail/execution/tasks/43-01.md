# 43-01 — Repair the selected-packed current-Q producer boundary

Revision: `hotpath-v9-20260914-r2`. Cluster: `43a-current-q-producer-v9`.
Model: **Luna High**; first retry **Luna High**, same family.

## Objective

Resolve the distinct producer-side failure left after phase 41: the live
selected-packed graph completes, but no production page-mass result reaches
the existing publication boundary. Trace the actual selected-packed graph
result and connect its valid current-Q page-mass producer to the already
captured snapshot/page identity. Keep publication after the scheduler fence,
retain precise drop accounting for every rejected event, and do not synthesize
samples or replace the production path with the superseded direct kernel.

## Required symbols and invariant

Audit and, where necessary, repair `llm_graph_context::build_attn_inp_kv`,
`llm_graph_input_attn_kv::refresh_direct_telemetry`,
`llama_context::publish_kv_attention_telemetry`, and
`llama_kv_attention_telemetry::publish_completed`, including the hybrid child
lookup that owns the live attention input. For every completed eligible
selected-packed query, one valid result must carry the same snapshot epoch,
page generations, query index, and page list into publication; a missing,
stale, malformed, or unavailable result must produce its exact drop reason.
Preserve `selected <= A_by_layer <= H <= L`, target/draft Turbo4, GPU draft,
native MTP, and the full-L production route.

## Fixture, before/after test, and stop condition

Before the change, run the focused telemetry/execution fixtures and record the
live producer, graph-input, and publication/drop counters reproducing zero
current-Q samples. After the change, run `test-kv-attention-telemetry`,
`test-kv-attention-execution`, and the available model-free pager checks, then
the smallest CUDA C>H natural-recall smoke if the build is available. Stop at
this boundary without scale if the smoke still has zero real samples or no
non-sentinel candidate; report the first missing producer/route/lifetime edge
and do not paper over it with forced transfer.
