# 21-09 — Exercise bounded paging pressure and lifecycle

Recommended model: **Luna High**. Phase 21; cluster `21c-final-measurements`.
Depends on: `21-08`.

## Work

Run short, resumable segments: warm focus, known cold-page promotion, early /
middle / late focus shift, sustained churn, cancellation/drain, checkpoint
restore, restart, and slot reuse. Ensure occupied pages exceed the observed
hot capacity for pressure segments while preserving all-Turbo4 target and GPU
MTP placement.

For each cold segment correlate logical page ID, canonical host checksum,
H2D event/fence, physical slot/generation, selected route, answer, and
post-request counters. Distinguish clean D2H sealing from useful H2D promotion.
Sample host, pinned, VRAM, event, descriptor, page-table, and queue resources
before/high-water/after repeated equal-work cycles. Zero movement is a finding,
not proof of paging.

## Acceptance and deliverables

Create `handoffs/21-09.md` and `evidence/PHASE21_SOAK.json/.md`. Incomplete
segments are resumable and explicitly incomplete. HTTP health alone never
passes a segment; no unowned process or port 8092 may be touched.
