Revision: `hotpath-v10-20260914`. Cluster: `50b-hotpath-ownership-v10`.
Model: Luna High; first retry High. Prerequisite:50-03.

## Source and performance question

`src/llama-graph.cpp` packed `set_input`, content-version copies,
`build_attn_mha` and graph reuse keys; `src/llama-kv-attention-execution.*`
packed-cache find_or_create/graph owners; `src/llama-kv-cache.cpp` SET_ROWS,
seal/synchronize/input paths; mature CUDA Turbo4 FA dispatch. Phase36's
214tok/s vs1436tok/s prefill is the problem, not evidence PCIe must cost6.7x.

## Work in this order

1. Use one rebuilt-bundle q0 C6144 cold prefill and two cached128-token appends,
   not tiny short prompts. Sample categories: GEMM/FA, SET_ROWS/pack copies,
   routing summary+rank, H2D/D2H, CPU loops, scheduler waits, graph builds and
   allocations. Include one all-GPU same B/U/MTP diagnostic control. Attribute
   wall time without summing overlapping CUDA durations as serial time.
2. Remove residual O(L) or O(H) per-input CPU scans/copies. Dirty range/version
   updates are per changed page/current rows; selected workspace owner capacity
   is A, not H/L. Reuse per-layer descriptor vectors and allocations. Inventory
   introspection belongs to optional sampling, not all layer input callbacks.
3. Packed tensors remain stable across content changes. Copy newly admitted
   selected pages once; copy only changed current rows while preserving real
   graph dependency after K/V SET_ROWS. Avoid full A-page recopy for a tail
   token, and avoid duplicate pack of identical K/V rows. Content version is
   dirty metadata, not workspace/graph allocation key. Keep physical/native
   causal mappings valid for arbitrary selected logical gaps and GQA.
4. Use legal contiguous selected view when already in required order without
   copy. Otherwise mature compressed packed FA. Verify dispatcher on prefill,
   decode and MTP multiquery; no fallback to custom paged scalar/direct or
   giant temporary F16 due to a diagnostic flag. Keep49-04 graph assertion.
5. If current-row duplication dominates, fuse/redirect the existing write+
   packed-current scatter only with explicit graph dependency and49-06 output
   parity tests. Do not alias two live owners or turn off causal/current rows
   to get a fast benchmark. Prefer a bounded small CUDA row-update kernel over
   CPU synchronous tensor_get/set. Optimize the measured top categories first.
6. If mandatory current pages force A growth for a large U, bound microbatch
   at the proven legal frontier rather than rebuild A scratch on every row.
   Workloads with ordinary small appends must not allocate L-sized attention
   scratch. GDN/recurrent and full-L draft memory remain separately accounted.

## Tests and bounded before/after result

Extend packed workspace/current-row numerical tests: identical selected sets
compared with allresident reference for n_q1/2/3/64/128, partial tails,
permutations, GQA, MTP rejection and graph replay. Include numerical values,
not merely tensor shapes/dispatch strings. Run49-06 promotion consumption.
Record same q0 input bytes and observed cache_n, paired before/after pp,
cached append, decode, selected-copy bytes/new-row bytes, graph builds and
peak scratch. Traceoff production results must accompany diagnostic timing.
Keep beneficial changes isolated by commit. If a proposed fusion doesn't
improve relevant measured cost, do not retain it for theoretical elegance.
