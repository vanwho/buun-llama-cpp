## Ordered implementation / experiment

1. Wire the actual per-layer graph operation/callback sequence that can stage cold Turbo4 pages and merge attention partials. An inventory ledger or HTTP status change is not the implementation.

2. Iterate full logical page coverage in bounded waves per query tile/layer; merge unnormalized (m,l,o) with stable online-softmax rescaling, then normalize once. Treat empty/masked partitions safely.

3. Use a separately budgeted staging window and generation fences; avoid evicting mandatory hot/write/MTP state. Deduplicate coverage, preserve tail lengths/causal positions and never read unmapped rows.

4. Support both prompt prefill tiles and native-MTP verification, not only one all-resident decode token. CPU cold attention remains optional and is not required.

5. Expose exact partial-state/copy/coverage telemetry and verify every logical valid row participates exactly once.

6. Use exact prefill + selective decode as the conservative quality baseline; quantify its slower cold-load cost separately from decode speed.
