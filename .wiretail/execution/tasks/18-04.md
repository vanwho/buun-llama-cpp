## Ordered implementation / experiment

1. Build a field ownership/unit table. Separate requested/admitted/allocated/valid/selected values. Remove any overwrite of measured native-MTP context buffers by target admission estimates.

2. Expose actual target/draft K/V codec/backend, resolved per-sequence capacity, actual MTP rows/bytes, target resident and host valid pages/bytes, physical pool capacity and live allocation peak.

3. Report direct/reference/dense/exact route counts for prefill, single decode and MTP verification separately. Add emitted/predicted/accepted token counters, with an explicit acceptance denominator.

4. Connect queue/copy/wait and useful/aligned H2D/D2H counters to real operations. Unknown is null/reason, measured zero is zero. Do not populate counters from plans or units from similarly named byte values.

5. Snapshot atomically with request/slot/config generation and monotonic timestamps. Record metric reset semantics so deltas after restart are not negative or combined across processes.
