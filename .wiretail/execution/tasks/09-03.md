# 09-03 — Bind target KV writes, positions, and mutations to compact pages

## Objective

Make real target evaluation write Turbo4 K/V into pager physical slots while preserving logical positions,
partial-page rules, recurrent state, and every cache mutation operation.

## Read

- Task README, cluster `09a-live-memory`, plan 22 steps 2–3 and 7.
- Handoffs 02-01, 02-04, 03-01, 05-01, 05-03, 05-04, 09-02.
- Target KV store/update graph nodes, `llama_memory_i`, hybrid/recurrent memory, cell-position index,
  sequence mutation/copy/remove/keep/shift, checkpoint/prompt-cache paths, and tests.

## Implementation

1. Translate each logical write position to a current physical slot and row without exposing physical
   order as RoPE/causal position.
2. Reserve and pin the write page before graph submission. Initialize/clear reused slots safely and reject
   a write when no legal victim/free slot exists.
3. Track valid row runs for full and partial pages, repeated positions where supported, layer/K/V segment
   completion, mutation generation, and dirty state.
4. Seal only after every required segment and position has completed. A partial current page stays pinned,
   device-authoritative, and excluded from clean eviction.
5. Implement copy/remove/keep/shift/rewind/clear through a preflighted composite operation with recurrent
   and MTP companions. Invalidate or reseal affected host generations; never publish half a mutation.
6. Maintain ordinary target memory behavior in `off`; `observe` records identities without compacting.

## Tests

Single/multi-page writes, page boundary, one-row tail, odd tail, slot reuse, out-of-order graph completion,
duplicate/repeated positions, shift/copy/keep/remove, rewind, speculative reject, cancellation, prompt reuse,
checkpoint restore, stale generation, no victim, and feature-off. Use fake completion ordering and a CUDA
small-model/model-backed write fixture.

## Acceptance

Read back every written Turbo4 segment and logical position from compact slots; operations agree with the
dense reference; failed mutations leave the prior generation usable; no page seals early.
