provenance. Read only phase-17 implementation handoffs and the benchmark
contract. Preserve raw results outside Git and put hashes/pointers in compact
manifests. Dynamic context and measured hot capacity are inputs; never encode
the historical 77K estimate as a rule.

An oversized native-MTP context is not a terminal blocker. On CUDA allocation
failure, record the failure, stop the failed attempt through the managed
benchmark/profile harness with non-interactive `sudo -n`, and descend through
smaller contract-valid context values until a feasible Turbo4-MTP run is
obtained or the ladder is exhausted. Do not substitute a CPU-only run for the
CUDA evidence or block after one failed context.
