# 17-18 — Prove full 256K context capacity and residency

Archived unstarted packet, superseded 2026-09-05. See POST17_IMPLEMENTATION_STRATEGY.md
and the active WORK_STATE.json; do not execute this historical packet.

## Objective

Demonstrate that the stated 256K context can be opened and used with canonical
CPU-RAM Turbo4 target KV pages, a ledger-derived hot subset in VRAM, and fully
GPU-resident, context-sized Turbo4 MTP draft KV. Every target and draft KV
measurement in this task must remain Turbo4; no F16 or alternate codec path is
an acceptance substitute.

## Read

- Cluster `17i-full-context`, handoff 17-17, dynamic admission code, pager
  metrics, and current task state.

## Work

First run a bounded functional 262,144-token startup/prefill/retrieval/decode
smoke (or the configured model maximum if lower), recording admission, page
count, canonical host bytes, VRAM hot capacity, resident/host pages,
transfer/fault telemetry, and native Turbo4 MTP rows/bytes/types/placement.
Exercise early, middle, and tail sentinels. After the all-or-nothing smoke,
ramp the same Turbo4 configuration through approximately 20K, 40K, 60K, 100K,
175K, and 256K resolved contexts (adjusting to valid page/context boundaries)
and record startup success, usable capacity, prompt/decode speed, memory,
residency, and transfer counters. For every interval, reuse the original three
canonical benchmark prompts and the established warmup/trial/sampling protocol
so the curve is comparable to 17-16. These curve measurements are findings,
not speed gates, and must never become a fixed production hot-token rule. Do not
gather the cache into F16 or evict draft KV. If the 256K smoke fails, repair
the generic admission/allocator path or record a precise reproducible blocker;
a smaller context is diagnostic evidence only.

## Acceptance

The raw run proves either a usable 262,144-token Turbo4 target/draft context
with the required placements and telemetry, or a precise capacity blocker with
focused tests and an actionable remediation. It also contains the non-gating
context/speed curve. No smaller context may be reported as full-goal evidence.

## Deliverable

Create `handoffs/17-18.md` and a hashed raw full-context capacity/residency
result.
