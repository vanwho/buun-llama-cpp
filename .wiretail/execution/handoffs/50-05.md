## Measured choice

The bounded Qwen q0 ladder used the installed model, CUDA RTX 4080, `L=77824`,
6,144 prompt tokens, 128 output tokens, page size 256, selective pager, and
native GPU Turbo4 MTP. The selected candidate is `B128/U128/n_max=2`:

- cold: 32.87 s total, 3.21 s decode, 90 draft / 81 accepted;
- paired continuation: 32.71 s prefill, 3.21 s decode, 90 draft / 81 accepted;
- `B64/U64` and `B128/U64` both stayed near 247 draft / 2 accepted and had
  approximately 9.7 s decode;
- `n_max=1` reduced work to 125 draft / 1 accepted, so its shorter decode is
  not a fair MTP improvement.

The paired request observed an exact 6,144-token LCP, then the recurrent trim
was rejected and the server correctly reprocessed the prompt. This is retained
as a measured cached-append limitation, not represented as a cached-speed win;
no acceptance or rollback state was forced.

The measured ledger reported weights 13,695,600,000 bytes, fixed context
131,072, recurrent state 470,680,000, MTP compute 268,435,000, graph
268,435,000, MTP KV 82,313,200, packed workspace 510,394,000, catalogue
19,986,200, charged 16,206,500,000, usable device 16,720,200,000, and
201,327,000 bytes of headroom. Scratch high-water was 31,653,900 bytes after
warmup and verification. A is therefore left as the runtime scratch
reservation; no server-specific A default was added to portable code.
