# 09-04 handoff — sealed target pages to canonical Turbo4 host RAM

## Delivered

The live pager now owns a host-seal boundary backed by the existing selected-page
capture, bounded pinned ring, and host catalog contracts. A page remains
`gpu_dirty` until the complete-page D2H capture and catalog publication both
succeed; capture, budget, ring, and catalog failures restore the dirty state.
Duplicate publication aliases the existing authenticated page, while erase and
victim replacement invalidate the matching catalog key.

`llama_kv_cache::finish_pager_batch()` now reports the count of present runtime
K/V tensors rather than a fixed provisional layer count, and calls the seal pass
only after all successful tickets in the graph batch have completed.

## Segment layout and authentication

The cache provider enumerates the constructed runtime `layers[0..15].k/v`
Turbo4 tensors. For each of the 32 selected units it records the tensor's
actual `ne[0]`, `ne[1]`, row size, stream offset, backend/device binding, and
stable tensor source identity. A page maps its 256 logical positions to the
256 physical rows beginning at `physical_slot * page_tokens`. The transfer
copies opaque tensor bytes directly; it performs no dequantization or
requantization.

Page identity includes nonzero session, sequence, page-generation,
representation, model, topology, codec, codebook, rotation, and meansub
identity fields. Each unit snapshot binds lineage/controller generation,
Turbo4 representation generation, row geometry, topology digest, and the
canonical explicit-capture representation digest. The selected capture layer
authenticates every copied segment and streaming digest before catalog commit.

## Stream, event, and ownership rules

The pager host boundary creates one direction-neutral bounded ring. CUDA lanes
use the backend event path owned by the ring; the CPU fake lane uses synchronous
fallbacks. Ring capacity is charged once as `pinned_preimage_ring`; each
published page owns immutable pageable segment chains and descriptor metadata.
The ring is released before its accounting gauge is cleared, and the catalog
releases page charges on invalidation or teardown. No whole-store pinned backing
is enabled.
