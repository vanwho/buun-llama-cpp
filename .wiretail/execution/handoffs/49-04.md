# 49-04 handoff

Status: complete. Revision: `hotpath-v10-20260914`.

Implemented immutable selector submission ownership and removed the telemetry-
only attention pass from normal selected-packed graphs.

Implementation:

- `llama_kv_cache::pager_routing_output` now seals the exact ordered logical
  page identities, content/summary versions, session/sequence/rollback and
  query generations, query position, rank-region offsets/counts, head layout,
  and selector tensor owner. Returned indices are decoded only through this
  descriptor. Rank regions come from the built KV_PAGE_SELECT op parameters,
  including page inventories smaller than the configured attention budget.
- Mailbox submission is retained until the fixed slot is actually published;
  pending/ready work prevents duplicate refresh submission. Consumption
  ignores a global residency epoch change, while current mapping, session,
  sequence/page generations, query generation/position, and source
  content/summary versions are revalidated before policy publication.
- Resident selection is accumulated per layer. Cold candidates are deduplicated
  by stable bundle identity, ranked with `1/(1+rank)`, ordered by maximum
  priority, distinct nominating-layer count, then logical page, and bounded to
  two cold bundles. Mailbox capacity reserves room for cold bundles before
  resident candidates are written.
- Packed selected attention no longer allocates packed telemetry descriptors,
  refreshes packed telemetry, or emits `kv_packed_page_mass_producer`.
  Mature packed FA remains the normal packed consumer. Direct paged attention
  retains the explicitly diagnostic telemetry route.
- Added a real summary-content-version accessor on the pager and deterministic
  pending/completed, harmless-epoch, stale-generation, and two-slot lifecycle
  assertions to `test-kv-page-select`.
