# 25-08 handoff

## Result

Completed a real Qwen3.8-27B pressure proof. The deterministic driver selected
host-committed cold logical page 0 through the live policy and residency
transaction path, evicted one page, promoted one page to physical slot 7, and
verified host/device byte identity after 96 H2D completion events. A complete
real server request also returned HTTP 200 at pressure with bounded H=8 storage
and positive H2D movement.

## Implementation

- `src/llama-context.cpp` and `src/llama-kv-attention-view.cpp`: admit
  `sealing_host` as GPU-resident for selected attention while async host
  publication is in flight.
- `src/llama-kv-cache.cpp`: treat only the active write-frontier page as
  structurally current, allowing sealed GPU pages to be victims; add a
  conservative query-less cold-host fallback and reset it at cache clear; add
  the opt-in forced-page promotion seam.
- `src/llama-kv-pager-config.h`, `src/llama-kv-pager.h/.cpp`: carry the
  disabled-by-default test page, expose post-event host/device checksums and
  physical page identity for the driver receipt.
- `common/arg.cpp`: add internal `--kv-test-force-page N` probe option.
- `tests/test-kv-pager-model.cpp`: chunk real prompts by `n_batch`, support
  fixed decode, emit transfer/slot/checksum metrics, and make forced pressure
  mode pass only with positive promotion/H2D plus equal checksums.
