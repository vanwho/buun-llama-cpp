# Handoff — task 15-04

## Result

Implemented dynamic native-MTP placement and pager admission. Native MTP now
reserves its resolved target-sized Turbo4 K/V payload before target hot pages
are admitted, using allocator-shaped row geometry and the existing alignment,
scratch, routing/staging, guard, and headroom ledger. An absent MTP layer does
not create a phantom reservation. Unsupported native MTP cache geometry is
refused explicitly.

The fit contract now carries a required terminal GPU-layer count for native MTP
and rejects explicit or fitted placements that would leave the MTP block on the
host. Native MTP also refuses CPU/non-offloaded draft K/V configuration instead
of silently accepting a non-GPU draft cache.
