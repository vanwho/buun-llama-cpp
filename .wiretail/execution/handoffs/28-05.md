# 28-05 handoff - layer-granular residency and canonical transfers

## Outcome

Implemented layer-aware residency identity and transfer scope for full-attention
Turbo4 pages. Canonical host objects remain bundle-owned; layer mappings carry
the compact attention-layer ordinal plus content version, valid length, and
consumer-event metadata. Graph KV writes now bind one K/V row-index input per
cache layer in deterministic model-layer order, while views and scratch
reservations use layer physical-row geometry. GDN/recurrent layers remain out
of pager geometry and native MTP remains a separate allocation domain.
