# Handoff 41-01 — live current-Q publication boundary

## Result

Repaired the selected-packed telemetry handoff so a completed eligible
selected-packed submission carries its live residency snapshot, query token,
and selected page identities to the completion boundary. The old silent
handled path is gone: when selected-packed has no page-mass producer, the
completion boundary records a precise `no_output` rejection. Metadata and
identity failures are deferred to that same boundary and counted once. No
synthetic attention sample was added, and the selected-packed/Turbo4 route
identity is unchanged.

The CPU-only workspace cannot run the natural CUDA C>H smoke. The first live
missing edge is now explicit: selected-packed computes the selected Q/K/V
result but does not produce the page-mass sidecar consumed by
`publish_kv_attention_telemetry()`.
