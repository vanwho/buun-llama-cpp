# Handoff 50-02 — cadence and parallel page ranking

## Result

Implemented accepted-target-token refresh cadence and device-side parallel
catalogue ranking for the V10 GPU pager.

- Submission IDs remain unique per routing request; refresh eligibility uses a
  committed accepted-token watermark, dirty policy state, and configurable
  `--kv-router-refresh-tokens` (default 8).
- Ordinary successful target decode reports accepted tokens through the memory
  owner. Speculative verification and re-evaluation are suppressed, and the
  native/speculative rollback owner reports only the committed accepted delta.
- CUDA scoring exits before dot-product work when refresh is disabled or no
  candidate is eligible. Refreshed selection rejects causal, generation,
  finite-value, and summary-stale candidates before scoring.
- CUDA uses stable 64-bit score/page keys and CUB radix sort for independent
  resident/cold partitions, with explicit `-1` output padding. CPU reference
  eligibility and finite-score behavior match the CUDA contract.
