# 20-03 handoff — bounded predictive promotion overlap

## Outcome

Local implementation is complete and verified. The bounded owner-side
prefetch scheduler now supports previous-query/layer prediction as lookahead,
dedicated asynchronous backend tickets, bounded staging/events/pinned slots/
queued bytes, priority ordering, out-of-order completion, cancellation and
stale-generation cleanup, authoritative `ensure_ready()` waits/fallbacks, and
a bounded correlated timeline. The lifecycle owner exposes observe/predict
forwarding with generation validation. The existing pager remains an explicit
synchronous baseline pending isolated live measurement.

Prediction accounting distinguishes a needed-in-flight page from a useful
published page, so failed/stale/cancelled transfers do not become useful hits.
Existing VBR run/chunk planning remains the transfer-level coalescing seam;
different page identities stay separate scheduler tickets.
