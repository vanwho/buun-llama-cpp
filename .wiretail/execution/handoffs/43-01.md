# Handoff 43-01 — selected-packed current-Q producer repair

## Result

page-mass-producing graph node. The ordinary packed attention path remains the
production consumer of the compact Turbo4 cache; the telemetry node is a
bounded, single-layer sidecar over the same physical pager K/V storage and
selected page descriptors. Its page-mass output is graph-owned, scheduler
fenced, and published using the already captured snapshot epoch, token index,
query positions, and page identity.

Packed graph input refresh now updates the sidecar's mutable control,
descriptor, and query-position inputs. Graph reuse includes whether the
cadence-valid telemetry output exists, including the hybrid attention child.
Malformed packed pager geometry fails closed before graph construction. The
existing publisher and `publish_completed` validation/drop accounting remains
in force for missing, stale, malformed, or unavailable results.
