# 35-02 handoff

## Result

Implemented the independent `GGML_OP_KV_PAGE_SELECT` path and added backend
parity coverage. CPU and CUDA both return fixed I32 resident/cold regions,
logical IDs, deterministic score/page ordering, and `-1` padding. The CUDA
implementation uses cooperative page scoring and bounded ranking; it does not
copy Q to host or use the old direct attention route.

The graph producer seam is now at the shared attention builder: it receives Q
after model-specific positioning and before attention's head/query permutation,
uses row zero as the first-query causal boundary, and explicitly expands any
selector result into the executed graph. Cache contexts fail closed with an
explicit not-configured result until catalogue/mailbox tensors are bound.

## Findings

The updated selector is backend-parity clean on the available CPU and RTX
4080 CUDA backends. The timing scales with catalogue pages while remaining a
bounded fixed-K graph operation. The graph hook is shared by hybrid contexts,
including the full-history base child of iSWA; recurrent/SWA-only contexts do
not invent selector inputs.
