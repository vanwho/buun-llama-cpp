# 28-04 handoff - tiled paged Turbo4 prefill

## Outcome

Implemented production multi-query paged Turbo4 prefill through the mature
MMA, online-softmax, GQA, and output pipeline. A paged source policy resolves
descriptor rows and physical slots in device code, reuses decoded K/V tiles
across grouped query columns, preserves native-position/mask/causal behavior,
and skips pages not selected by any query in the current tile. Direct fused
MMA dispatch is automatic for bounded multi-query output calls; telemetry,
split-state, merge, and explicit reference calls retain their established
descriptor-aware paths. Conservative column-width selection covers legacy
Volta/Turing MMA limits without SM90-only APIs.
