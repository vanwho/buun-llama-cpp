- Accumulate only rows where `query_start <= position < query_end`; carry `[count, turn_id]` and clear sums when turn id changes.
- Accumulator sources are transformed Q, per-row absolute positions, persistent F32 sums, persistent I64 count/turn, and I64 `[turn,start,end]` control. Output is compact `[head_dim, query_heads]` mean Q.
- CUDA keeps Q and accumulator state on device. CPU implementation is a deterministic math reference.
- Keep GQA head identity and independent per-layer sums. Turbo WHT direction 2 is still applied once by the caller.
- Selector IDs remain per-layer, keyed from the model-derived full-attention layer list; the existing retrieval boundary combines layer candidates using normalized reciprocal rank `1 / (1 + rank)`.
