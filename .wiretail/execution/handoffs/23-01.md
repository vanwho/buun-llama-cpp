## Implementation

- Extended the checked admission ledger with explicit recurrent-state,
  MTP-compute, external-occupancy, graph, routing-table and staging rows.
- Reserved the recurrent tensor footprint from model metadata and the
  measured co-tenancy compute ask before automatic target-page admission.
- Kept the physical device total as the ceiling when external occupancy is a
  named charge, preventing double subtraction/double charging.
- Reconciled measured context/compute/external values without growing beyond
  the preallocation plan or changing the requested context/MTP rows.
- Added category rows to context metrics, server JSON and startup logging.
- Added a bounded, strictly descending page-aligned retry for allocator OOM;
  each attempt records page cap, admitted pages, requested bytes and a stable
  tuple fingerprint. Realized-size mismatches remain terminal.
- Preserved the cache-owned external slab authority; the pager does not create
  a second target KV backing.
