# 19-02 Handoff

## Result

Complete locally with the named live forced-small-hotset checkpoint deferred
because the RTX 4080 was occupied. Bounded graph writes now use pager tickets'
physical slot rows, while logical positions remain in page identities. Pager
completion is generation-checked and fails closed on an unexpected completion
status. Post-fence sealing captures the exact Turbo4 source rows into the
canonical host catalog, including contiguous partial tails without padding.

Clean GPU eviction preserves the host catalog entry; overwrites invalidate the
old canonical entry before publication so same-identity writes cannot alias
stale bytes. Non-contiguous valid-row holes are not sealed.

## Invariants

- `ticket.physical_row = physical_slot * page_tokens + intra_page_row`; no
  logical position is used as an unbounded compact-slab write offset.
- K and V graph writes share one ticket generation/commit boundary.
- Host capture reads the source tensor's existing Turbo4 bytes and representation
  identity; no dequantize/requantize path is introduced.
- Host validity is separate from GPU presence, and tail padding is not valid.
- Rejected/stale completions do not publish visible page state.
