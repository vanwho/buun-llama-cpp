## Decisions and invariants

- Historical retrieval budget is `R - query_pages`; `G` remains reserved.
- Generation eviction prefers completed generation pages, then may borrow only
  clean, host-backed prior history outside the selected set and active query.
- Server query replay removes the provisional suffix, keeps the published map,
  and replays only the final-user token span. MTP carry is refreshed from target
  processing and remains bound to the frozen history generation.
- Do not infer target/draft parity from sampled text across dense and selected
  target views; compare state on each same-view fixture.
