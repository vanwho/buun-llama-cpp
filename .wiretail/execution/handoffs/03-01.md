# 03-01 handoff

## Outcome

Added the backend-neutral `llama_kv_attention_view` reference seam. It builds
an immutable compact row plan from a residency snapshot and an explicitly
ordered selected-page list. Compact slots are independent from logical page
IDs and source physical slots; native logical positions are expanded into a
bounded vector for RoPE/masking, with a valid-row mask for the selected view.
The view's `get_n_kv()` is the selected physical row count, including a
short/tail page, rather than the logical context frontier. An explicit graph
fence retains the immutable view and source snapshot until graph completion.

The builder rejects absent/non-resident pages, duplicate selections, invalid
page alignment/position identity, and row-count overflow. Full pages, gaps,
permutations, and the current short tail are supported. No KV payload or
whole-context F16 gather buffer is allocated.
