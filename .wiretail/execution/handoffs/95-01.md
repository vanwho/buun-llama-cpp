The task retains checked absolute token offsets. Pager turn boundaries use that interval; prefill checkpoint splitting uses its start. Unsupported multimodal or ambiguous rendered spans log the capability reason and use the documented full-prompt fresh-suffix fallback. Raw completion compatibility remains unchanged. Focused build and named executable proof pass; receipt validation passed and task state is done.

## Decisions/invariants

- The count is derived from parsed server-side chat messages, never from a client page identity or token offset.
- Role spans are checked for exact user-message cardinality, ordered in-range offsets, and a nonempty final span. The full rendered user delimiter is included; the next recognized role delimiter (including assistant generation trailer) is excluded.
- Span matching runs against the full tokenized request, never per-message tokenization. A cached-prefix seam inside a multi-token delimiter is handled by resolving on the complete request.
- Multimodal and ambiguous/missing delimiter forms use an explicit full-prompt fresh-suffix policy. Raw completion keeps its existing compatibility behavior.
