## Delivered

- Added per-page content, host-committed, and summary-committed versions. A
  clean page, pin change, identity-preserving publication, or resident epoch
  change does not trigger a summary source read.
- Deferred summary sampling until the page host seal succeeds when canonical
  host backing is configured. The cache summary provider reads the typed
  captured Turbo4 K unit image and retains tensor readback only as the explicit
  no-host fallback.
- Added batched `update_pages()` and targeted `invalidate_pages()` routing-store
  boundaries. A changed seal wave acquires inventory once and publishes one
  store per configured layer rather than rebuilding for each page/input.
- Kept identity and generation invalidation exact across overwrite, rollback,
  removal, shift, copy, and physical-slot reuse.
- Added deterministic assertions for clean no-op sealing, tail-only refresh,
  speculative rollback refresh, resident-only epoch changes, batch publication,
  and exact identity invalidation.
