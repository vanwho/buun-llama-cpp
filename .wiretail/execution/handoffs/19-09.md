# 19-09 handoff — bounded split-KV paged attention

## Outcome

Implemented bounded split-KV attention for qualified direct paged Turbo4
decode. Partition CTAs produce the existing unnormalized `[m,l,o]` contract;
a second CUDA launch merges and normalizes globally. Page mass is accumulated
per partition and divided by the merged global denominator. The serial
query-tile path remains available for small shapes, capacity one, exact-wave
debugging, and the correctness oracle.

## Invariants and raw pointers

- Partition state is unnormalized `[m,l,o]`, not normalized partial output.
- The merge uses exact floor-based page partition boundaries, including uneven
  page counts; logical-page IDs remain independent of scan order and physical
  slots.
- Scratch is bounded by selected shape and an explicit capacity capped at 16;
  the runtime partition count is limited by capacity, pages, `ceil(rows/256)`,
  and CUDA device properties, never a server-specific SM constant.
- Direct output remains in the Turbo V rotated domain; inverse WHT/mean
  restoration remains at the graph boundary.
- Final local fixture shape: 530 rows, four logical pages, three query tokens,
  four Q heads, capacity three, 38,304 bytes scratch; all assertions passed.
