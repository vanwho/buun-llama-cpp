## Decisions/invariants

- Generation eviction requires exact current sequence/turn ownership and page
  identity, clean canonical host content at the current version, no page/read/
  transfer pins, no host seal in flight, no frozen-history ownership, and a
  completed routing summary when configured.
- During generation only the oldest completed generation-owned page is a
  victim. Spare retrieval capacity can be borrowed; frozen selected history and
  the mutable current tail remain protected.
- The completed-generation index is per turn and ordered by logical position;
  stale identities are removed lazily. Successful async host completion also
  queues eligible generation pages.
- Turn clear releases the tail frontier, drains bounded host work, and
  reclassifies generated/frozen pages as prior history.
