# 05-01 handoff

## Outcome

Made hybrid memory mutations composite-owned. The attention cache remains the only
page/VBR owner; recurrent state stays fixed-layout and GPU-resident, while the
optional QSA index cache joins the same coordinator and follows the attention
slot plan. Batch preparation now performs attention and index planning before
the recurrent preflight and publishes attention only after all rejecting
preflights pass.

Sequence removal, transient removal, copy, keep, shift, clear, and state import
now run under one hybrid VBR operation. Recurrent copy rejection happens before
attention publication, and state-import exceptions clear all affected children
before closing the failed operation. Decode/update contexts apply recurrent,
then the optional companion, then attention under one operation and fixed
participant completion aggregate. Indexed preparation rejects attention/index
slot-plan drift before mutation.

## Invariants/evidence

The mutation scope mints at most one operation and adopts it into every armed
attention/companion cache. Unarmed caches remain inert, preserving the disabled
VBR path. Recurrent capacity rejection is checked before attention/index copy,
and indexed slot plans must match exactly before batch preparation proceeds.
Decode manifests retain per-sequence ranges and SWA-wrap coverage, and the
composite closes only after every armed asynchronous child reports terminal
status.

## Deferred verification

CUDA page transfers, GPU-resident recurrent tensors, stale asynchronous page
completion, and long-context Qwen3.8 hybrid/MTP behavior were deferred because
this transaction task was run without binding the external server runtime to
the fixture. The reference GPU and Qwen3.8-27B checkpoint are available at
`/srv/ai/models/text/Qwen3.8-27B-UD-IQ4_XS.gguf`; model availability was not the
limitation. The hardware follow-up in phases 08–14 must exercise VBR-enabled
decode completion and fault injection at each child boundary.

## Remaining risks

The local rollback test did not execute model-backed hybrid cases because the
production graph/transfer owner was not wired into this task. The VBR composite
path is compiled but not hardware-exercised here; later integration must
validate the separate GPU-resident MTP cache and real async page completion
against this transaction boundary using the pinned Qwen3.8 artifact.
