# 101-12c handoff

## Result and current state

The selected-path repair is implemented and locally verified. Request-local telemetry from 101-12b showed 1,024–1,088 per-head summary-provider publications (64 layer/head configs across 16–17 closed pages). `pager_routing_summary_build` decoded each canonical key page once into all layer/head range and mean vectors, then deep-copied one cached vector bundle for every provider publication. The telemetry's `summary_build_bytes` counts canonical key-source bytes scanned; it is not used as a vector-copy byte estimate. The callback now transfers each input once and rebuilds the page cache if a consumed entry is requested again.

No post-fix speed result is claimed; 101-12d owns the canonical retake.

## Decisions and invariants

- Preserve H4096 semantics, native GPU Turbo4 MTP nmax2, L8192/P256/B1024/U256, and the automatic pager route.
- The fix changes ownership transfer only; per-head data and pager byte accounting remain intact.
- Keep retry behavior by rebuilding when an already-consumed config entry is requested.
