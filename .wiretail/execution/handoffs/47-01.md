# 47-01 handoff

## Result

Repaired the first current-Q readiness boundary in `llama_kv_cache::apply_pager_live_policy`.

- A current selector output captured before a post-query write-frontier seal
  can have `refresh_enabled=false`. It is advisory, not a candidate, but it
  must remain registered while `pager_policy_dirty_` is retained so the next
  graph boundary refreshes it.
- Stale outputs and consumed or invalid enabled outputs still drop at the
  existing owner-side boundary; no candidate or page is manufactured.
- Candidate region decoding now uses the configured resident A-page count,
  matching `build_kv_page_select`, instead of assuming the resident and cold
  output regions are equal.
- Added a debug diagnostic when a dirty boundary has no readable current-Q
  result, including the query generation, table epoch, and retained output
  count.

## Deferred verification

The rebuilt CUDA server loaded the Qwen3.8-27B Turbo4 target and native-MTP
draft K/V on CUDA, selected the packed pager route, and produced coherent
natural output for a 4,201-token prompt. A 4-page smoke configuration and a
large 4.5K append both stopped at the pre-fence write reservation boundary
with the existing fail-closed `decode() ... no_victim` result. A smaller
128/64 cached one-token append sequence was started; it advanced naturally
through 4,074 evaluated tokens, but was stopped before the first physical
overflow because cache shifting is disabled for this pager context and each
step reprocessed the full prefix. The metrics collected before that boundary
showed selected packed CUDA, 8 selected pages, Turbo4 target/draft K/V, and
zero promotion/useful H2D; no candidate or selected-cold-use proof was
claimed.

The isolated smoke server was stopped and the pre-existing
`llama-server.service` was restarted and returned `{"status":"ok"}` on port
8080. The natural C>H candidate/promotion/use accounting remains deferred to
the phase harness, whose smaller append schedule can reach the post-seal
scheduler fence without this local batch-reservation failure.
