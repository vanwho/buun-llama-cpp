# 08-03 handoff

## Outcome

Target hot-capacity admission and automatic policy quotas are now runtime-sized.
The old 304-page policy capacity, absolute policy quota defaults, 1024-page
telemetry array, and implicit 256-token admission multiplication are gone from
production code. Missing logical-page admission input fails closed.

## Admission contract

`llama_cache_budget_admit()` now returns the complete checked ledger:

- usable device bytes after optional user and backend-safe limits;
- aligned fixed, MTP, scratch, routing, allocator-guard, and headroom terms;
- total reserved and charged bytes;
- raw page bytes and aligned page charge;
- resolved page-token width, logical page count `L`, admitted pages `H`,
  capacity tokens, and unused remainder;
- measurement provenance and post-allocation reconciliation status.

The calculation is:

```text
usable = min(capacity, optional user budget, optional backend-safe limit)
reserved = aligned MTP + aligned scratch + aligned routing + allocator guard
charged = aligned fixed + reserved + aligned headroom
H = min(floor((usable - charged) / aligned page charge), L, user caps)
```

All additions, products, alignment, and `H * page_tokens` conversion are
checked. `L`, page width, MTP rows, page bytes, scratch, and other required
geometry are explicit runtime inputs; zero required geometry is refused.

## Policy and telemetry changes

`llama_kv_policy_controller_config` now requires runtime `capacity_pages`.
Zero page counts are explicit overrides; otherwise recent/structural/
historical/transient quotas are derived from capacity-relative ratios and zero
default minima. Minima and explicit quotas are clamped to the post-mandatory
capacity. Integer remainders are assigned in deterministic priority order, and
the existing candidate fill reconciles the deduplicated target to `H` whenever
the trace contains enough logical pages. Explicit quota settings remain
available for tests and users.

Attention telemetry stores a vector sized from the resolved logical page count,
with allocation failure disabling the instance. Its accounting multiplication
and score-byte rollup saturate instead of wrapping. Fixed-window code remains a
manual-capacity fixture seam; no production caller uses it as a hot-capacity
default.

## Tests and capacities

- Admission tests cover missing geometry, aligned ledger terms, backend/user

  existing explicit quota and mandatory-overflow cases.
- Telemetry tests construct a 2,048-logical-page instance, beyond the removed
  historical 1,024-page array, and verify accounting.
