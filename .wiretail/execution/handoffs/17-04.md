# Handoff: 17-04 — dynamic Turbo4/MTP VRAM admission

## Result

Completed the dynamic admission repair for the Turbo4 target pager and native
MTP companion. Runtime admission now uses the device total plus the resident
model/context/compute breakdown, retains opaque driver/peer occupancy as a
backend-safe limit, reserves context-sized native-MTP rows before target pages,
charges allocator alignment, transient staging, bounded routing metadata, and
explicit VRAM headroom, and keeps the target pager allocation separate from MTP
ownership.

The admission result carries requested context, resolved context, accepted
target tokens, an `accepted` flag, and a typed refusal. Successful server
telemetry exposes those fields; an impossible request is logged with the same
machine-readable fields before pager construction raises. A zero-page fit is
now an explicit insufficient-capacity refusal rather than a successful empty
pager.
