# 17-02 handoff — pager and native-MTP telemetry export

## Outcome

Completed the live pager metrics contract. The server now exports the
telemetry publish-time counter required by the adapter as
`llamacpp:kv_pager_attention_publish_time_us`, alongside the existing transfer,
wait, byte, page, epoch, host, and device-ledger fields. The exporter also
includes the remaining bounded attention/execution counters and transfer
accounting fields.

Native MTP evidence is now bound to the actual native draft context at metrics
scrape time. The snapshot reports the realized MTP row/byte allocation, cache
types, and a placement state: `gpu` only when the measured context allocation
is GPU-resident and Turbo4/Turbo4; `unsupported` for a supplied context that
does not satisfy that contract; and `not_present` when no native MTP context is
live. External MTP sidecars are deliberately not treated as native MTP.

## Deferred verification

benchmark acceptance. A later controlled run should use the configured
candidate service, authenticate `/metrics`, confirm a non-`not_present` MTP
backend with measured Turbo4/GPU allocation, and capture queue/publish timing
over real requests. Live CUDA graph behavior, throughput, quality, and frozen
corpus acceptance remain deferred; no credentials or machine-specific paths
are recorded here.
