# 25-07 handoff — asynchronous canonical host publication

Status: implementation complete; task state is updated separately after the
final validation command.

## Delivered

- Added a bounded host-publication worker queue to `llama_kv_pager_host`.
- Reused the existing VBR capture ring, event completion path, host catalog,
  and provider snapshot contract; no parallel payload representation was
  introduced.
- CUDA backends with async copies and events enqueue capture work and publish
  only after completion. Unsupported or forced-synchronous backends retain the
  synchronous path, and queue pressure falls back synchronously.
- Kept source pages pinned while host publication is inflight, cancelled stale
  work on invalidation, and exposed `host_inflight_pages` separately from
  logical occupancy.
- Deferred the mutable async tail so generated-token append does not recopy the
  whole partial page on every seal.
- Exported async-completion, queued, and inflight counters through context and
  server metrics.
- Added the deterministic CUDA byte-equality publication test and CPU fallback
  coverage through the existing pager test binary.
