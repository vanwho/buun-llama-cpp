# 03-04 handoff

## Outcome

Integrated the selected-attention lifecycle across prompt and generation
boundaries. `llama_kv_attention_prefill_admission` admits multiple chunks into
the current 256-token page, only opens the next page after completion, requires
an explicit finalization for a short tail, and permits decode only after that
tail is sealed. The tail remains part of the resident row count.

`llama_kv_attention_execution` now routes feature-off work to dense attention,
observe work to dense attention with an observe diagnostic, prompt/unsupported
shapes to the compact selected reference, and the exact causal batch-one
Turbo4 D=256 GQA=4 decode shape to the direct route when the backend loader
reports direct capability. Invalid selected metadata and scratch overflow are
typed refusals. Route logs contain the explicit dense, observe, selected
reference, selected direct, and refusal labels.

Graph parameters now carry table, selected-content, representation, and shape
epochs. `llm_graph_params::allow_reuse` fences all four route-affecting keys,
while `llm_graph_result` retains the immutable selected-view fence. The
context releases all submitted selected-view leases after its scheduler
synchronization boundary. The selected-content key also prevents reuse when a
different ordered page list is made from the same residency snapshot epoch.

Scratch sizing is derived only from resident rows plus transfer/router rows;
logical context length is not an input to the reservation arithmetic.
