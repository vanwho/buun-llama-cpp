## Findings

The selected n-max1 run is the measured production choice because it improves
committed decode speed over n-max2 while preserving the full-L GPU draft
invariant. Sparse native-MTP benefit versus dense all-GPU remains unproven:
the selected path has a measurable acceptance cost, although both paths
completed the same 128 output tokens. No full draft-history refill workaround
was added.
