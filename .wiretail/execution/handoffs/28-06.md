# 28-06 handoff - asynchronous ranked cold promotion

## Outcome

Added a bounded two-slot GPU-candidate mailbox with compact page/layer
identity, generation, score, requested-byte, content-version, and speculation
metadata. Completion polling is callback-based and nonblocking; stale table or
speculative candidates are discarded before readiness. The existing prefetch
scheduler now keys requests by full layer identity, bounds predictive refreshes
by cadence/page/byte budgets, preserves bounded pending/inflight/ready state,
and supports generation-safe publication and event release. The pager exposes
the mailbox, and the live policy consumes only validated mailbox candidates;
the old per-token blocking Q readback path was removed.
