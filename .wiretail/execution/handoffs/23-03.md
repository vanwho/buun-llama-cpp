## Finding and implementation

The current Qwen3.5 GGUF is `qwen35` with 24 query heads, 4 KV heads, 256-wide
K/V heads, and GQA ratio 6. The direct Turbo4 CUDA kernel already computes
`kv_head = query_head / gqa_ratio`, but route admission and both CUDA shape
checks required `query_heads == 4 * kv_heads`. That stale ratio gate caused the
live prompt path to select `selected_reference`.

The following boundaries now accept any divisible GQA ratio, including Qwen’s
24:4 geometry:

- `llama_context::prefill_ubatch_size` and
  `llama_context::prepare_kv_attention_graph`;
- backend-neutral direct-route selection and fallback-reason propagation;
- CUDA paged Turbo4 raw and graph shape validation; and
- the CUDA numerical fixture, expanded from 4:1 to 24:4 storage.

The kernel’s 16-query-token bound is unchanged. Query tiles above that bound
remain on the explicit bounded reference route. Direct rejection now reports
the first concrete backend, phase, geometry, storage, model-feature, or slab
geometry reason.
