# 19-05 Handoff — direct tiled selective prefill

## Outcome

Completed the bounded direct selective-prefill path for supported Qwen35/
Qwen35MOE Turbo4 geometry. A single CTA now processes a one-to-three-query
tile, traverses compressed page descriptors once, decodes each physical K/V
row once per tile, and applies query-local native causal positions.

## Changed files

- `ggml/src/ggml-cuda/fattn-paged-turbo4.cuh`, `ggml/src/ggml-cuda/fattn.cu`:
  document and implement the shared compressed K/V query tile; preserve
  explicit query/head/page-mass/partial strides and page/tail addressing.
- `src/llama-context.cpp`: admit selective prefill, cap supported Turbo4
  prefill chunks at three queries, retain physical-window bounds elsewhere,
  and identify resident scratch in diagnostics.
- `src/llama-kv-attention-execution.cpp`: route supported selective prefill
  tiles to direct and expose the route reason/counter.
- `tests/test-cuda-fattn-paged-turbo4.cu`, `tests/test-kv-attention-execution.cpp`:
  cover query tile sizes 1/2/3, causal/tail/page-mass/partial behavior, and
  selective-prefill direct counters.
- `.wiretail/execution/evidence/19-05_PREFILL.{json,md}`: receipt and summary.

## Invariants

- Q/output remain `[head_dim, query_head, query_token, batch]`; the direct
  geometry remains causal, batch one, head width 256, GQA ratio four, and
  query tile width one through three.
- K/V remain native compressed Turbo4 bytes. Page descriptors translate the
  logical selected row to a physical slot; compact row index is never used as
  a physical address, and causal checks use native positions.
- Direct prefill allocates no full logical-context F16 target or unbounded
  dequant gather. Scratch is resident/transfer/router-row bounded; kernel
  shared state is fixed by the three-query tile plus optional resident page
  telemetry.
- Selective prefill is the intentionally bounded approximation. Exact
  full-history prefill and cold-page wave/merge execution remain 19-06 work.
- Prefill progress and dispatch counters remain in the existing execution
  metrics; direct/reference counters distinguish healthy tile submissions from
  fallback behavior.
