## Findings

The implementation keeps graph shape tied to admitted physical capacity while uploading only mutable row IDs/descriptors. Unchanged history is not recopied on the packed path; content versions and dirty intervals are updated in one batch. The router fast path avoids route/inventory history work when no mailbox or policy state changed. The live q0 used CUDA Turbo4 selected attention and reported zero H2D/copy bytes; graph-level live counters are not exposed by the bounded q0 receipt.
