# 10-02 handoff — direct Turbo4 paged decode dispatch

Status: done locally; no commit was created.

## Implementation

The live selected-attention graph now builds the direct operation for qualified
Qwen full-attention decode layers:

```c
ggml_tensor * ggml_flash_attn_ext_paged_turbo4(
    ggml_context *, ggml_tensor * q, ggml_tensor * k, ggml_tensor * v,
    ggml_tensor * physical_storage, ggml_tensor * page_table,
    ggml_tensor * native_positions, ggml_tensor * native_mask,
    ggml_tensor * query_positions,
    const ggml_flash_attn_ext_paged_turbo4_params *, const void * pages_host);
```

The operation receives F32 Q, raw I8 views over the persistent pager slab,
device page/position/mask inputs, and an immutable host page-table copy. The
existing CUDA backend API remains available for direct fixtures and optional
page-mass/partial-state output:

```c
ggml_cuda_flash_attn_ext_paged_turbo4(ggml_backend_cuda_context &, params);
```

CUDA registers the operation through its allocation, `supports_op`, and
compute dispatch paths. The CUDA implementation validates the marker, raw
Turbo4 types, exact decode geometry, strides, page bounds, causal metadata,
and finite scale before launching. Page dequantization remains in the direct
kernel; no selected or full-cache F16 K/V tensor is formed.

The generic graph descriptor and established CUDA fixture descriptor are kept
as distinct C++ types with compile-time layout checks, preserving the raw CUDA
API boundary while allowing the graph dispatch to consume the generic GGML
operation metadata.

## Dispatch matrix

| Runtime condition | Route |
| --- | --- |
| Selective mode, Qwen35/Qwen35MOE, one sequence, one-token causal decode, Turbo4 K/V, Dk=Dv=256, GQA=4, CUDA layer device, scheduler backend, valid pager slab/geometry, no ALiBi or soft-cap | `selected_direct` |
| Same admitted selected Qwen shape but prefill, non-CUDA backend, unsupported head/type/attention option, or direct resource unavailable | `selected_reference` bounded gather |
| Feature off/observe/exact, unsupported graph family or batch/sequence shape, invalid page/residency metadata | existing dense/observe/exact route or explicit refusal |

The reference route remains the fail-closed fallback. The direct route uses
physical source slots from the page descriptors while applying compact native
positions, native validity masks, causal query positions, arbitrary page
order, logical gaps, and short tails.

## Resources and lifetime

The pager's existing GGML storage tensor is exposed as the backing slab. Each
physical slot contains all layers' K page followed by V page; per-layer byte
offsets and the slot stride are recorded in pager geometry. Per graph, the
page table is an I8 device input, native positions and query positions are I64
device inputs, and the validity mask is an I8 device input. These metadata
inputs are explicitly assigned to the pager CUDA device so CUDA graph capture
does not receive host pointers. Graph content/table/representation/shape
epochs remain part of graph reuse, and the existing metadata graph fence keeps
the residency table alive through submission and completion.

The direct CUDA launch uses one 256-thread block per Q head and the backend
stream. It allocates only bounded dynamic shared memory for Q rotation,
reductions, and page mass when requested; the live graph does not request page
mass output.

## Deferred verification

At the time of this foundation task, the direct fixture was not connected to a
production model graph, host page catalog, or real CUDA promotion path. The
statement that no runnable Qwen35/Qwen35MOE model was present referred only to
the Git worktree/test fixture; it did **not** mean that the server lacked a
model. The pinned Qwen3.8-27B GGUF is available externally at
`/srv/ai/models/text/Qwen3.8-27B-UD-IQ4_XS.gguf` (architecture `qwen35`), and
the existing `/srv/ai/config/profiles/qwen38-fast.env` is the canonical
Turbo4/MTP server configuration for it (with `qwen38-big.env` as the ordinary
control). These are the required live targets for phases 08–14. Consequently,
dense-versus-selected
reference/direct per-layer and final-logit parity, direct-dispatch logs, and
throughput must be run against that artifact once the production pager wiring
is present; they are not optional or permanently deferred by this handoff.

The raw direct fixture covers permutations, logical gaps, a tail, native causal
masking, page mass, and partial-state paths, but it does not replace the
Qwen3.8 model proof.
