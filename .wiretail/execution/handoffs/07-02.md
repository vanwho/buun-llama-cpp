## Remaining risks

The documentation now matches the implemented internal seams, but the public
operator surface does not yet run selective or exact paging. The main residual
risk is that future runtime wiring could change page counts, MTP placement,
telemetry names, or quality/throughput results; the acceptance records must be
updated from raw runs rather than inferred from these bounded contracts.
