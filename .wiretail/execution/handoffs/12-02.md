# Handoff 12-02 — Pager metrics and benchmark adapter

## Result

Implemented the bounded pager metrics boundary and bound the pager profile
adapter to server `/metrics` output. The context produces one scalar snapshot
containing pager geometry, residency/host ledgers, budget accounting, MTP
rows/bytes, routing configuration, attention counters/accounting, and graph/
transfer execution counters. Server metrics serializes the snapshot as
`llamacpp:kv_pager_*` Prometheus samples; mode, route, MTP backend, and target
types are labeled. The adapter maps those samples into the existing pager
envelope and rejects successful live runs when a required field is missing.
