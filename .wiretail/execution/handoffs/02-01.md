# 02-01 handoff

## Outcome

Added a bounded selected-page capture/adoption seam below the whole-prefix
artifact layer. A request carries logical page identities, explicit logical
positions and physical source cells, expected unit generations, and the
complete 16-layer K/V unit set. The adapter projects exact position, segment,
payload, source-operation, and authentication costs before retaining payload
storage.

Capture acquires one immutable page snapshot, validates the existing VBR unit
representation descriptors and topology identities, streams each page/unit
through the existing pinned-ring and segmented-chain path, and performs a
terminal snapshot recheck before publishing an immutable capability. Exactly
32 Turbo4 units are required for every page; a failed or stale transfer leaves
the result empty. No full-context vector or public state serializer is used.

## Invariants/evidence

- Fake-provider coverage captures two non-contiguous pages: one complete 256
  position page and one three-position tail, across all 32 layer/side units.
- Exact quote coverage checks 259 positions, 96 logical source segments and
  operations, 16,576 payload bytes, and 64 authenticated chunks.
- Wrong representation type, missing unit, stale page generation,
  representation change, geometry/payload overflow, and short transfer all
  reject with an empty capability.
- A provider recheck failure after all transfers rejects the complete private
  result, proving partial results are not adoptable.
- Existing Turbo4 codec/reference, codebook, rotation, mean-subtraction, and
  topology evidence is copied into the page unit descriptors; page identity
  retains the session, sequence, generation, representation, model, topology,
  and position fields.
- Payloads are held in existing bounded `artifact_segment_chain` instances
  filled through `vbr_pinned_chunk_ring`; no multi-gigabyte temporary vector is
  allocated and no `state_write`/`state_read` transport is used.
- Full-prefix artifact serialization code and wire constants were unchanged.

## Remaining risks

- The page provider must bind its page/unit snapshot to the live KV owner and
  supply the exact existing VBR representation descriptors; this task only
  defines and tests that production boundary with deterministic fakes.
- The selected-page result is an immutable capture/adoption capability; actual
  catalog ownership and GPU-slot installation are intentionally not included.
