# Handoff: 10-03 — decode graph epochs and first checkpoint

## Outcome

Task 10-03 is complete locally. The selected-attention execution boundary now
keeps every immutable page-view lease through `clear()` until the normal
scheduler completion boundary. This covers route fallback and mode changes
while an older direct graph is still in flight. A replacement table can be
prepared immediately, but its lease remains distinct from the old one.

The execution seam also exposes cumulative graph capture/replay/rebuild and
submission/completion counters, direct page-table upload bytes, descriptor
preparation time, kernel and total-token timing hooks, wait count, and scratch
high-water marks. The graph input records descriptor-copy preparation time and
the context records selected-graph waits and total token time. CUDA event
timing remains the backend fixture responsibility.

## Tests and results

The expanded `test-kv-attention-execution` matrix passes. It covers unchanged
reuse, ordered page content, physical slot remap, representation epoch, table
epoch/tail growth, query position and shape, direct-to-reference fallback,
irrelevant scratch/metrics ownership, and old/new leases across clear and
replacement. Its counter assertions are eight captures/rebuilds, one replay,
nine submissions, 96 direct page-table bytes, and the larger scratch request as
the high-water mark.

Commands run:

```sh
cmake --build build --target test-kv-attention-execution -j2
ctest --test-dir build -R '^test-kv-attention-execution$' --output-on-failure
ctest --test-dir build -R '^(test-kv-attention-execution|test-kv-attention-view|test-kv-attention-telemetry|test-kv-residency)$' --output-on-failure
ctest --test-dir build-cuda-test -R '^(test-cuda-graph-key|test-cuda-fattn-paged-turbo4)$' --output-on-failure
python3 -m json.tool .wiretail/execution/evidence/DECODE_CHECKPOINT.json
git diff --check
```

Results: all four CPU tests passed; both available CUDA tests passed. The
direct fixture was run seven times, with the first two treated as warmups and
the final five recorded in
[`decode-direct-fixture-trials-10-03.txt`](../evidence/decode-direct-fixture-trials-10-03.txt).
Measured kernel-event median was 20.952 ms, mean 20.8656 ms, over the bounded
four-head/one-query/529-selected-row fixture.

## Deferred verification

The Qwen3.8 GGUF exists, but no task-local runner currently provides dense,
selected-all-pages reference, and direct routes over identical prompts and
outputs while exposing the new counters. Therefore live model pp/tg, TTFT,
inter-token p50/p95, logits parity, and bounded `H<L` quality-independent
allocation/timing comparisons are deferred. The checkpoint makes no model
speed or quality claim and does not evaluate the final 3x gate.

A cold full CUDA-backend rebuild was started to recompile the changed graph
consumer and stopped during the large template-instantiation phase after the
available narrow CUDA executables had already passed. It should be rerun by
the next CUDA-capable integration task if a clean full-build artifact is
required.
