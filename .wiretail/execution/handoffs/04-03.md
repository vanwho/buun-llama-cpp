# 04-03 handoff

## Outcome

Added a deterministic decode-boundary hot-set controller beside the existing
policy replay seam. The controller validates traces, admits mandatory/current,
structural, recent, summary, exploration, and retention candidates in bounded
order, preserves all pin classes, and returns typed pin overflow. The default
partition is exactly 96 recent, 32 structural, 140 historical, and 36
transient pages (304 total), while smaller runtime capacities remain supported.

Evidence fields are independently normalized before ranking. Attention EMA,
recent peak, frequency, recency, fault/dirty cost, age, and configurable
hysteresis are represented without freezing calibrated production coefficients.
Each decision records bounded reasons for target entries, victims, and
unavailable attention evidence. The function is pure: it performs no transfer,
graph, or backend operation, and the previous target is read-only.

stable replay, current and speculative pin preservation, stable keeps across a
