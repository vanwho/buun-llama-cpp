# 19-06 Handoff — live exact GPU page-wave reference

## Outcome

Implemented the exact GPU page-wave graph boundary for supported Qwen35/
Qwen35MOE Turbo4 attention. Exact admission now publishes an immutable
coverage plan; graph construction creates one paged Turbo4 node per wave inside
each attention layer, keeps cold payloads in a bounded private staging slab,
and carries device-owned unnormalized `[m,l,o]` state between waves. Only the
last wave normalizes before the existing output path. The CPU `compute_wave`
callback remains a numerical oracle and is not used by the CUDA route.

## Invariants

- Exact page descriptors preserve logical order, physical slots, valid tail
  lengths, native positions, and exactly-once compact row coverage.
- Cold staging is `peak_staging_pages * page_bytes`, with offsets recomputed for
  the staging slot count; resident pager offsets are not reused for cold slabs.
- K/V remain native compressed Turbo4 bytes. No full logical-context F16 target,
  attention matrix, or CPU `compute_wave` result is allocated for GPU execution.
- Intermediate waves merge max/sum/value with stable online-softmax rescaling;
  empty/masked partitions produce safe zero output/state.
- Exact graph nodes are initial noncaptured operations; later capture tuning is
  outside this task. Native MTP uses the same exact graph seam when its query
  block satisfies the existing one-sequence/small-tile admission.
