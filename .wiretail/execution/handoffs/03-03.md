# 03-03 handoff

## Outcome

Implemented the first CUDA direct-page Turbo4 decode primitive for the exact
reference geometry: causal one-token decode, Turbo4 K/V, Dk=Dv=256, GQA=4,
and batch 1. Each CUDA block handles one Q head, rotates Q with the existing
Turbo signed FWHT contract, walks the validated selected page table, resolves
the physical slot, and dequantizes only the current Turbo4 K/V row directly
from its codebook/norm payload. No selected-cache or whole-cache F16 gather is
created.

The launch boundary is fail-closed for pointer/metadata errors, Turbo4 types,
head dimensions, GQA/batch/query geometry, causal mode, stride arithmetic,
physical-slot bounds, malformed compact/tail/page identity, and page-mass
telemetry shape. Optional online softmax mass reduction writes bins by logical
page and does not alter the attention output. The output remains in the raw
Turbo V rotated domain; inverse WHT and mean restoration remain at the graph
integration boundary owned by 03-04.
