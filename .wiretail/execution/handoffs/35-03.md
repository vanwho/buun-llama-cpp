# 35-03 handoff

## Result

Implemented the live selector-to-policy route. The shared Q graph callback
builds the real page selector for each attention layer, registers its compact
I32 output, and attaches graph-owned catalogue/query sideband inputs. At the
existing scheduler fence, outputs are copied into one pager-owned fixed
mailbox slot per refresh, validated against query/table epochs, and consumed
as bounded per-layer selections. Normal oldest-cold invention was removed;
the test force path reports `forced`.

## Findings

The deterministic fixture proves the real GGML selector output is consumed as
owned, epoch-qualified page identities; the existing mailbox fixture covers
pending/not-ready, stale-generation cancellation, failed-publication rollback,
and backpressure. Per-layer target vectors are capped by admission A and are
not formed from a cross-layer union. Selector refresh is enabled on the first
query, every eighth query, or a dirty page/request boundary; unchanged graph
inputs remain reusable.

The live service smoke sample returned HTTP 200 for health and chat, and its
pager request/table epochs advanced from 2/124 to 6/251. That process reported
`selected dense`, so it is not claimed as proof of this uncommitted selector
publisher.
