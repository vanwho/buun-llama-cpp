# 93-11m handoff

## Result and current state

Implementation is complete. The production path has a disabled-by-default,
refresh-scoped selector trace exposed in slot metrics. It records query
row/position/epoch, one optional target's selector eligibility inputs, up to
two raw cold selector IDs, readback/mailbox status, and policy/H2D/publication/
use outcomes. The driver leaves nomination unknown without direct evidence.

## Decisions/invariants

- Enable with `LLAMA_KV_PAGER_SELECTOR_TRACE=1`; optionally identify one page with `LLAMA_KV_PAGER_SELECTOR_TRACE_PAGE=<logical-id>`. The target is observation-only.
- Trace state is one fixed-size snapshot per due refresh. No prompt, attention matrix, full inventory, or per-token output is added. Raw arrays serialize only `raw_cold_count` entries, retaining `-1` when the selector returns an invalid index.
- Empty `natural_proof` leaves nomination unknown (`promotion_chain_incomplete`) unless direct raw output or an explicit selector reason exists.
- Natural promotion remains a success-only receipt; stage facts are recorded independently.
