# 09-02 handoff

## Outcome

Added the context-owned production pager owner and a backend-aware compact target
allocation seam. The owner has no global state, publishes an immutable geometry/
admission snapshot, keeps logical metadata at `L`, bounds residency/device slots
at `H`, and releases a partially or fully realized backend allocation through RAII.
The ordinary cache remains the existing construction boundary until 09-03 binds
target writes and mutations to this owner.

## Ownership and allocation order

```text
llama_context
  ├─ ordinary memory (existing recurrent/MTP/fixed companions)
  └─ unique_ptr<llama_kv_pager>  [target owner, destroyed before memory]
       ├─ host logical_pages[L]
       ├─ immutable residency table/device slots[H]
       └─ one backend buffer: H * aligned_page_charge bytes
```

Enabled construction is ordered as follows:

1. Resolve `C = cparams.n_ctx_seq` and inspect Qwen attention layers, heads,
   key/value dimensions, Turbo4 row sizes, backend topology, sequence layout,
   and VBR authority before pager allocation.
2. Complete ordinary memory and graph reservation, then query device free bytes,
   backend alignment, host free/budget, and the realized graph scratch estimate.
3. Build `L = ceil(C / page_tokens)` and pass the measured page charge plus
   fixed/MTP/scratch/routing/staging/guard/headroom fields to the existing checked
   budget admission function. `H` is clamped to `L` and the configured hot-page
   cap; zero `H` is a refusal.
4. Allocate exactly the admitted physical byte count (`H * aligned page charge`),
   require the backend-reported size to match, then create `L` host descriptors
   and an `H`-slot residency table.
5. Any failed plan, allocation, realized-size check, or later constructor step
   destroys the owner and releases its buffer. Normal context destruction follows
   the same owner-before-memory order.

## Accounting and memory ledgers

The owner snapshot records `C`, page geometry, measured cross-layer page bytes,
`L`, `H`, physical rows, requested/realized bytes, host metadata bytes, and the
full admission result. Admission reconciles:

```text
usable = min(device capacity, optional user budget, optional backend safe limit)
reserved = aligned MTP + aligned graph/kernel scratch + aligned routing/staging
            + allocator guard
charged = aligned fixed + reserved + headroom
H = min(floor((usable - charged) / aligned target-page bytes), L, page caps)
```

For a model-backed run the before/after target ledger is intentionally symbolic
until the target GGUF is available:

| Ledger | Existing target path | Pager owner in this task |
| --- | ---: | ---: |
| logical context | `C` positions | `L = ceil(C/P)` metadata entries |
| target physical rows | existing cache construction, pending 09-03 binding | `H * P` |
| target device bytes | allocator/model dependent | exactly `H * aligned page charge` |
| MTP/recurrent/fixed/graph terms | existing context allocations | explicit admission columns; no VBR pool reuse |
| host metadata | existing cache metadata | `L * sizeof(llama_kv_page_id)` |

The fake backend tests exercise exact requested/realized bytes, aligned page
charges, `H/L` changes, caps, odd tails, tiny budgets, and release accounting.

## Fault matrix

| Failure | Refusal/status | Cleanup guarantee |
| --- | --- | --- |
| pager off | `disabled` | no probe or allocation |
| invalid/overflowing geometry | `invalid_geometry`/`overflow` | no backend call |
| duplicate representation authority | `unsupported_authority` | no backend call |
| unknown/insufficient host metadata budget | `host_budget` | no backend call |
| mandatory ledger cannot fit or `H == 0` | `admission` | no backend call |
| absent backend callbacks | `missing_backend` | owner is not returned |
| backend allocation failure | `allocation` | any returned handle is released |
| realized size differs from request | `realized_mismatch` | mismatched handle is released |
| vector/table construction throws | `allocation` | owner destructor releases buffer |
| normal context teardown | — | owner releases before ordinary memory/backends |
