generated and 64 committed tokens per trial, `B=U=128`, and GPU-util/power
smoke samples. Median prefill/decode rates were:

| Row | Prefill tok/s | Decode tok/s |
| --- | ---: | ---: |
| all-GPU, feature off | 1589.586 | 49.731 |
| all-GPU, native MTP | 1487.629 | 36.684 |
| CPU-main-KV, native GPU MTP | 634.338 | 10.167 |
| selected, feature off | 135.285 | 24.849 |
| selected, native MTP | 138.747 | 36.289 |

Native MTP counters were observed. The all-GPU and CPU-main-KV controls
proposed 123 drafts and accepted none; selected native MTP accepted 39-40 of
44-47 drafts. The secondary selected `U=64` shape was slower than `U=128`.

The cached-append proof reached the observed frontier `6143`, then appended
exactly 64 prompt tokens with `cache_n=6142` and committed 64 output tokens.
Its append movement recorded 64 summary builds, 96 host-seal D2H calls, 24
logical graph rebuilds/submissions, zero faults, zero evictions, zero H2D
useful bytes, and zero `selected_packed` use.

The dominant measured attribution is selected reference-route/selector work
combined with host summary/seal movement and graph churn. The expected single
improvement is a stable graph-friendly direct or packed CUDA plan for the
selected cold/reference working set. `selected_packed` remains diagnostic only;
it was not a candidate row.
