# 25-04 handoff - reusable Turbo4 selected attention

Status: implementation complete; local host/CUDA builds and focused tests pass.
WORK_STATE is updated separately to mark only 25-04 done.

## Delivered

- Added `llama_kv_attention_dense_view_check()` for Turbo4 rotated-domain
  selections. It rejects invalid codec/domain, noncausal query order, physical
  holes, native gaps, poisoned non-tail pages, and invalid tails.
- Added `selected_dense` and `selected_packed` route decisions. Eligible
  physically contiguous pages use typed views over the persistent pager slab
  and existing dense Turbo4 Flash Attention, without a second full KV buffer.
- Added per-layer compact Turbo4 K/V buffers for noncontiguous pages. Copies
  remain raw codec bytes; no F16/F32 gather is used. Page generations drive
  changed-page repack, and current query pages get raw CUDA graph copies after
  cache writes.
- Added pack allocation/accounting (`packed_bytes`, `pack_bytes`,
  `pack_time_us`, `pack_epochs`, `pack_reuses`) and physical-view graph keys so
  remaps rebuild plans while unchanged compact layouts reuse them.
- Added CUDA raw quantized 3-D copy support for one-stream page views.
- Extended deterministic view/execution tests for eligibility, route choice,
  scratch charging, and pack metrics.
