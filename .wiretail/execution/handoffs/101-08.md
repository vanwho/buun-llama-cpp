## Decisions and invariants

- Shift is prior carry at row 0, then the preceding target hidden row. The target
  position metadata is retained; binding follows batch row order because MTP
  catch-up coordinates can differ from target source coordinates. Per-row
  sequence identity and owner generation are validated.
- Unsupported or noncontiguous cases keep the explicit host fallback and report
  its reason. Successful single-GPU binding reports `fallback_reason=none`.
- Transfer counters count hidden-row traffic. The live trace measured target
  D2H 20,480–61,440 bytes per process call and draft H2D 20,480 bytes per call;
  same-device shifted rows are D2D. The remaining H2D is the carry row, and D2H
  rows are requested for CPU-side verification/carry state.
