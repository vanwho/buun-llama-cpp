- PAGE_RERANK derives KV heads from packed width / query dimension; K.ne[2] remains stream count. Constructors and backend gates validate GQA, packed row widths, dimensions and tensor strides.
- Identity is I64[2,P+1]: query generation/job serial in column 0, expected generation/content per page thereafter. Rerank checks each page against its own expected identity and current query generation.
- Softcap is `cap*tanh(dot*attention_scale/cap)`. The CUDA kernel uses eight warps per (page, KV head), warp-strided rows, reusable decoded key lanes across grouped query heads/probes and one final block barrier. It does not materialize F16 keys or read V.
- Caller-owned streaming state is `[2,P,Qheads,probes]` `(m,s)` and is initialized once per layer/job. Chunks combine LSE state, staged slots are local to the staged key buffer, and stale identities cannot update the state.
- Added `GGML_OP_KV_PAGE_MASS` / `ggml_kv_page_mass`: CUDA normalizes each valid head/probe across the full represented resident+cold pool, then emits 16-byte I64[2,P] records with peak/mean across valid channels. Empty/stale pages emit invalid IDs.

## Decisions and invariants
- Attention scale is the ordinary target scale and is applied once before softcap. Candidate-pool exactness is over represented Turbo4 keys, not omitted-page dense equivalence.
- Identity descriptor versions may differ per page. A stale page is excluded individually; query-generation mismatch invalidates the current query.
- Persistent state fixture scratch: 512 B; mass probability scratch: 256 B; rerank static shared memory: 4096 B/block; mass normalize: 1024 B/block; mass emit: 3072 B/block.
