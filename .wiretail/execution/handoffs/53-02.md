# 53-02 handoff — packed attention resource repair

## Result

Implemented the selected-view packed allocation and graph-failure cleanup
repair, and made MMQ shared-memory admission account for the selected kernel's
static shared allocation and the persistent-queue header.

## Changes

- Packed row capacity is derived from the selected compact page extent and
  rounded only to the pager page-row alignment. The old admitted physical
  window sizing was removed.
- Added overflow-safe packed allocation-byte helpers and regression assertions
  for the 444 selected rows → 512 aligned rows case.
- Added provisional packed-owner tracking and `abort_graph_build()`. Graph
  input destruction and graph-build exceptions now release provisional owners
  and call `finish(false)` so failed construction cannot leave pending pager
  writes or stale generation publication.
- Packed content generations are published only after graph-owner submission.
- MMQ now configures only the kernel variant that is actually launched and
  filters J candidates using `sharedMemPerBlockOptin - sharedSizeBytes`, with
  room for the sparse persistent header.
