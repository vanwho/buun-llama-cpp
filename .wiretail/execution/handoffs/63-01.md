## Repair

- `llama_kv_attention_packed_cache::find_or_create` now sizes a new packed
  owner from the maximum compact extent across all selected pages. The page
  vector is a selection and is not required to be ordered by compact row, so
  the old `pages.back()` sizing could under-allocate a small first request.
- `llama_kv_attention_packed_cache::submit_graph` retains the local unique-owner
  list until `graph_leases_.push_back` succeeds. An allocation exception can
  therefore run the existing cleanup against the original owner list instead
  of leaving incremented in-flight leases stranded on a moved-from vector.
- The existing CUDA `launch_mul_mat_q` resource admission and Turbo4 placement
  boundary was preserved. The smoke did not report a launch-resource failure.
