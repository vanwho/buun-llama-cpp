# 17-03 handoff — contract-safe benchmark adapter

## Outcome

Completed the pager adapter contract hardening. Canonical runner exit status is
recorded separately from adapter validation, failed post-validation runs invoke
the established profile activator and verify the restored profile, managed PID,
and health, and valid successful runs retain the candidate under the default
keep-loaded policy. Explicit `--restore-control` remains available for control
runs.

The adapter now records a precise `failure_class` while retaining the raw
canonical records, run configuration, lifecycle state, and full validation
errors. Authentication rejection is explicit and never exposes the API key.
The portable mock suite covers missing `queue_us`, explicit
`mtp_backend=not_present`, HTTP 401/403, candidate identity mismatch,
restoration, canonical failure status separation, and successful keep-loaded
behavior.
