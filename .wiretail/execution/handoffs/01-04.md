# 01-04 handoff

## Outcome

Added `llama_kv_policy_replay`, a bounded, versioned, CPU-only pure policy
kernel. Retrieval is a deterministic deduplicated union of the write page,
recent pages, anchors, application/in-flight pins, summary top-K, and
exploration pages. Retention orders evictable resident pages using observed
attention EMA, retrieval hits, recency, dirty cost, age, and stable page-id
ties; cold/unobserved attention is unavailable and is never treated as zero.
Pinned-page overflow is an explicit refusal.
