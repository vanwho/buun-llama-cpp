# 28-07 handoff - MTP and fast paged-attention integration

## Outcome

Integrated the native-MTP and paged-attention hot path. Native MTP now starts
with a draft/Q-shaped working batch and grows only to the actual target
callback, while retaining the full resolved per-sequence MTP KV geometry and
device hidden-state handoff. The standalone speculative example marks native
verification explicitly and does not feed managed MTP drafters raw target
batches.

Automatic qualified Turbo4 prefill/verify/decode now prefers direct paging;
the compact packed bridge remains an explicit capability/diagnostic route.
Packed destinations reuse across in-place representation epochs and retire
superseded entries only after the scheduler fence. Graph reuse now fences on
the residency table epoch, and query positions participate in content keys.
