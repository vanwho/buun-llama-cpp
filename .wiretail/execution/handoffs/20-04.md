# 20-04 handoff — shape/content graph reuse

## Outcome

Implemented the measured graph-side steady-hot optimization. Selected KV
metadata now exposes separate content and layout keys. Residency epoch,
physical-slot/page order, and native query values are mutable data; bounded
shape/configuration and representation identity define graph topology.

Reused selected graphs refresh fixed-capacity direct page descriptors and
reference physical row IDs only when the content key changes. Native positions,
valid bits, query positions, and the selected causal mask are updated at that
same boundary. Unchanged submissions avoid those descriptor transfers. Direct
page host storage is updated in place so the GGML kernel's captured host
descriptor pointer remains valid. Context page-ID, query-position, and row-ID
workspaces retain bounded capacity, and direct physical-slab submissions skip
the duplicate reference row lookup.

## Profile and invariants

The deterministic matrix records 9 submissions, 5 captures/rebuilds, 4
replays, 48 capture-time page-table bytes, and 2 epoch changes. Page
permutation, physical-slot remap, and query-position changes replay the same
layout; tail growth and shape/configuration changes rebuild. Coverage includes
prefill, decode, MTP verify, direct/reference, exact, observe, dense, and
refusal routes. Off/observe modes retain the pre-existing pager bypass.

The host descriptor vector is sized at graph construction and only its existing
elements are overwritten on a reused layout. Reference row refresh uses the
existing vector capacity. Graph fences remain per-submission, preserving old
immutable views until completion.
