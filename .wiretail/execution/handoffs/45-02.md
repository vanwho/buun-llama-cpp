# Handoff 45-02 - bounded natural-cold revalidation

## Result

The 45-01 CUDA binary was measured with the existing v9 B1-B5 harness at
`L8192/H4096/A2048/B128/U64`, 256-token pages, Turbo4 target and draft K/V,
GPU draft K/V, and native MTP. The matched three-prompt controls completed
with 128 committed tokens each. The selected-packed run measured decode
`34.7836, 34.4398, 34.1688` tok/s; CPU-main-KV measured
`10.1215, 10.0846, 10.1530`; pager-off all-GPU measured
`36.5296, 36.6687, 36.7821`. No precise speedup claim is promoted.

The natural recovery fixture reached C=5004 through six incremental turns and
completed a 5052-token cold-topic recall with coherent 8-token output. It
produced 26 positive current-Q attention samples and selected packed execution,
but candidate publication, promotion, useful H2D, and selected cold-page use
were all absent. Eligibility therefore failed and scale stopped before 32K.

## Runtime observation

The first fresh natural run failed at C=2807 with `KV pager batch write
reservation failed: transaction`. After a fresh managed service restart, the
same identity and geometry completed the bounded run. This is recorded as a
runtime failure recovered by isolation; it is separate from the persistent
selection-quality gate failure.

not met. A future run must first observe a non-sentinel current-Q candidate,
