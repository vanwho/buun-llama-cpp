# 28-03 handoff — cooperative paged Turbo4 decode

## Outcome

Replaced production paged Turbo4 decode dispatch with a cooperative CUDA
kernel. A CTA owns a KV head, query token, and bounded KV partition; up to
eight GQA query-head warps reuse one decoded K/V row. The loader resolves page
descriptors and physical/row/head strides once per tile, preserves Turbo4
codebook/channel scaling, Q WHT, V unrotation, online softmax, page mass, and
split-state merge, and uses bounded shared memory. The former serial kernel is
named `ggml_cuda_fattn_turbo4_paged_reference_kernel` and is reachable only
through the explicit test-only `reference_kernel` parameter.

The shared-layout calculator was also corrected for decoded-V extent and the
full page-state allocation. The fixture now compares production output with
the reference kernel and retains the CPU oracle across gaps, tails,
permutations, GQA, masks, all-masked rows, and split-KV cases.
