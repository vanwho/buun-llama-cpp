# V10 task 84-02: route promotion

## Result

Task 84-02 is complete. Automatic selective dispatch now prefers the direct
Turbo4 consumer for the proven one-page decode and prefill shape, keeps the
selected logical page table (no compact packed owner), and never selects the
packed bridge automatically. Explicit `reference`, `packed`, and `direct`
overrides are available for diagnostics and fail closed when unsupported.

The live direct graph boundary is intentionally conservative: a multi-page
prefill direct experiment produced a CUDA illegal-memory failure even after
the split capacity and telemetry sidecar were bounded. Multi-page prefill is
therefore routed to the canonical selected reference consumer until that
long-prefill graph has an independent proof. This prevents an unsafe shape
from becoming an automatic production route.
