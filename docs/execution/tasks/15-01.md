# 15-01 — Re-sync upstream and construct reviewable change slices

## Objective

Recheck current upstream, integrate safely, and map the completed implementation into small dependency-
ordered slices suitable for human review and possible contribution.

## Read

- Repository `CONTRIBUTING.md`, any `AGENTS.md`, task README, cluster `15a-upstream-handoff-v2`.
- Plan sections 13, 17–18, 25; old slice map; all phase-14 handoffs.

## Work

1. Require a clean worktree, fetch `upstream`/`origin`, record tips/divergence and search current upstream
   issues/PRs only to detect duplicates. Do not author or post GitHub text.
2. Determine whether the recorded upstream tip is already an ancestor of the integration branch. The task
   agent must not rebase, merge, switch, commit, or push: if integration is required, write the exact
   range/conflict forecast for the authorized outer Git owner. After that owner supplies a clean updated
   branch on a recovery attempt, resolve remaining source-level regressions by ordinary edits and rerun
   focused tests after each conflict group plus the full required tests.
3. Update `upstream/SLICE_MAP_V2.md` with exact source ranges/hunks, dependencies, destination (generic
   llama.cpp versus Buun-specific), tests, benchmarks, risks and exclusions.
4. Separate at least: draft placement/dynamic MTP; generic sizing/page core; host/CUDA residency; Turbo4
   attention; routing/telemetry/policy; Qwen/server lifecycle; exact mode; tests/docs. Avoid a giant slice.
5. Range-diff against upstream, scan for unrelated changes/generated churn/machine paths, and ensure
   execution metadata is excluded from implementation slices.

## Acceptance

The recorded upstream is an ancestor of the integration branch (either already or after an authorized
outer-Git recovery), the release tests/smoke still pass, every implementation hunk belongs to one slice,
no duplicate active upstream change is ignored, and no GitHub action is taken.

## Deliverable

Create `handoffs/15-01.md` and the V2 slice map with SHAs, range-diffs, test reruns, conflicts and human
next-action checklist.
