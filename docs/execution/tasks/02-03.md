# 02-03 — Add batched asynchronous page transfers

## Objective

Move selected cross-layer pages between GPU and host in bounded batches with explicit events and no
global-lock wait.

## Read

- Task README; plan section 8.8.
- `src/llama-vbr-pinned-ring.*`, VBR stage/capture/adopt transfer adapters, backend async/event APIs,
  VMM batching from `65eb44ebc`, and llama.cpp `2d8d612e4` contiguous-run batching.

## Implementation

- Build per-device D2H/H2D plans from contiguous layer/side/physical runs.
- Reserve catalog, pinned-ring, destination-slot, and event capacity before submitting.
- Attach the full generation/table snapshot to each completion.
- Batch descriptors and copies; report useful versus actual/aligned bytes.
- Wait outside residency/catalog/controller locks.
- Make cancellation idempotent and leave submitted work fenced until resources are safe to reclaim.
- Add allocation-free counters for queue, submit, copy, wait, cancellation, and stale completion.

## Tests and acceptance

Fake-backend tests inject failure before/after reserve, submit, event arm, and completion. Verify no pin,
slot, ring, or catalog leak and no partial publication. If CUDA hardware is available, run a small
round-trip smoke test; otherwise record it as deferred, not passed.
