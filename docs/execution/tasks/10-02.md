# 10-02 — Dispatch direct Turbo4 paged Flash Attention in live decode

## Objective

Bind the existing direct paged Turbo4 CUDA kernel to qualified production decode graphs for every target
full-attention layer.

## Read

- Task README, cluster `10a-live-decode`, plan 9.5 and D10.
- Handoffs 03-03, 06-02, 10-01.
- `ggml/src/ggml-cuda/fattn*`, dispatch/loaders, selected operator metadata, Qwen attention graph, backend
  op registration, CUDA graph and resource tests.

## Implementation

1. Define/extend a backend operation that accepts Q, raw Turbo4 physical K/V storage, validated page
   descriptors, native positions/mask, query positions, table/content epoch, and optional mass output.
2. Qualify runtime geometry/types/device/query shape explicitly. Dispatch direct CUDA for supported decode;
   use 10-01 selected reference for supported fallback shapes; reject everything else clearly.
3. Address physical slots while applying logical positions and tail validity. Support arbitrary page order,
   gaps, all-pages-fit, and the live `H` bound.
4. Reuse existing Turbo4 tile dequantization in registers/shared memory. Allocate no selected/full F16 K/V
   tensor. Bound descriptor/mass scratch to selected pages and active heads/layers.
5. Attach consumer fences and CUDA error/event propagation to the pager table generation.

## Tests

Extend backend-ops/direct fixtures for one/many pages, tail, permutations, logical gaps, supported Qwen
GQA/head dimensions, page-mass on/off equality, mask/causal cases, invalid pointers/ranges/types/shapes,
and maximum admitted descriptor count discovered by fixture input. Run Release CUDA test, memcheck,
racecheck, and live dense/selected-reference/direct per-layer/final-logit comparison.

## Acceptance

Live decode logs show direct paged dispatch at each intended layer; output meets frozen tolerance; sanitizer
is clean; kernel resources and scratch are recorded; fallback/refusal is explicit; no full F16 gather exists.

## Deliverable

Create `handoffs/10-02.md` with op signature, dispatch matrix, resource usage, parity and sanitizer logs,
and raw live evidence.
