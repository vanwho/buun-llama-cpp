# 02-02 — Add host Turbo4 page catalog and budget

## Objective

Store cold target pages as authenticated opaque Turbo4 payloads with explicit RAM accounting.

## Read

- Task README; plan sections 8.2–8.4.
- `src/llama-vbr-artifact-catalog.*`, artifact segment/storage classes, cache accounting/budget code,
  and Phase 02 selected capture descriptors.

## Implementation

- Add an internal page backing key from model/execution/topology/sequence/page/representation identity.
- Store all layer/side segments, native-position metadata, digest, dirty/clean provenance, and bytes.
- Charge metadata, pageable payload, and any pinned residency separately.
- Enforce host budget before capture; deterministic eviction may remove only unpinned reconstructible or
  obsolete entries under the chosen policy.
- Reject corruption, short payload, codec/topology mismatch, stale session/page/representation epochs,
  duplicate ownership, and integer overflow.
- Do not allocate/pin the whole 2.9-GiB cold set by default; pinned staging is bounded separately.

## Tests and acceptance

Round-trip one and multiple pages, replacement, stale invalidation, checksum failure, exact-budget edge,
metadata charge, alias/dedup behavior, and clean shutdown. Existing prompt artifact catalog semantics and
wire versions remain unchanged.
