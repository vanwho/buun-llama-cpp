# 03-02 — Add backend-neutral page-table attention plumbing

## Objective

Define the graph/operator contract for direct selected-page attention without locking it to one model.

## Read

- Task README and Phase 03 compact reference view.
- Upstream llama.cpp `8e93a9773` sparse-FA operator/dispatch/tests.
- `/srv/repos/matiaslin/llama.cpp` block-table operator only as a reference.
- Existing ggml flash-attention operator metadata and backend support checks.

## Implementation

- Add a bounded page/block table tensor or op metadata with physical slot, valid row count, and native
  position mapping.
- Define ordering, alignment, tail, causal-mask, GQA, batch, and lifetime semantics.
- Add backend capability detection and a typed unsupported result.
- Include table epoch in graph reuse/capture keys.
- Ensure off path has no extra tensor/op and unsupported backends never reinterpret metadata.
- Keep K/V types visible so Turbo4 dispatch is explicit.

## Tests and acceptance

Extend an existing backend-op test with metadata validation, empty/one/tail/permuted/gapped tables,
wrong shape/type, overflow, and unsupported backend. The compact reference remains the oracle.
