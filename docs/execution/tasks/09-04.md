# 09-04 — Bind sealed target pages to canonical Turbo4 host RAM

## Objective

Connect real compact target K/V tensors to the authenticated host catalog so every sealed page has a
canonical opaque Turbo4 CPU-RAM copy before it can become a clean eviction victim.

## Read

- Task README, cluster `09b-live-transfers`, plan 8.4, 8.5, 22 step 3.
- Handoffs 02-01, 02-02, 02-03, 09-03.
- VBR artifact capture/catalog/stage/validate, pager transfer plans, CUDA buffer-copy APIs, pinned ring,
  context completion events, cache identity and budget tests.

## Implementation

1. Enumerate the actual target full-attention K/V tensor segments for one logical page from runtime
   geometry; record useful and aligned bytes without assuming layer count/row size.
2. On full-page seal, schedule bounded D2H capture only after producing graphs complete. Copy opaque
   Turbo4 bytes; never dequantize/requantize.
3. Default to pageable canonical allocations with bounded pinned staging. Make whole-store pinned backing
   an explicit experimental setting only for phase-13 comparison.
4. Authenticate session/model/topology/codec/codebook/representation/page generations, logical positions,
   segment lengths, checksums, and catalog budget before publication.
5. Keep the GPU page dirty/pinned until host publication succeeds. On failure retain/retry or fail the
   request according to typed policy; never label it clean.
6. Invalidate/reseal on mutation and release all catalog charges/staging pins/events on clear/teardown.

## Tests and checkpoint

Fake and CUDA copies for full/tail/reseal pages, segment permutation, corruption, short read/write,
stale events, catalog/ring exhaustion, cancellation, duplicate seal, codec/topology mismatch, and budget
rollback. Model-backed ingest seals multiple pages and verifies byte checksums against device storage.

## Acceptance

Every sealed page is cataloged exactly once with complete Turbo4 bytes; partial/failed pages are absent;
host RSS/accounting matches catalog charge; no unbounded pinned allocation exists.
