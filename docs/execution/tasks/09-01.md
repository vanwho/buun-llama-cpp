# 09-01 — Add one normalized experimental pager configuration and gate

## Objective

Make pager intent reach target-context construction through one portable configuration object, with
`off` as the unchanged default and strict capability/refusal diagnostics.

## Read

- Task README, cluster `09a-live-memory`, plan sections 10, 21–22.
- Handoffs 01-01, 03-02, 08-01–08-05.
- Common params/argument conversion, public context params boundaries, server config/context startup,
  model metadata, backend capability helpers, parser tests, generated docs workflow.

## Implementation

1. Define internal normalized modes `off|observe|selective|exact` and settings for page size, VRAM/host
   budget, safety headroom, recent policy, optional hot-page cap, router, telemetry, prefetch, and debug.
2. Use `auto` values as typed states, not magic integers. Parse sizes with existing helpers and reject
   overflow/contradiction.
3. Add an experimental CLI/server surface sufficient for live phases 09–11. Keep names in one parser
   location so 12-01 can finalize them without parallel aliases.
4. Build a capability result listing exact reason codes: backend, model architecture, causal mode,
   Turbo4 K/V, attention geometry, page geometry, device topology, sequence/slot layout, host budget,
   MTP type/device/context match, and conflicting VBR authority.
5. Validate before any pager allocation. `off` must not run capability probes that change behavior;
   `observe` may allocate bounded summaries but never moves pages.
6. Log normalized settings and reason codes without server-specific paths or hardware names.

## Tests

Parser/env precedence, auto/explicit sizes, invalid modes/units, page-size compatibility, cap safety,
all refusal reasons, feature-off byte-for-byte config defaults, and native-MTP requirements. Regenerate
help/docs and test their diff. Build CPU parser/server and CUDA server.

## Acceptance

A live dry startup reaches an explicit `off`, `observe`, or pager-qualified state. Unsupported settings
fail before partial construction. No hot count is defaulted, and no implementation allocation beyond
normalized config is added in this task.

## Deliverable

Create `handoffs/09-01.md` with CLI/config table, capability matrix, tests, generated docs, and downstream
constructor entry point.
