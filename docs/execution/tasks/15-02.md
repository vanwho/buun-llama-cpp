# 15-02 — Repair and freeze a real multi-page pager corpus

## Objective

Replace the current schema-valid but semantically empty corpus with deterministic prompts that exercise
multiple logical pages and permit dense control to recover every expected answer.

## Read

- Task README, cluster `15b-corpus-contract`, plan sections 12.4, 19, 24–25.
- `tools/server/bench/generate-pager-corpus.py`, `pager_benchmark_contract.py`, benchmark README, V2
  quality evidence, and the deployed Qwen tokenizer metadata.

## Work and acceptance

Add deterministic category fixtures and answers to the actual prompt, with calibration and held-out
partitions constructed by the same immutable rules. Generate tokenized contexts at declared lengths,
place needles at declared page distances, include tails/odd page counts and focus-shift/churn cases, and
record tokenizer/model hashes. Remove the misleading held-out answer suffix. Extend validation to check
fact presence, expected-answer reachability, token-length tolerance, page-distance bounds, unique hashes,
and partition separation. Regenerate a new corpus version; never mutate V2 in place.

Run corpus validation, dense control for all cases, and a small selected-all/reference fixture. Stop
before pager tuning if dense control cannot answer the facts. Preserve raw prompts/responses and hashes.

## Deliverable

Create `handoffs/15-02.md`, the versioned corpus and validator changes, semantic validation output, and
raw dense-control pointers. All production code remains path- and server-independent.
