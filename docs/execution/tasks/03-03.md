# 03-03 — Implement Turbo4 paged flash-attention decode

## Objective

Implement the CUDA decode kernel that reads selected Turbo4 K/V pages directly and optionally reduces
attention mass by logical page.

## Read

- Task README; plan sections 9.4 and 12.2.
- Current Buun Turbo4 loaders/dispatch in `ggml/src/ggml-cuda/fattn*`.
- Operator contract from 03-02, compact oracle from 03-01, upstream sparse FA `8e93a9773`, and the
  community page kernel’s addressing shape.
- Relevant closed Buun asymmetric/Turbo corruption issues and tests.

## Implementation

- Support the exact reference geometry first: causal decode, T4 K/T4 V, GQA=4, Dk=Dv=256, batch 1.
- Address physical slots through the validated table while masking by native logical position.
- Preserve Turbo rotation/unrotation, codebook, scale, and mean-subtraction behavior exactly.
- Handle tail rows and arbitrary physical page order.
- Optional page-mass reduction must not change output when enabled.
- Avoid whole-cache F16 dequantization; bound shared/register/scratch use and keep NVIDIA sm_89 correct.
- Refuse all unsupported shapes/types rather than falling through to a wrong kernel.

## Tests and acceptance

Compare against compact gather and dense Turbo4 across one/tail/many/permuted/gapped pages with fixed
seeds and tolerances. Run backend ops and compute-sanitizer on bounded fixtures when CUDA is available.
Record kernel timing and resource/compiler output, but defer optimization until correctness passes.
