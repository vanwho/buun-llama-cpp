## Runs

   control for this SHA using the frozen ladder rule.
2. Run at model maximum context: same-context ordinary CPU target K/V with Turbo4 GPU MTP; selective warm

   observe overhead <=5%, and no hidden full-context GPU target allocation.
6. If a hard speed gate fails, profile and test at least three evidence-driven repair hypotheses, rerun
   correctness/quality affected by retained changes, mint a new release hash, and repeat rather than
   weakening the gate.
7. Restore the original service/profile and 8080/8091 health; do not touch 8092.

degradation is disclosed separately. This task cannot be deferred or passed from historical benchmarks.
