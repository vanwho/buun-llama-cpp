# 03-01 — Build compact selected-cache reference view

## Objective

Create a simple correctness path whose attention width is resident rows, not the 262K logical frontier.

## Read

- Task README; plan sections 8.5 and 9.3.
- `src/llama-kv-cache.*`, `src/llama-kv-cells.*`, graph attention builders, and upstream non-contiguous
  restore/position fixes referenced by the salvage matrix.

## Implementation

- Materialize selected page rows into compact Turbo4 K/V physical slots.
- Build a compact native-position vector/mask from logical metadata; preserve original RoPE positions.
- Expose an internal immutable memory view and graph epoch.
- Keep the current write page and tail mask correct.
- Make `get_n_kv()`/equivalent graph dimension equal selected physical rows in selective mode.
- Pin snapshot pages until graph completion.
- Leave off/observe paths unchanged.

## Tests and acceptance

At small contexts, compare selected-all-pages with current dense Turbo4 output. Compare permuted and
gapped selections with an explicit gather reference. Assert graph/scratch dimensions scale with resident
rows. No new CUDA paged kernel is required in this task.
