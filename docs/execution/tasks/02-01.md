# 02-01 — Add bounded selected-page capture descriptors

## Objective

Create the narrow seam that captures/adopts chosen 256-cell Turbo4 page ranges without serializing a
whole context or bypassing the representation identity/generation rules shared with VBR.

## Read

- Task README; plan sections 5.1, 8.4, and 9.3.
- `src/llama-vbr-artifact-{capture,adopt,stage,validate}.*`,
  `src/llama-vbr-explicit-capture.*`, `src/llama-vbr-generation-*`,
  `src/llama-vbr-pinned-ring.*`, and relevant KV capture adapters.
- Design/table output from Phase 01.

## Implementation

- Define a bounded page-range request with logical page identity, expected generations, positions, and
  required layer/side units.
- Project exact segment counts/bytes before allocation.
- Produce existing representation descriptors for Turbo4 codec/codebook/rotation/mean-subtraction and
  topology identity.
- Stream segments through the existing bounded ring/segment-chain interfaces.
- Require all 16 target attention layers and both K/V sides for a complete cross-layer page.
- Recheck snapshot/generations after transfer; partial results are never adoptable.
- Leave full-prefix prompt artifact behavior byte-compatible.

## Tests and acceptance

Use fake providers in an existing VBR test target. Cover one/two/non-contiguous pages, partial tail,
wrong type, missing unit, stale page generation, representation change, overflow, and short transfer.
No multi-gigabyte temporary vector and no public state serializer call may appear.
