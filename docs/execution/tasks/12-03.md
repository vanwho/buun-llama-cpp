# 12-03 — Prove off/observe/selective/exact server compatibility and fail-closed behavior

## Objective

Close the usable-surface phase with real server lifecycle tests for all modes, ordinary behavior, and
unsupported configurations.

## Read

- Task README, cluster `12a-operator-surface`.
- Handoffs 10-05, 11-05, 12-01–12-02; server integration tests and benchmark smoke records.

## Work and tests

1. `off`: compare configuration, allocations, output and performance smoke against the pre-pager route;
   assert no pager host/device/table/telemetry owner exists.
2. `observe`: dense/current attention with summaries/telemetry only; assert zero page promotions/evictions
   and measure overhead.
3. `selective`: cross admitted capacity, retrieve/promote a cold page, publish dynamic tables, and retain
   context-sized GPU MTP.
4. `exact`: visit all pages through waves and return a valid response with complete coverage.
5. Exercise startup refusal for every documented unsupported model/type/device/topology/budget/sequence/
   MTP combination and inject failure after each construction phase to verify rollback.
6. Exercise request cancellation, clear, shutdown, profile restart, and repeated starts. Capture memory and
   health before/after.
7. Run focused server/argument/KV/speculative tests plus CUDA sanitizer on touched paths.

## Acceptance

All four modes match their semantic contract; unsupported input fails before serving; `off` remains
ordinary; no resource leaks or stale completions; generated docs and metrics agree; 8080/8091 restore and
8092 is untouched.

## Recovery

Diagnose mode failures at configuration, ownership, graph, transfer, or lifecycle boundary using typed
counters. Do not downgrade a requested mode silently or mark an unexecuted path passed.

## Deliverable

Create `handoffs/12-03.md` and an operator-surface matrix linking tests, live commands, raw results,
refusals, resource deltas, and remaining performance work only.
