# 12-01 — Finalize the experimental pager CLI and diagnostics

## Objective

Consolidate the now-live runtime into one documented experimental operator surface without fixed hot-set
defaults or a prematurely stable public library ABI.

## Read

- Task README, cluster `12a-operator-surface`, plan sections 10, 21, 25.
- Handoffs 09-01, 09-02, 11-05; parser/help/operator docs and generated-doc tooling.

## Work

1. Review actual live needs and finalize one spelling for mode, page size/capability, VRAM/host budget,
   headroom, recent policy, optional hot-page upper bound, router, telemetry cadence, prefetch and debug.
2. Remove temporary aliases unless existing released fork compatibility requires them; document any kept
   alias and canonical output.
3. Ensure `auto` derives context/MTP/hot capacity and policy. No example/default contains a preferred hot
   token/page count.
4. Emit a single startup summary: resolved context, MTP rows/types/device/bytes, logical/admitted pages,
   byte ledger, policy config, route capability, and refusal reason.
5. Fail before partial construction for incompatible native `-cd`, K/V type, GPU, host/device budget,
   topology, sequence count, page geometry, VBR authority, or attention mode.
6. Regenerate CLI/server/completion docs and shell completions through repository tooling.

## Tests and acceptance

Parser/env precedence, every valid/invalid combination, auto resolution, explicit caps, off behavior,
generated-doc stability, and live startup for all four modes. Help matches behavior exactly; no machine
path or hardware assumption enters source.

## Deliverable

Create `handoffs/12-01.md` with final option table, compatibility decisions, generated files, test/startup
matrix, and refusal examples.
