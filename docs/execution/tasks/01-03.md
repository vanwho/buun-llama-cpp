# 01-03 — Implement budget and MTP reservation arithmetic

## Objective

Make the ~77K hot-set target a checked result of real memory accounting, with full MTP reserved first.

## Implementation

Add pure internal arithmetic that inventories, in order:

1. weights and non-KV buffers already resident;
2. exact recurrent/fixed companions;
3. full 262,144-token MTP Turbo4 K/V (expected payload 264 MiB for reference geometry);
4. graph and Turbo4 dequant scratch at the selected batch/ubatch;
5. routing summaries, page tables, events, and transfer rings;
6. configured headroom;
7. remaining bytes rounded down to complete 256-token cross-layer target pages.

Use actual tensor row sizes and device allocation granularity, not only 4.125 bpv. Produce typed refusal
reasons. A diagnostic 77,824 override may lower capacity but must not force overcommit.

## Tests and acceptance

- Assert reference payload arithmetic from plan section 3.
- Test one-byte-short rounding, overflow, MTP F16 accidental selection, missing scratch, multiple
  devices, zero budget, and capacity above/below 304 pages.
- Ledger totals reconcile; no component is charged twice.
- Existing off/VBR fit behavior is unchanged until selective mode is enabled later.
