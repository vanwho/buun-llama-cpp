# 11-02 handoff — all-page query retrieval and structural union

## Outcome

Added the backend-neutral `llama_kv_routing_retrieve()` seam. It validates a
pre-attention query against the live residency epoch and page identity tags,
asks the immutable routing-summary store to score every valid page, and forms
a bounded deterministic union. The priority is current/write and pinned
pages, structural anchors, recent pages, summary top-K, then rotating
exploration. Page identity is carried through every selected entry; logical
page numbers are never used as the authority by themselves.

The result exports per-page score availability, centroid upper-bound tagging,
selection reason, native page distance, query/table generations, summary
bytes, comparison count, score/union/total timing fields, and fallback state.
Missing or stale summaries are unavailable evidence rather than zero scores.
Mandatory overflow returns a typed refusal without a partial target. When
`H >= L`, the complete valid inventory is returned as the dense-equivalent
small-context rule.

## Ownership and contract

- `llama_kv_routing_query` is the pre-target-attention query representation;
  its generation, token index, table epoch, model/topology/representation
  identities, sequence, layer, and head are explicit tags.
- `llama_kv_routing_page_attributes` is the controller/application seam for
  current, pin, structural-anchor, and recent classifications.
- `llama_kv_routing_summary_store::score()` remains the all-page scoring owner;
  retrieval only consumes its bounded score records and does not copy K/V or
  attention matrices.
- A missing summary uses mandatory/recent/previous-target safe candidates and
  reports `unavailable_summary`; a mismatched summary reports
  `stale_summary`. A stale query is rejected before score use.
- Exploration is bounded and deterministic: sorted logical candidates are
  selected from a circular offset derived from `exploration_seed +
  exploration_turn`.

## Baseline and checkpoint

The selected baseline uses the task 11-01 representative summary form (four
vectors from the caller-configured runtime layer/head, production default
layer 0/head 0), a CPU reference score path, one summary candidate, and one
exploration candidate. The machine-readable configuration, synthetic cold
needle result, failure examples, and deferred measurement fields are in
[`ROUTING_RETRIEVAL_CHECKPOINT.json`](../evidence/ROUTING_RETRIEVAL_CHECKPOINT.json).

The deterministic fixture scores six valid pages with 24 representative
comparisons, includes a partial tail, and places the cold needle in the
requested set. Synthetic attention-mass capture and stable latency numbers
are intentionally null until the model-backed calibration runner is
available.

## Remaining risks

The query source is an explicit integration seam rather than a live graph
producer in this task. Task 11-03 can consume the selected identities and
generation tags, while the model-backed calibration phases must bind the
actual pre-attention query and validate the baseline against exact/dense
attention before promotion.
