# 11-03 handoff — live GPU-reduced per-page attention telemetry

## Outcome

The selected direct Turbo4 graph now has an optional logical-page mass output.
The existing CUDA reduction is enabled only for a configured layer and sampled
query-head range; feature-off, dense/observe, selected-reference, and exact
routes keep their existing output path. Non-due cadence graphs omit the
reduction and D2H copy, including graph-reuse decisions at cadence boundaries.

The graph input captures the selected sequence's immutable residency snapshot
and full page records. After the scheduler fence, the context copies only the
bounded page-mass tensor, validates the captured epoch and all page/session,
sequence, page, representation, model, topology, codec, rotation, and native
range identities, and publishes to `llama_kv_attention_telemetry`. A rebuilt
table preserves statistics only for equal full page identities. Canceled or
failed graph submissions do not publish. An accessor exposes the accumulator
to the internal retention/controller boundary.

EMA, recent peak, frequency, and normalization change only for participating
pages. Unknown resident/cold pages remain unobserved. The telemetry counters
now include samples, sampled tokens/pages/layers/heads, skipped/stale/invalid
counts, GPU reduction time when supplied by a backend event, D2H bytes/time,
publish time, and total observe overhead.

## Configuration

`llama_kv_pager_config` accepts `telemetry_interval_tokens`,
`telemetry_layer`, `telemetry_head_begin`, and `telemetry_head_count` (zero
head count means all heads). The common parser exposes the corresponding
`--kv-telemetry-interval`, `--kv-telemetry-layer`,
`--kv-telemetry-head-begin`, and `--kv-telemetry-head-count` options.

Device capture storage is `L * query_heads * sizeof(float)` for one configured
layer. The host transfer is page-mass data only; no K/V payload or attention
matrix is copied.

The CUDA-enabled build was started with `cmake --build build-cuda --target
llama -j8`; the modified `fattn.cu` translation unit compiled cleanly before
the repository-wide template build was stopped at 44%. The existing direct
Turbo4 fixture was also run against the CUDA library and passed on the RTX
4080 (`20.561 ms`). Existing fixture sanitizer results remain recorded in the
10-02 CUDA handoff; the new optional graph source itself has not been exercised
with a live model.

## Deferred verification

The linked GPU is occupied by an existing model server and no isolated
model-backed calibration slot is available for this task. Consequently, the
following are deferred to `/srv/ai/paged-kv/results/11-03/`: five dense/observe
and five selected telemetry trials, real Qwen layer/head capture, CUDA event
reduction timing, live D2H timing, dense/reference/direct final-output parity,
captured-mass consistency against dense/exact attention, graph cancellation and
table-rebuild runs, and optional-source memcheck/racecheck. These checks must
be completed before phase-14 acceptance; no model-backed performance or
quality result is claimed here.
