# Handoff 05-03

## Outcome

Server request reuse now has an independent slot session generation, separate
from prompt lineage. Every accepted launch mints a nonzero generation before
restore or decode. Slot-file restore and empty-slot artifact import mint before
installing replacement state as well. Asynchronous VBR capture candidates carry
the value through transfer and reject publication if the slot was reused. A
queued task is a hard publication boundary: the queue cancels the shared
capture session,
then the scheduler drains and abandons the private transfer before processing
the task. Explicit server termination performs the same drain after releasing
the queue mutex.

The initial pager lifecycle contract is modelled as single-slot authority;
selective multi-slot admission is rejected while ordinary off/observe
multi-slot behavior remains permitted. Native MTP is included in the existing
live-memory and configured-compute accounting scans. Cache-debug slot output
exposes the request generation for lifecycle diagnosis. Existing immutable
VBR validation and sealed publication paths remain the only artifact adoption
boundary.

## Deferred verification

Model-backed Qwen3.8 selective-attention startup, real page transfer faults at
each backend phase, full 262,144-token host-budget pressure, MTP GPU placement,
and hardware teardown remain deferred. The local CUDA build is available, but
the required Qwen3.8 checkpoint and end-to-end pager fixture are not
configured. Later verification must exercise cold/same/divergent prompts,
clear/reset, cancellation during transfer, slot reuse with a late completion,
invalid artifacts, host pressure, and shutdown while checking that no stale
page publishes and all host/pinned/MTP/recurrent bytes return to zero.

## Remaining risks

The server’s public pager mode wiring is still intentionally outside this
task; the single-slot admission seam is ready for that authority to consume.
End-to-end proof of page residency and hardware allocator behavior therefore
belongs to the deferred model-backed checks and the subsequent checkpoint/
speculative-rollback task.
