## Deferred verification

The active external service at `/srv/ai/paged-kv/build/buun/bin/llama-server`
was using 15326 MiB of the only GPU during the broad CUDA run. Consequently
the full operator sweep and three model/VBR stress tests were rerun only in
narrow/resource-independent forms and are not claimed as clean-GPU passes.
The exact later check is to stop or otherwise quiesce that service, verify
free GPU memory, then rerun:

```sh
ctest --test-dir build-14-01-cuda -R '^(test-backend-ops|test-llama-archs|test-thread-safety|test-moe-cache)$' --output-on-failure
```

Model-backed selective-pager quality/context/answer acceptance is intentionally
owned by the later phase-14 model acceptance tasks; this task makes no such
claim.
