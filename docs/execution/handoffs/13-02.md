# 13-02 handoff — direct Turbo4 paged decode optimization

## Outcome

No candidate met the 13-01 direct-kernel budget, so no production optimization
was retained. Three independent profile-driven hypotheses were implemented,
compiled, correctness-checked, measured with seven invocations each, and
rejected after their measured medians regressed against the baseline. The
baseline source and launch geometry are restored unchanged. This satisfies the
packet's alternate acceptance path: document and test at least three hypotheses
before a genuine performance block.

The initial baseline median was 20.865 ms for the bounded four-head, one-query,
529-selected-row fixture. The fresh post-revert baseline median was 20.969 ms;
the difference is within the observed run noise. The retained cumulative
improvement is 0% and no speed or quality claim is made for the live model
route.

## Hypotheses and code deltas

| Candidate | Code delta | Measured median | Median delta | Decision |
| --- | --- | ---: | ---: | --- |
| A — warp/register specialization | One warp per head, register-resident FWHT and value accumulators, warp-broadcast metadata/norms | 21.738 ms | +4.184% | Rejected |
| B — descriptor cache | Stage each 24-byte page descriptor once per page in shared memory | 22.074 ms | +5.794% | Rejected |
| C — packed-nibble reuse | Fetch each packed byte once per even/odd lane pair and shuffle to its partner | 22.297 ms | +6.863% | Rejected |

All candidate edits were reverted. `ggml/src/ggml-cuda/fattn.cu` has no final
diff. Raw invocations, measured sets, means, sample deviations, and empirical
max/p95 values are preserved in
[`kernel-profile-13-02.txt`](../evidence/kernel-profile-13-02.txt).

## Repetitions, noise, and resources

Each run used the existing Release CUDA test build on an RTX 4080 (compute
8.9), with two warmups and five measured CUDA-event samples. Baseline measured
sample standard deviation was 1.219 ms in the first set and 0.521 ms in the
fresh final set. Candidate A/B/C deviations were 0.870/0.468/0.993 ms,
respectively. The final linked CUDA library hash was
`400a48d1898620ff13cfbc3e86242ecb0c43aafe345e86cfcba727f3f3fc2aa9`.

The final `cuobjdump` resource line for
`ggml_cuda_fattn_turbo4_paged_decode_kernel` is `REG:40 STACK:0 SHARED:0
LOCAL:0`; it matches the baseline resource summary. No retained candidate
changed resource usage.
