## Truth table

| Target `no_kv_offload` | Draft setting | Draft `offload_kqv` | Target placement |
|---|---|---:|---|
| false | `auto` | true | unchanged (GPU/offloaded) |
| true | `auto` | false | unchanged (CPU) |
| false or true | `gpu` | true | unchanged |
| false or true | `cpu` | false | unchanged |

`gpu` is rejected when no GPU backend is built and fails during context setup
when the selected model has no usable GPU device. Invalid values fail with the
accepted-value diagnostic. The normalized spelling is
`--spec-draft-kv-device auto|gpu|cpu`, with environment/config spelling
`LLAMA_ARG_SPEC_DRAFT_KV_DEVICE`; CLI values override configuration values.
