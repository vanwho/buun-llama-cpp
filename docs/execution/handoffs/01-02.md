# 01-02 handoff

## Outcome

Added CPU-only internal `llama_kv_*` page identity and residency-table
primitives. The implementation reuses `VBR_GENERATION_PAGE_CELLS` (256),
validates sealed/tail position ranges, tracks identity generations,
representation/topology digests, page state, host/dirty flags, and pins, and
publishes immutable snapshot states through generation-checked transactions.

## Deferred verification

- No CUDA/backend calls were introduced; backend transfer and hardware checks
  belong to later tasks.
- Concurrency stress, fault injection across transfer phases, and integration
  with attention graph consumers remain deferred to later residency tasks.

## Invariants for later tasks

- A logical page cannot appear twice, and a physical slot cannot have two owners.
- Physical slots are bounded and ephemeral; snapshots retain prior table state
  until graph consumers release them.
- Publication increments the table epoch only after validation; stale
  transactions and pinned replacement attempts are rejected.
