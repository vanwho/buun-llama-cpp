# 14-03 handoff - held-out quality acceptance

## Outcome

The locked `pager-corpus-v2` acceptance was executed and produced a
`BLOCKED` decision. This is an observed quality/contract failure, not a
deferred check and not a selective-quality acceptance claim. The dense control
and corrected selective run each scored 0/12 on the frozen held-out checker.
The exact route reached its planner for all 12 requests but failed closed
because exact CUDA page-wave callbacks are not configured.

The frozen prompts contain only a partition marker, a sealed-pages marker, and
the question. They do not contain the category fixture facts described by
`input_construction`, so the dense control cannot recover the frozen expected
answers either. This was recorded as a corpus/input-contract failure rather
than hidden behind an aggregate score. No prompt, answer, checker, policy, or
threshold was changed after observing output.
